# 在线课堂（管理端）课程管理复刻接口文档

> 版本：v1.0 ｜ 日期：2026-10-03 ｜ 服务：OnlineClassroom（经网关 /api/kng）
> 配套：01-需求文档.md、02-技术实现方案.md、04-建表与种子数据.sql、05-课件管理增补文档
> 通用约定同课件管理 v1.0 接口文档（{code,message,data}、page 从 1 起、id 字符串、课件模块的分页/枚举约定）。

---

## 1. 通用约定（增量枚举）

| 枚举 | 值 |
|------|-----|
| 课程 status | 0未发布 1发布中 2已发布 3已下架（原平台 5→0、4→2） |
| unlockMode | 1自由学习模式 2按顺序学习 |
| unlockUnit | 1按内容 2按章节 |
| structureType | 0无章节 1有章节 |

## 2. 接口列表

### 2.1 课程列表（CS-01）【参照原平台 POST /kng/knowledge/courselist】

#### FP-CS-01 分页查询课程列表
- **Method / Path**：`POST /api/kng/admin/course/list?page=1&pageSize=10&orderBy=updateTime&orderType=desc`
- **请求参数**（body，可空）：同课件列表去掉 `type`：

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 名称/分类名/上传者 OR 模糊 |
| status | int | 0/1/2/3 |
| catalogId / includeChildCatalog | | 同课件 |
| onSale | int | 是否上架 |
| uploadTimeStart/End、updateTimeStart/End | string | 时间区间 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 3,
    "records": [
      {
        "id": "1948010293847565300",

        "catalogId": "1948010293847565031",
        "catalogName": "验布机",
        "status": 2,
        "statusDesc": "已发布",
        "onSale": 1,
        "hidden": false,
        "updateTime": "2026-09-24 10:35:54",
        "studyCount": 2,
        "platformNo": "ZXKT2026092400003",
        "coverUrl": "/kng-files/202609/course17.png",
        "createdByName": "朱友婷",
        "structureType": 1
      }

  }
}
```

### 2.4 课件学习详情（CS-05）

### 2.5 学习数据四件套（CS-06）

### 2.6 创建与第一步表单（CS-07/08）

#### FP-CS-08a 创建课程（点下一步时）
- **Method / Path**：`POST /api/kng/admin/course`
- **请求**：

```json
{
  "title": "未命名课程",
  "catalogId": "1948010293847565031",
  "finishStandardPercent": 100,
  "viewPermission": 1,
  "structureType": 1
}
```

- **行为**：插入 status=**0 未发布**；生成 platformNo；返回 `{"data":{"id":"1948010293847565300"}}`。
- **响应**：`{ "code": 0, "message": "success", "data": { "id": "1948010293847565300" } }`

#### FP-CS-07 保存第一步表单（编辑/创建共用）
- **Method / Path**：`PUT /api/kng/admin/course/{id}/basic`
- **请求**：创建参数全集 + 其余表单字段（standardDurationFollow/standardMinutes/standardSeconds/studyScore/description/coverUrl/code/versionStr/speedEnabled/speedHoursCalc/contributorId/attachments）。
- **响应**：`{ "code": 0, "message": "success", "data": null }`

### 2.7 设计器（CS-07a）【自行设计：整体读写】

#### FP-CS-07a-1 读取设计器结构
- **Method / Path**：`GET /api/kng/admin/course/{id}/designer`
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "structureType": 1,
    "unlockMode": 2,
    "unlockUnit": 1,
    "chapters": [
      {
        "id": "1948010293847565310",
        "name": "章节1",
        "description": "",
        "tasks": [
          {
            "id": "1948010293847565311",
            "coursewareId": "1948010293847565100",
            "taskName": "V2智能验布机",
            "hidden": false,
            "credits": 1.33,
            "durationText": "13 分 20 秒",
            "coursewareStatus": 2,
            "coursewareType": 2
          }
        ]
      }
    ],
    "flatTasks": []
  }
}
```

- **说明**：无章节课程 flatTasks 生效、chapters=[]；credits/durationText/coursewareStatus 为 join 课件实时值（展示用）。

#### FP-CS-07a-2 保存设计器（保存/暂存共用）
- **Method / Path**：`PUT /api/kng/admin/course/{id}/designer`
- **请求**：同读取结构（不含 join 展示字段）+ `publish`：

```json
{
  "publish": true,
  "structureType": 1,
  "unlockMode": 2,
  "unlockUnit": 1,
  "chapters": [
    { "id": "1948010293847565310", "name": "章节1", "description": "",
      "tasks": [ { "coursewareId": "1948010293847565100", "taskName": "V2智能验布机", "hidden": false } ] }
  ],
  "flatTasks": []
}
```

- **行为**：事务内全删全插 chapters+tasks；kng_ref 同步重建（delete by ref_id → batch insert，ref_type=1、ref_name=课程名快照）；`publish=true` 且当前 status=0 → status=2（已发布）；`publish=false`（暂存关闭）状态不变。
- **校验**：coursewareId 必须存在且未删除（已下架允许）；任务总数 ≤999；章节名必填≤200；章节说明≥5 字（填了才校验）。
- **响应**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "课件【xxx】已删除，无法保存", "data": null }`

### 2.8 选课件抽屉数据源（CS-07a）
复用 `POST /api/kng/admin/courseware/list`（课件模块接口）：`status=2`（已发布）+ `catalogId` + `keyword`；前端按入口类型传 type。

### 2.9 课程操作（CS-09）

| FP | Method / Path | 请求 | 说明 |
|----|--------------|------|------|
| 隐藏 | `POST /api/kng/admin/course/{id}/hide` | `{"hidden":true}` | hidden 标记；false=取消隐藏 |
| 下架 | `POST /api/kng/admin/course/{id}/take-down` | — | status 2→3、on_sale=0 |
| 批量上架/下架 | `POST /api/kng/admin/course/batch/put-on`、`.../batch/take-down` | `{"ids":[]}` | |
| 移动 | `POST /api/kng/admin/course/batch/move` | `{"ids":[],"targetCatalogId":""}` | |
| 复制 | `POST /api/kng/admin/course/{id}/copy` | `{"targetCatalogId":""}` | 深拷贝三表+ref 重建；status=0；title 加"-副本"；响应 `{"data":{"id":"新id"}}` |
| 删除 | `DELETE /api/kng/admin/course/{id}` | — | 引用检查（kng_ref 中 ref_type=2 培训/考试引用本课程——当前恒无）；连带删 chapters/tasks/ref(by ref_id) |
| 批量删除 | `POST /api/kng/admin/course/batch/delete` | `{"ids":[]}` | |
| 下载 | `GET /api/kng/admin/course/{id}/download` | — | 恒 `{ "code": 1, "message": "课程无源文件", "data": null }` |
| 引用记录 | `GET /api/kng/admin/course/{id}/references` | — | 查 kng_ref（ref_id=课程id 且 ref_type=2）；当前恒空 |

- 删除失败示例（未来）：`{ "code": 1, "message": "课程已被培训【xxx】引用，无法删除", "data": null }`

### 2.10 任务隐藏（设计器内，CS-07a）
任务隐藏随设计器整体保存（hidden 字段），无独立接口。
