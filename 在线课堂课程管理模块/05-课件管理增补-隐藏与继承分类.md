# 课件管理增补文档：隐藏操作 + 创建继承选中分类

> 版本：v1.1（增补）｜ 日期：2026-10-03 ｜ 对象：课件管理模块 v1.0 已实现代码的**增量需求**
> 声明：本文件不推翻课件管理 01~03 v1.0 文档，仅追加两个功能点与对应接口/DDL 变更；DDL 已合并进 `在线课堂课程管理模块/04-建表与种子数据.sql` 的增补段。
> 背景：课程管理模块设计过程中用户指出的两处遗漏。

## 增补A：更多菜单增加"隐藏"

### A1. 需求
- 课件"更多"hover 菜单在**下架之前**新增"隐藏"项。
- 点击弹确认弹窗（复用课程模块截图18 的语义，样式见 `在线课堂课程管理模块/在线课堂课程管理-观察素材/原图/18-任务预览弹窗.png`）：
  - ⚠ 橙色警告图标
  - 标题"确定隐藏此课件吗？"
  - 正文"已选择课件：xxx" + "隐藏后对所有学员不可见"
  - 【取消】【确定】
- 确认后：课件列表行**置灰 + "已隐藏"标签**（不消失、不下架）；操作列可再次进入更多菜单，"隐藏"项变为"取消隐藏"（取消后恢复）。
- **隐藏与下架为独立双标记**（用户拍板）：hidden 列独立于 status；两者可同时存在；列表筛选/搜索不受隐藏影响。
- 学员端不可见为未来语义，本次仅存储与标记。

### A2. 数据变更
`kng_courseware` 新增列 `hidden TINYINT NOT NULL DEFAULT 0`（DDL 见课程管理模块 04 SQL 增补段，幂等）。

### A3. 接口
- **隐藏/取消隐藏**：`POST /api/kng/admin/courseware/{id}/hide`，body `{"hidden":true}` → 更新 hidden 列。
- **列表响应**：`POST /api/kng/admin/courseware/list` 的 records 行增加 `"hidden": false` 字段（v1.0 响应结构追加，向后兼容）。
- **详情响应**：`GET .../courseware/{id}/detail` 增加 `"hidden": false`。

### A4. 验收标准
- Given 已发布课件 When 更多-隐藏-确定 Then 行置灰+"已隐藏"标签，刷新仍在；更多菜单项变"取消隐藏"
- Given 隐藏课件 When 取消隐藏 Then 恢复正常样式
- Given 隐藏课件 When 下架 Then 两个标记并存（隐藏+已下架）

## 增补B：创建时继承左树选中分类

### B1. 需求
- 课件管理四种发布途径（上传文件/SCORM/HTML/外链）的表单页打开时：若列表页左树**当前有选中分类**，表单"分类"默认=该选中分类（含其全路径回显）；未选中则保持现状（默认空，用户自选）。
- 路由跳转时通过 query 携带 `catalogId`（如 `/kng/courseware/publish/file?catalogId=xxx`），表单初始化读取并预选。
- 课程管理的创建第一步（CS-08）同款设计（已在课程管理 01 文档写明，本文仅做课件侧）。

### B2. 实现
纯前端：CoursewareMgmt 跳转发布路由时把 `selectedCatalogId` 拼进 query；CoursewareForm onMounted 读取 query.catalogId 预填分类。无后端变更。

### B3. 验收标准
- Given 左树选中"服务话术" When 点发布课件-上传文件 Then 表单分类默认"服务话术"
- Given 未选中分类 When 打开发布表单 Then 分类为空待选
- Given 直接粘贴 URL（无 query）进入 Then 分类为空，不报错
