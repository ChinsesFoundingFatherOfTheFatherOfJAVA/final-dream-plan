# 在线课堂（管理端）课程管理复刻需求文档

> 版本：v1.0 ｜ 日期：2026-10-03 ｜ 配套：02-技术实现方案.md、03-接口文档.md、04-建表与种子数据.sql、05-课件管理增补-隐藏与继承分类.md
> 参照平台：train.chinajack.com/kng/#/course/mgmt；勘察记录见 `在线课堂课程管理-观察素材/逆向勘察记录-2026-10-03.md`
> 前置模块：分类管理、课程设置、**课件管理**（v1.0 文档已交付且实现）——课程管理大量复用课件管理的组件与表结构

## 1. 项目概述

复刻课程管理：课程列表（复用课件列表骨架，无类型列）、课程详情三 tab、创建/编辑两步流程（基本信息表单 → 章节任务设计器）、更多菜单操作（隐藏/下架/移动/删除/复制/下载/引用记录）、任务对课件的引用联动（kng_ref 正式启用）。

**同轮交付的课件管理增补**（见 05 文档）：更多菜单加"隐藏"、创建时继承左树选中分类。

范围边界：学员端不做；微课/练习/考试任务类型置灰占位；讨论/问卷/签署/作业/实战演练图标不显示；真实转码/字幕/AI 不做（沿用课件模块待办）。

## 2. 术语与枚举

| 枚举 | 值 |
|------|-----|
| 课程状态 status | 0 未发布、1 发布中（课程一般不经历，预留）、2 已发布、3 已下架（对齐课件模块口径；原平台 4/5 映射 2/0） |
| 解锁模式 unlockMode | 1 自由学习模式、2 按顺序学习 |
| 解锁单元 unlockUnit | 1 按内容、2 按章节（unlockMode=2 时生效） |
| 课程结构 structureType | 0 无章节、1 有章节（可切换） |
| 任务类型（图标行） | 做：文档1/视频2/音频3/压缩4/SCORM6/HTML7/外链8 + 本地上传；占位：微课5/练习/考试；不显示：讨论/问卷/签署/作业/实战演练 |

权限：沿用菜单级（`kng:course` 权限点，v1.0 已建）；不做数据范围（对齐课件模块拍板）。

## 3. 功能需求

### CS-01 课程列表页
- **功能描述**：`/kng/course`，三栏布局与课件列表**完全同构**（复用 CatalogTreePanel/FilterDrawer/FilterTags/MoreMenu/Pagination 组件）。
- **差异**：①无"类型"列与类型筛选；②更多筛选弹窗**不含**"是否被课程引用"（课程无此概念），保留 是否上架/上传时间/更新时间；③名称列图标=课程封面缩略（无封面用系统默认图）；④状态含 未发布（创建未保存发布的课程也在列表）。
- **接口**：`POST /api/kng/admin/course/list`（结构同课件列表）。
- **验收标准**：
  - Given 左树选分类 When 查询 Then 仅返回该分类课程（口径 radio 生效）
  - Given 存在未发布课程 Then 列表可见该课程，状态灰点"未发布"，操作=编辑/更多

### CS-02 顶部按钮
创建课程（CS-08）；批量操作（上架/下架/移动/删除，同课件实现）；更多筛选（CS-01 差异项）；搜索（名称/分类/上传者）；导出数据不做。全部复用课件管理组件。

### CS-03 详情-基础信息 tab
- 路由 `/kng/course/info/:id`；结构与课件详情同构（label-value + 右侧封面 + 锚点只读四区）。
- **字段**：名称、分类（全路径）、标准时长（**"13 分 20 秒"=任务时长和，后端聚合**）、学分（任务学分和，如 1.33）、平台课程编号、简介、附件（本期仅保留表单/契约兼容，不持久化）、编码、版本；相关方=贡献者；权限=浏览权限；功能=倍速/学时。
- **砍**（对齐课件模块减法）：标签、价格、推荐系数、作者、主讲/辅讲老师、是否隐藏、分享权限、游客访问、完课评论、讨论区、笔记区、下载权限、App保存权限（课件模块编辑表单有此两项但为课件语义，课程表单本就无，详情也不展示）。
- **验收**：Given 课程含 1 个 13分20秒任务 Then 详情标准时长显示"13 分 20 秒"；右上角【编辑】跳 CS-07 step1。

### CS-04 详情-学习详情 tab
- 章节分组表格：章节行"第N章：章节名"（展开/收起）；列=课件名（类型图标）/近7天学习人数（ⓘ）/总学习人数（ⓘ）/操作（查看详情）。
- 顶部灰字说明："仅统计当前课程下各个课件的学习数据，若课件在其他地方被学习，产生的学习数据不在此课程中统计"。
- 无章节课程：任务平铺（无章节行）。
- **接口**：`POST /api/kng/admin/course/{id}/chapter-study-stats`。
- **验收**：Given 课程章节1含课件"V2智能验布机"（近7天2人/总2人）When 打开 tab Then 章节行+课件行数据正确；点查看详情 → CS-05 页。

### CS-05 课件学习详情页（课程内）
- 路由 `/kng/course/courseware-study/:courseId/:coursewareId`；页标题"[课件] 课件名"+← 返回。
- **列**：姓名/账号/所属部门/岗位/学习状态/开始学习时间/完成时间/累计学习时长/完课用时/完课方式/**学习进度(%)**（比课件管理的学习详情多最后一列）。
- **筛选**：所属部门（弹窗：部门树+底部 radio 仅当前部门｜当前部门及后续新增子部门 → hasChild 0/1）、学习状态（已完课/学习中）、完课方式（培训/自学）、姓名/账号搜索。
- **接口**：复用 `POST /api/kng/admin/courseware/{id}/study-records`，请求体加 `courseId`。
- **验收**：Given 学员进度 83.33% Then 学习进度列显示"83.33%"。

### CS-06 详情-学习数据 tab
组件级复用课件详情学习数据 tab（三统计卡/完课用时条形/部门双柱）；接口同构（study-overview/finish-time-overview/dept-first-level/dept-finish-overview，路径换 course）。数据源 kng_study_record（恒空，正常空态）。

### CS-07 编辑课程-第一步（基本信息）
- 路由 `/kng/course/edit/:id/step1`；表单=课件编辑表单复用（**去掉"上传文件"段**；字段/校验/联动/减法清单与课件模块一致：名称必填0/200、分类必填+新增分类入口、封面、标准时长 radio（跟随学分策略｜单独）、学分 radio（跟随时显示实时计算值——**课程跟随时计算值=任务学分和**而非策略折算，因为课程无自身时长）、完课标准下拉 10~100%、简介富文本、附件≤50、编码、版本、贡献者、浏览权限、倍速/学时两级联动）。
- 底部按钮：【暂存关闭】（保存表单+保持当前状态，返回列表）、【下一步】（保存表单 → 设计器）。
- **验收**：Given 修改名称点下一步 Then 表单保存且进入设计器；返回 step1 回显新名称。

### CS-07a 设计器-第二步（章节任务）
- 路由 `/kng/course/edit/:id/designer`（工程内自实现，非独立 SPA）。
- **顶栏**：← 返回 / 章节栏 / 【自由学习模式 ▼】【暂存关闭】【保存】。
- **解锁模式抽屉**（截图10/11）：radio 自由学习模式（默认，"不设学习限制，学员可以在任何时间学习"）｜按顺序学习；解锁单元 radio（按内容[默认]/按章节，仅按顺序学习时可选）；"不参与闯关的任务类型"（话术训练/演讲训练/实战演练）**不做**；【取消】【确定】。
- **章节栏**（structureType=1 时显示）：
  - +添加章节 → 弹窗：章节名称（必填 0/200）+ 章节说明（0/500，至少 5 字）【取消】【确定】（截图12）
  - 章节项：选中高亮；右上 ⋯ 菜单=编辑（同弹窗带回显）/删除（二次确认；有任务连带删任务）
  - 顶栏按钮支持 有章节↔无章节 切换（无→有自动建"章节1"；有→无需确认"切换后任务将平铺"）
  - 章节拖拽排序不做
- **任务类型图标行**：做=文档/视频/音频/scorm/html/外链课 + 本地上传；**占位置灰**（悬浮"功能建设中"）=微课/练习/考试；不显示=讨论/问卷/签署/作业/实战演练。
- **选课件抽屉**（截图13/14）：标题"课程库中的"（知识库选择按钮不做）；筛选=选择课程分类（下拉树）+类型（继承入口点击的类型）+关键词搜索；列表=**已发布**课件（checkbox/名称/状态/学分/时长/过期时间）；"已选择 N/99"（上限 99）；分页 20/页；"全选筛选结果"/"清除所有"；【取消】【确定】→ 勾选课件作为任务加入当前选中章节末尾（无章节=列表末尾）。
- **本地上传**：新窗口打开课件模块发布页（带分类预选）；发布后回设计器手动刷新可见（不做自动监听）。
- **任务列表**（每章节）：
  - 列=类型/名称/学分/时长/状态（取课件状态：绿点已发布/发布中/未发布；转码成功等媒体态文案不做）/操作
  - 操作：👁 预览 → **隐藏确认弹窗**（⚠"确定隐藏此任务吗？已选择任务：xxx" "隐藏后对所有学员不可见"【取消】【确定】，截图18）→ 确认后任务置灰+"已隐藏"标签，再点预览弹窗变"取消隐藏"；**编辑** → 抽屉（课件名称[必填]+选择课件["..."换选]+"编辑课件"链接→嵌套抽屉=课件编辑表单精简版，保存同步任务）；**更多=删除**（确认弹窗）
  - 拖拽排序不做；右上方"包含 N 个任务"
  - **批量操作**：删除任务（确认）/移动任务到章节（弹窗树选择，截图15）
- **保存语义**：【保存】=整体提交（章节结构+任务清单+解锁模式）→ 课程状态=**已发布**，返回列表；【暂存关闭】=保存结构但状态保持**未发布**，返回列表。
- **验收标准**：
  - Given 无章节课程点"视频"图标 When 抽屉勾选 2 个视频课件确定 Then 任务列表追加 2 行，类型=视频
  - Given 隐藏任务"V2智能验布机" Then 该行置灰+"已隐藏"标签；取消隐藏恢复
  - Given 按顺序学习+按章节 When 保存 Then 配置落库且重新进入回显
  - Given 未发布课程点保存 Then 列表该课程状态变"已发布"

### CS-08 创建课程
- 路由 `/kng/course/create/step1`；表单预填"未命名课程"（截图19）；**左树选中分类时分类默认=选中分类**（增补B 同款）。
- 【下一步】→ **立即创建课程记录（status=未发布）** → 跳设计器；首次进入弹"选择要创建的课程结构"（无章节/有章节两卡片+说明文案，截图20）；选无章节=空态"从上方选择任务类型添加任务"（截图21）；后续进入不再弹。
- 未发布课程在列表可见（操作=编辑/更多），可持续编辑直至保存发布。

### CS-09 课程更多菜单
| 菜单项 | 行为 |
|--------|------|
| 隐藏 | 弹窗（同任务隐藏语义）→ 课程行置灰+"已隐藏"标签；可取消隐藏；隐藏≠下架独立标记 |
| 下架 | 同课件：确认弹窗（无倒计时？——课件下架有 2s 倒计时，课程沿用同款弹窗组件）已发布→已下架 |
| 移动 | 抽屉同课件（选目标分类） |
| 删除 | 引用检查（被培训/考试引用阻止）+ 二次确认；删除时**连带清除其全部 kng_ref 任务引用行** |
| 复制 | 副本"xxx-副本"（重名叠加序号）status=未发布；章节+任务结构完整复制（任务指向同一批课件，ref 行同步生成） |
| 下载 | 返回 code=1"课程无源文件"（原平台为打包任务课件，本次不做打包）前端提示 |
| 引用记录 | **占位**弹窗（本模块 kng_ref 已有课程侧数据但被课程引用的场景是培训/考试，仍空态） |

### CS-10 引用联动（kng_ref 正式启用）
- 任务添加 → insert kng_ref（courseware_id/ref_type=1课程/ref_id=课程id/ref_name=课程名快照）
- 任务删除/换选课件 → 删/改对应 ref 行
- 课程删除/复制 → 删源 ref 行/为副本生成 ref 行
- **课件侧生效**：课件"更多-删除"引用检查真实生效（"课件已被课程《xxx》引用，无法删除"）；课件"引用记录"弹窗显示真实列表
- 课件下架/隐藏对已引用任务：任务状态列同步显示课件状态，不阻止
