# 在线课堂课程管理模块 实施记录与偏差

> 日期：2026-10-03 ｜ 配套：01~05 文档 ｜ 实施方式：4 个并行/串行实施批次（后端核心 → 后端操作与设计器 → 前端页面族 → 前端设计器）+ 整合验证
> 验证：后端编译通过、单测全绿（`contextLoads` 因 Nacos/MySQL 网络不可达失败属环境问题）；前端 vue-tsc、vitest 21/21、生产构建通过
> **数据库**：虚拟库与服务器不在同一局域网，04 SQL 未执行、未做库上验证——联调前需先在目标库执行 04（三张新表 + 两列幂等增补）

## 1. 交付清单

### 后端 OnlineClassroom（26 个文件）

- 实体：`KngCourse` / `KngCourseChapter` / `KngCourseTask`（按 04 DDL）；`KngCourseware` +hidden；`KngStudyRecord` +studySchedule
- Mapper：`KngCourseMapper` +XML（列表三查询 + countPlatformNoByPrefix）、Chapter/Task Mapper；`KngStudyRecordMapper` +4 个按课件 id 集合过滤方法（章节统计/学习数据四件套用）
- DTO：`KngCourseDtos`（列表/详情/章节统计/创建/表单保存/设计器读写全家）
- 服务：`CourseService`（列表/详情聚合/章节统计/学习数据四件套/课程内课件学习记录）、`CourseOpService`（创建/表单保存/隐藏/上下架/移动/复制深拷贝/删除/下载/引用记录）、`DesignerService`（结构整体读写、全删全插、ref 重建）、`CourseRefService`（kng_ref 门面）
- 控制器：`CourseController` / `CourseOpController` / `CourseDesignerController`
- 课件增补：hidden 列贯通（实体/列表/详情/hide 端点）；`assertNotReferenced` 升级为 ref_type=1 精确口径 + "课件已被课程《xxx》引用"文案（CS-10 生效点）

### 前端 front-end（约 20 个文件）

- `api/course.ts` 全量接口封装；6 条课程路由（kng:course 权限）
- 页面：`CourseMgmt`（三栏列表，无类型列/未发布灰点/隐藏标签）、`CourseInfo`（三 tab）、`CoursewareStudyInCourse`（学习进度列）、`CourseForm`（两步表单第一步，创建预填"未命名课程"+catalogId 继承）
- 设计器：`CourseDesigner` + 11 个组件（结构选择/章节面板与弹窗/图标行三态/任务表/选课件抽屉/解锁模式抽屉/编辑任务抽屉/嵌套精简课件编辑/移动任务弹窗）
- 课件增补：CoursewareMgmt 更多菜单加"隐藏/取消隐藏"（共用 HideConfirmDialog）、行置灰+"已隐藏"标签、四种发布途径与课程创建均带 `catalogId` query 继承左树选中分类（增补A/B）

## 2. 实现决策（超出/细化文档的部分）

1. **课程平台编号独立序号空间**：格式照 03 文档 `ZXKTyyyyMMddNNNN`，但序号在 kng_course 表内计数（课件同格式序列在 kng_courseware 计数）——两个序列可能产生同号，如需全站唯一改前缀即可（代码已注释）。
2. **学分跟随语义**：有任务=Σ课件 studyScoreCalc；无任务且 studyScore≠null 返回该值；无任务且 null 返回 **null**（课程无 type 字段，课件按类型折算公式不适用——前端创建态显示 0.00，标注待定未编造公式）。
3. **课程学习数据口径**：kng_study_record 无课程维度列，四件套/章节统计以"本课程任务的课件 id 集合"过滤（当前恒空属预期，CS-06 已注明）；studyCount 列表恒 0；studySchedule 列已就位待学员端写入。
4. **设计器保存**：全删全插 + 事务 + ref 重建（02 §5 拍板）；publish=true 且 status=0 → 2；结构切换为纯本地操作（toast"保存后生效"），有→无展平保留任务（附录C 推断项）。
5. **删除引用文案**：课程删除检查实现为"课程已被【ref_name】引用，无法删除"（ref 行无"培训/考试"类型标签，待 ref_type=2 落地方可细分）。
6. **副本语义**：课程复制 status=0、on_sale=1（对齐创建而非课件副本）、hidden=0、章节任务深拷贝（章节 id 重新映射）、ref 重建。
7. **durationText**：0分0秒→空串；仅秒→"N 秒"；仅分→"N 分"；否则"X 分 Y 秒"。
8. **课程表单**：复制精简自 CoursewareForm（非参数化），去掉上传文件段；attachments 仅契约接收不持久化（04 DDL 无课程附件存储列）。
9. **审计字段**：工程无 MetaObjectHandler，updated_at 沿用课件模块显式赋值模式。
10. **Element Plus 使用口径**：当前工程已全量注册 Element Plus；创建课程分类选择使用 `el-tree-select`（支持节点展开/收起），其余设计器布局仍复用现有组件。
11. **结构选择弹窗打通**：CourseForm 创建分支跳设计器携带 `?choose=1`，设计器弹结构选择并在选择后 `router.replace` 清 query 防再弹。
12. **设计器全屏路由**：`/kng/course/edit/:id/designer` 改为顶层路由，不套 `OnlineClassroomLayout` 侧栏与内边距，保证设计器占满视口；结构选择弹窗改为原平台同款纵向卡片布局。
