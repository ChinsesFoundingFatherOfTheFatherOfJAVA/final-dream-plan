## 3. 已确认的产品与代码事实

### 路由

- `/exam/exam-mgmt`：考试列表 + 分类树，替换现有 PlaceholderPage
- `/exam/exam-mgmt/create?examType=onlineExam&catalogId=`：三步创建向导
- `/exam/exam-mgmt/publish?arrangeId=&examId=`：发布配置页，已发布编辑共用
- `/exam/exam-mgmt/detail?arrangeId=&tab=student|question|analysis`：考试详情三 tab
- `/exam/result?ueId=`：答卷详情页
- `/exam/paper/quick?paperId=&arrangeId=`：固定出卷编辑阶段
- `/exam/paper/auto?paperId=&arrangeId=`：随机出卷编辑阶段

### 原站读接口实测

- API 主机：`https://api-phx-ali.yunxuetang.cn`
- 考试列表：`POST /ote/arrange/list`
- 考试详情：`GET /ote/arrange/{id}`
- 发布配置详情：`GET /ote/arrange/detail/{id}`
- 考生列表：`POST /ote/arrange/tracing`
- 已安排学员：`GET /ote/arrange/{id}/examinees/list`
- 部门树：`GET /udp/depts/tree`
- 岗位：`GET /udp/positions`
- 签名记录：`GET /ote/arrange/{id}/list-uem-sign`
- 试题分析：`GET /ote/arrange/{id}/statistics`
- 试题查看：`GET /ote/ques/{examQuesId}`
- 统计分析：`GET /ote/arrange/{id}/analysis`
- 答卷详情：`GET /ote/ue/{ueId}/result/admin/view`
- 随机卷策略：`GET /ote/exam/strategy/{examId}`

原站列表响应是 `{ datas, paging }`；本平台响应必须改成 `ApiResponse{code,message,data}` + `PageResult{records,total}`（ExamService 公共类，**不是** `{list,total,page,size}`；后者只属于 StaffManagement 通知域，见 `09-实施偏差与决策记录.md` D-01），映射放在后端。

关键枚举：

- 考试 `status`：0 未发布、2 进行中、3 已结束
- `auditStatus`：0 未发布、2 审核通过
- 考生 `passed`：0 不通过、1 通过、2 未知
- 考生 `status/userArrStatus`：实测 3 已完成、4 重新考试

禁止把考试 `status` 和考生 `status` 混用。

### 现有前端结构

- 考试/题库/试卷页面位于 `front-end/src/views/exam/`，不是 `views/admin/exam/`。

- 试卷编辑器已有真实路径 `/exam/paper/quick`、`/exam/paper/auto`，优先复用。

## 7. 关键业务规则

### 后端

- 发布考试校验试卷已发布，生成不可变 `exam_paper_snapshot`，更新 `exam_paper_use` 与 `exam_paper.used_qty`。
- 考生唯一性：`arrange_id + user_id` 去重，逻辑删除后重新添加要复活历史行。
- 补考：`retake_used` 行锁，禁止重复；创建 `attempt_no + 1` 的预留 attempt。
- 同步试卷：只更新后续 attempt 的 snapshot，不改历史答卷。
- 分析数据：重算排名、分值、题目统计后才写 `analysis_enabled=1`；失败不改标志。
- 权限：所有写操作后端二次校验，不依赖前端置灰。
- 响应：`ApiResponse{code,message,data}`；本服务分页一律 `PageResult{records,total}`（**不要**写成 `{list,total,page,size}`，见 09 D-01），ID 全 string。
- 错误码按 `04-接口文档.md` §2，不新造重叠码。

### 前端

- 请求走 `src/api/request.ts`，不要绕过统一封装直接 axios。
- ID 全 string，防止 JS 长整数精度丢失。
- 不显示来源列；不显示通知模板 radio；只显示线上考试。
- 状态展示映射：`0 未发布 / 2 进行中 / 3 已结束`。
- 百分比字段 0~1，统一格式化显示。
- 所有抽屉和弹窗复用现有手写组件及其过渡，不引入第二套 UI 库。
