# 测练中心·考试管理复刻 接口文档

> 版本：v1.1 ｜ 日期：2026-10-14  
> Base URL：`http://<gateway>:8080/api/exam`  
> 鉴权：当前工程沿用登录后 JWT，前端请求头 `token: <jwt>`；网关统一校验，业务服务从 `AuthContext` 取当前用户。  
> 响应包裹：`{ "code": 0, "message": "success", "data": ... }`；`code != 0` 为业务失败。  
> 分页：`current`（默认 1）、`limit`（默认 10，可选 10/20/50/100）。**分页响应形状按服务归属区分**：ExamService 的接口（API-01~43、API-46~49）返回 `data = { records, total }`（公共类 `PageResult`）；StaffManagement 的接口（API-44/45，通知域）返回 `data = { list, total, page, size }`（`PageVo`）。依据见 `09-实施偏差与决策记录.md` D-01。  
> 时间格式：`yyyy-MM-dd HH:mm:ss`。  
> 来源说明：已完成原站核心读接口抓包。以下文档定义的是**本平台 `/api/exam` 实现契约**；原站真实路径与字段映射见 `观察素材/抓包/实测接口与字段.md`。

## 0. 与原站实测契约的关系

### 0.1 实测结论

- 原站 API 主机：`https://api-phx-ali.yunxuetang.cn`
- 原站业务前缀：`/ote/`
- 原站列表响应：`{ datas: [], paging: { limit, offset, pages, count } }`
- 本平台保持架构总纲统一契约：`{ code, message, data }`；分页形状按服务归属分两种（ExamService `{records,total}` / StaffManagement `{list,total,page,size}`），见 D-01
- 本平台路径继续走 `/api/exam/**` 网关，不把 `/ote/**` 硬编码进业务服务。

### 0.3 字段名原则

- 读接口字段名优先对齐原站实测：`name/status/auditStatus/entryStartTime/entryEndTime/totalQty/submitQty/passedQty/passRate/principalIds/principalNames`。
- 本平台已有试卷模块使用 `paper`，原站称 `exam`；对外接口仍使用 `paperId`，内部转换。
- 原站 `passed=2` 表示未知/未判定；本平台 `passStatus=-1` 表示未知，转换时映射为 `passed=2`。
- 原站列表分页用 `datas/paging`；本平台 ExamService 返回 `records/total`，StaffManagement 通知域返回 `list/total/page/size`（D-01）。
- 原站 `correctRate/answerQtyRate/passRate` 都是 0~1 小数；前端乘 100 显示百分比。

## 2. 通用错误码

| code | message | 场景 |
|---|---|---|
| 0 | success | 成功 |
| 40001 | 参数校验失败 | 必填项缺失、时间非法 |
| 40002 | 考试不存在 | arrangeId 无效或已删除 |
| 40003 | 无操作权限 | 当前用户不能执行操作 |
| 40004 | 考试状态不允许 | 已结束考试继续安排学员等 |
| 40005 | 试卷不可用 | 试卷不存在或未发布 |
| 40010 | 考试名称不能为空 | 创建/发布校验 |
| 40011 | 入场时间不能早于当前时间 | 创建/发布校验 |
| 40012 | 入场结束时间必须晚于开始时间 | 创建/发布校验 |
| 40013 | 通过分数不合法 | 通过分/比例校验 |
| 40020 | 考生已存在 | 添加学员时可跳过并返回明细 |
| 40021 | 补考只能安排一次 | 补考校验 |
| 40022 | 考生无作答记录 | 同步/补考条件不满足 |
| 40023 | 考生不存在或不在本场考试 | 考生 id 无效或不属于该考试 |
| 40024 | 答卷不存在或已删除 | 答卷 id 无效 |
| 40030 | 通知没有可发送对象 | 考试未安排学员 |
| 40040 | 导出任务创建失败 | 文件系统/参数问题 |
| 40101 | 未登录或 token 过期 | **仅网关**（考试域不再使用 401xx） |
| 40301 | 权限不足 | StaffManagement 权限快照 |
| 50020 | 导出文件生成失败 | POI/PDFBox 异常 |
| 50030 | 试卷快照生成失败 | 试卷数据异常 |
| 50040 | 通知通道不可用 | 通知投递/撤销失败 |

> 考试域（API-01~49）统一使用 `400xx/500xx`；`40101` 只由网关在未登录/过期时返回，
> 避免前端把"考试不存在"误判成"登录失效"。对照见 `09-实施偏差与决策记录.md` D-37。

## 3. 考试分类

### API-01 GET `/arrange/catalog/tree`

- 说明：读取考试分类树。
- 入参：`includeDisabled`（boolean，默认 true）。
- 出参：`data: ArrangeCatalogNode`
- 来源：🤔 设计值，交互对齐试卷模块。

### API-02 GET `/arrange/catalog/{id}`

- 说明：分类详情。
- 出参：单个 `ArrangeCatalogNode` + `createUser`、`createdAt`。

### API-03 POST `/arrange/catalog`

- 说明：批量创建分类。
- 入参：

```json
{
  "parentId": "root",
  "catalogText": "分类A\n 子分类A1",
  "adminUserIds": ["u1"],
  "inheritParentAuth": 0,
  "childInheritCurrentAuth": 0
}
```

- 出参：`{ "createdCount": 2, "errors": [] }`
- 错误：40001、40003。

### API-04 PUT `/arrange/catalog/{id}`

- 说明：编辑分类。
- 入参：`{ "name": "", "adminUserIds": [], "inheritParentAuth": 0, "childInheritCurrentAuth": 0 }`

### API-05 PUT `/arrange/catalog/{id}/move`

- 说明：移动分类。
- 入参：`{ "targetParentId": "uuid" }`
- 规则：目标不能是自身或子孙；层级 ≤10。

### API-06 PUT `/arrange/catalog/{id}/disable`

- 说明：禁用/启用分类。
- 入参：`{ "disabled": 1 }`

### API-07 DELETE `/arrange/catalog/{id}`

- 说明：删除分类。
- 错误：分类下有子分类或考试时 40001。

### API-08 POST `/arrange/list?current=1&limit=10&orderby=createdAt&direction=desc`

- 说明：考试列表。
- 入参：

```json
{
  "queryType": 1,
  "keyword": "",
  "catalogId": "1",
  "routingPath": "",
  "createUserId": "",
  "createUserIds": [],
  "publishStatus": -1,
  "examType": null,
  "arrangeType": -1
```

- `catalogId` + `routingPath`：分类筛选含子分类时，后端按 `routingPath` 前缀解析子树。

### API-09 GET `/arrange/{id}`

- 说明：考试详情。
- 出参：`data: ArrangeDetail`。

### API-10 POST `/arrange`

- 说明：创建考试草稿或直接创建。
- 入参：

```json
{
  "name": "默认考试",
  "catalogId": "root",
  "paperId": "uuid",

```

### API-11 PUT `/arrange/{id}`

- 说明：更新草稿配置，不发布；已发布考试也走同一接口做部分更新。
- 入参：`ArrangePublishForm` 的字段子集。
- 出参：`{}`。
- 已发布允许字段白名单（以 `ArrangeServiceImpl.update()` 实际上写字段为准）：
  `name/important/secrecy/catalogId/entryStartAt/entryEndAt/passScore/passRatio/ownerUserIds/ownerNames/notifySettings/advancedSettings/publishSettings`
- 已发布禁止字段：
  `paperId/paperName/paperBuildType/paperCatalogId/paperSecrecy/paperQuestions/paperStrategy/antiCheatSettings/learningTaskSettings`
- 「使用试卷」发布后锁定：请求携带与当前不同的 `paperId` 返回 `ERR_STATE`（已发布考试不可更换试卷，见 09 D-31）。
- 「获得证书」不接收；旧字段请求忽略。

### API-12 POST `/arrange/{id}/publish`

- 说明：发布考试。
- 入参：`ArrangePublishForm` 可选，若传则先保存再发布。
- 出参：`ApiResponse<Void>`（`data: null`）；发布状态与快照需要重新查 API-09。
- 规则：
  - 校验试卷存在、试卷已发布。
  - 生成 `exam_paper_snapshot`。
  - 更新 `exam_paper_use` 与 `exam_paper.used_qty`。
  - 若已有考生则只更新配置，历史 attempt 不变。
- 来源：✅ 原站实测 `POST /ote/arrange/fast-publish`；真实请求体与响应见 `观察素材/抓包/实测接口与字段.md` §3。
- 原站一次提交基本发布信息 + `examArrangeControl4Put` + `notifyConfig4Put`；响应返回最终 `arrangeId/examId`。

### API-13 PUT `/arrange/{id}/end`

- 说明：结束考试。
- 出参：`{ "publishStatus": 2, "endedAt": "..." }`

### API-14 POST `/arrange/{id}/copy`

- 说明：复制考试。

- 出参：`{ "arrangeId": "new-uuid" }`

- 说明：删除考试。
- 规则：进行中或有作答记录时返回 40004；未发布草稿可直接删除。

## 10. 与试卷模块的联动契约

考试模块不复制试卷接口，调用试卷模块现有能力：

| 用途 | 试卷模块接口 | 考试模块调用点 |
|---|---|---|
| 新建试卷 | `POST /api/exam/paper` | API-10 `paperMode=new` |
| 选择试卷 | `POST /api/exam/paper/list` | 创建向导抽屉 |
| 选择单卷详情 | `GET /api/exam/paper/{id}` | 进入编辑试题前 |
| 发布试卷 | `PUT /api/exam/paper/{id}/release` | 考试发布前校验/发布（返回 `ApiResponse<Void>`，试卷 status 置 4） |
| 固定出卷编辑 | `/exam/paper/quick?paperId=` | 创建向导第二步 |
| 随机出卷编辑 | `/exam/paper/auto?paperId=` | 创建向导第二步 |
| 导入试卷 | `POST /api/exam/paper/import` | 创建向导导入方式 |

考试发布后新增或更新 `exam_paper_use`，让试卷管理的引用次数能显示本考试。

## 11. 与学员端答题模块的联动契约

本模块提供消费接口，不实现答题页：

| 用途 | 接口 | 说明 |
|---|---|---|
| 学员考试列表 | 由学员端模块提供 | 读取 `exam_arrange_student` |
| 开始考试 | 由学员端模块提供 | 创建/更新 `exam_attempt`，绑定 `snapshot_id` |
| 提交答卷 | 由学员端模块提供 | 写 `exam_attempt_answer`，更新 `exam_arrange_student` 和 `exam_attempt` |
| 通知列表 | API-44 | 通用通知服务提供，ExamService 只发事件 |
| 标记已读 | API-45 | 通用通知服务提供 |
| 成绩/排名 | API-36/37/38 管理端只读 | 学员端是否可见取决于 `advancedSettings.answerView` 和 `analysis_enabled` |
