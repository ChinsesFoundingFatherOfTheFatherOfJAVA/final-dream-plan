## 三、升级后第一件事的建议

**先恢复验证能力，再继续写代码。** 顺序：

```
1. 确认 Bash 可用（随便跑个 echo 或 ls）
2. npm run type-check → 拿到真实报错清单
3. mvnw.cmd -o -q -DskipTests compile → 确认后端能编译
4. 跑数据库迁移
5. 重建团队继续
```

不要跳过第 2、3 步直接让人写代码——刚才就是因为验证失效才停的。
