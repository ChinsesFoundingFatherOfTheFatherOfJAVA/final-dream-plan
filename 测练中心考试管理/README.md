## 明确不做的范围

- 线下考试。
- 通知模板的默认/个性模板细分。
- 考试列表「来源」列。
- 添加学员的多筛选模式 tab。
- 在考试模块重写试卷编辑器。

## 关键设计决策

- 考试创建/编辑试卷阶段复用现有试卷管理模块。
- 发布考试时生成试卷快照，历史答卷不受后续试卷修改影响。
- 变更通知生成 `exam_change_notice` 与学员维度记录，学员端通过接口读取。
- 统计与正确率走聚合表，不在每次查询时扫描全量答卷。
- 已完成核心读接口抓包；本平台接口字段按实测语义映射，写接口 payload 仍标记为设计/待继续补采 🤔。
