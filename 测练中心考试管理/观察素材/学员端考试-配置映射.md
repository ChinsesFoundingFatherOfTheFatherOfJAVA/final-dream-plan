# 观察记录：考试配置项 → 学员端行为映射

> 来源：`train.chinajack.com/ote/#/quickexam/publish/exam?arrangeId=d385dba2-...`
> 目的：把管理端已有配置（`exam_arrange` + `advancedSettings`）与学员端实际行为一一对应，
> 作为学员端契约的依据。**未验证的项标 ⏳，已验证的标 ✅。**

## A. 基本信息

| 配置项 | 取值 | 对学员端的影响 | 状态 |
|---|---|---|---|
| 考试名称 | 文本 | 学员 Entrance/答题页标题 | ✅ 已见 |
| 重要考试 | 勾选 | 待确认（推测列表里打「重要」标） | ⏳ |
| 是否保密 | 开关 | 仅创建者/负责人/超管可见——**学员端不可见**，属管理端可见性 | ✅ 语义明确 |
| 考试分类 | 树选择 | 管理端分组，学员端不体现 | ✅ |
| 编号 | 文本 | 管理端用 | ✅ |
| 循环考试 | 开关 | 开启后按周期发放 | ⏳ |
| 入场时间 | 起止 | 入场页「入场时间」文案；不在区间内不能考 | ✅ 已见 |
| 是否必修 | 必修/选修 | 待确认（推测待学习列表标记） | ⏳ |
| 通过分数 | 固定分数 / 总分比例 | 入场页「通过分数」；结果页通过判定 | ✅ 已见 |
| 优秀分数 | 固定分数 / 总分比例 | 入场页「优秀分数」 | ✅ 已见 |
| 学员奖励 | 学分/积分/证书 × 考试归档后/考试通过后 | 通过后发放，学员端个人中心可见 | ⏳ |
| 参与人员 | 内部人员/指定员工/全员/游客 | 决定谁能看到这场考试 | ✅ 语义明确 |
| 批阅人 | 创建人/部门经理/直属经理/指定/定向 | 影响主观题批阅，学员端看「考试批阅」状态 | ✅ 已见（首页出现「考试批阅」标签） |
| 考试说明 | 富文本 | 待确认展示位置 | ⏳ |
| 通知设置 | 安排/取消/批阅/成绩下发通知 + 定时消息 | 走通用通知通道，学员端消息中心 | ⏳ |

## B. 更多设置

### B1. 考试设置

| 配置项 | 取值 | 对学员端的影响 | 状态 |
|---|---|---|---|
| 统一交卷时间 | 时间点 | 到点统一收卷 | ⏳ |
| 统一考试时长 | 时长 | 等于「考试限时」，倒计时 | ⏳ |
| 最短答题时长 | 时长 | 未到时长不能交卷 | ⏳ |
| 考试时长包含中途退出时间 | 开关 | 退出后是否继续计时 | ⏳ |
| 允许重复考试次数 | 不限次 / 限制次数 | 入场页「考试次数 X/Y 次」 | ✅ 已见 |
| 全部答完才能交卷 | 开关 | 交卷拦截（对应 `control4Stu.allowSubmitAllFinish`） | ✅ 接口已见 |

| 允许学员提交题目反馈 | 开关 | 每题反馈入口（`questionFeedbackEnabled`） | ✅ 接口已见 |
| 定时发布考试 / 定时结束考试 | 时间 | 到时自动开/关 | ⏳ |
| 答题错误将自动进入错题本 | 开关 | 错题本联动 | ⏳ |

### B2. 批阅设置

| 配置项 | 影响 |
|---|---|
| 批阅时隐藏考生信息 | 管理端批阅页 |
| **填空题自动批阅** | **决定填空是否即时出分，还是转人工** |
| **问答题自动批阅** | **决定问答是否即时出分（关键词判分），还是转人工** |
| 用户未作答不自动批阅 | 空答不进批阅队列 |
| 允许问答题智能批阅 | AI 判分开关 |

> 这四项直接决定学员交卷后是「立即出分」还是「等待批阅」。**核心映射点**。

### B3. 答卷设置（对应 `finished` 接口的 viewResult* 字段）

| 配置项 | 对应字段 | 学员端效果 |
|---|---|---|
| 允许学员查看考试成绩 | `viewResult` | 总开关，关掉则看不到结果 |
| 允许学员查看考试分数 | `viewResultScore` | 显不显示得分 |
| 允许学员查看是否通过标识 | `allowViewResultPassed` | 显不显示通过/未通过 |
| 允许学员查看考核点得分情况 | `viewResultPoint` | 显不显示按考核点得分 |
| 允许学员查看考试答卷详情页面 | `allowViewResultDetail` | 能不能看答卷（逐题对错） |
| 仅支持学员查看错题 | — | 详情页只显示错题 |
| 允许学员查看考题答案 | — | 显示标准答案 |
| 允许学员查看考题解析 | — | 显示解析 |
| 允许查看答卷时间范围 | 不允许 / 考试通过后 / 考试结束后 / 限制时间内 | `allowViewResultDetailType` + Start/EndTime |
| 不允许学员下载PDF答题结果 | 开关 | 详情页无导出 |
| 考试通过后查看 / 考试结束后查看 / 限制时间内查看 | — | 即上面的时间范围枚举 |

## C. 对学员端契约的关键结论

1. **学员端几乎所有可见性都由 `advancedSettings` 控制**，不能写死。结果页要按 `finished` 返回的
   `viewResult*` 系列字段决定渲染什么。
2. **作答样式有两种**（一页 / 单题分页），必须作为配置读取，不能只做一种。
3. **是否即时出分**取决于填空/问答自动批阅开关，学员端要能表达「待批阅」状态。
4. 防作弊项多，首期需要和用户确认做哪些（切屏限制、人脸核验成本最高）。
