# 观察记录：绚星云学习 OTE 的考试管理

> 模块名：测练中心·考试管理复刻  
> 观察时间：2026-10-14  
> 来源：`https://train.chinajack.com/ote/#/arrange/mgmt` 及其关联页面  
> 观察方式：用户材料（62 条浏览器标注 + 62 张带标记截图 + 用户逐条文字说明）+ 已授权 Playwright 只读抓包  
> 抓包状态：已完成核心读接口采样，未执行写操作；生产 JS chunk 已下载用于接口路径核对。  
> 实测明细：`抓包/实测接口与字段.md`、`抓包/live-capture.json`。

## 复现路径

1. 管理端进入「测练中心」。
2. 左侧选择「考试管理 > 考试管理」，进入原平台 `/ote/#/arrange/mgmt`。
3. 列表页查看考试分类树、考试列表、筛选与操作。
4. 点击「创建考试」，原平台先弹出线上/线下类型选择；本轮仅观察并复刻「线上考试」。
5. 线上考试创建流程共三步：`创建试卷 → 编辑试题 → 发布考试`。
6. 点击考试名称或操作列「管理」，进入考试管理页；页内有「考生情况 / 试题分析 / 统计分析」三 tab。
7. 点击页头「编辑」，进入 `/ote/#/quickexam/publish/exam` 发布配置页。
8. 考生列表点击「答卷」，进入 `/ote/#/examresultdetail?ueId=...` 查看答卷。

## A. 界面结构

### A1. 考试管理列表页

- 左侧为考试分类树；顶部有关键字搜索、创建分类、更多操作入口；底部为「包含子分类 / 仅当前分类」单选。✅📸
- 右侧顶部按钮为「创建考试」「批量操作」；下方筛选有全部考试、创建人、考试类型、考试状态、安排方式；第二行为考试名称/编号/创建人搜索与「导出数据」。✅📸
- 表格字段：考试名称、考试类型、考试状态、入场时间、创建人、创建时间、负责人、来源、安排人数、已交卷、已通过、通过率、操作。用户明确本轮排除「来源」。✅🧑
- 操作列每个考试显示「管理 / 更多」；未发布考试在更多菜单前有「发布」。✅📸
- 操作列右侧齿轮控制列显隐与排序。✅📸

### A2. 创建考试流程

- 「创建考试」后先选考试类型，原平台有「线上考试 / 线下考试」两张卡；本轮只做线上。✅📸
- 步骤条固定为三步：`创建试卷`、`编辑试题`、`发布考试`，右上角有「上一步」和「发布 / 更新后发布」。✅📸
- 创建试卷支持三种方式：`创建新试卷`、`选择试卷`、`导入试卷`。✅📸
- 创建新试卷时表单包含：试卷名称、试卷分类、出卷方式（固定/随机）、试卷保密。✅📸
- 选择试卷打开抽屉，左侧试卷分类树，右侧试卷列表，字段含试卷名称、出卷方式、创建人、更新日期、操作。✅📸
- 导入试卷打开「快速出卷」抽屉：下载模板、选择题库、选择/保密、上传 Excel。✅📸
- 随机出卷进入试卷策略矩阵编辑；固定出卷进入题型/大题画布编辑；这两种编辑页的用户要求是对齐现有试卷管理模块。✅🧑

### A3. 发布考试配置页

- 顶部为三步步骤条和保存按钮，主体为左右两栏。✅📸
- 左栏「基本信息」：考试名称（1000 字）、重要考试、是否保密、考试分类、编号、循环考试、入场时间、是否必修、通过分数、学员奖励等。✅📸
- 右栏「通知设置」：发送考试安排通知、发送考试安排取消通知、发送试卷批阅通知、成绩下发通知、定时消息设置。✅📸
- 用户明确通知设置不做「默认模板 / 个性模板」细分。✅🧑
- 页面下半部分「更多设置」：允许题目反馈、定时发布、定时结束、错题进错题本、考前签名确认、固定 IP；批阅设置；信息安全设置；学习任务限制；答卷设置；团队管理设置。✅📸

### A4. 考试管理页

- 头部「基本信息」：考试分类、考试状态、入场时间、试卷总分、发布时间、考试链接、创建人、使用试卷、考试二维码；来源字段仍出现但本轮不需要作为列表筛选项。✅📸
- tab：`考生情况`、`试题分析`、`统计分析`。✅📸
- 考生情况工具栏：添加学员、安排补考、同步试卷、分析数据、更多操作、导出、签名记录。✅📸
- 筛选：账号状态、考试状态、通过状态、加入方式、选择部门、选择岗位、开考开始时间、开考结束时间。✅📸
- 考生表格字段：账号、姓名、账号状态、部门、岗位、加入方式、考试状态、开考时间、交卷时间、加入考试时间、IP 地址、答题时长、成绩、最高分第几次考、切屏次数、提交方式；操作列为「答卷 / 更多」。✅📸
- 列表右侧齿轮打开字段设置，可勾选显隐并拖拽字段顺序。✅📸

### A5. 试题分析与统计分析

- 试题分析：导出数据、题型筛选、难度筛选、试题名称搜索；表格列含试题名称、题型、难度、答题次数、答对次数、正确率、答题详情。✅📸
- 点击试题名称打开「试题查看」抽屉；点击答题详情打开「答题详情」抽屉，展示选项人数与比例。✅📸
- 统计分析：参与人数/参与人次/通过率/优秀率四张统计卡；分值统计含试卷总分、通过分数、优秀分数、最高分、最低分、平均分、平均耗时；正确率柱状图可按题型、难度、考核点切换。✅📸

### A6. 答卷详情

- 顶部为学生与试卷摘要；右上角「导出 pdf」。✅📸
- 正文按大题分节，题目显示题干、选项、考生选择、正确答案、考点、解析。✅📸

## D. 动效与风格

- 框架风格：Element 系后台；抽屉从右向左滑入，弹窗居中缩放淡入淡出，时长约 200–300ms。🤔
- 表格行 hover 有浅灰背景；操作列链接使用主色蓝。✅📸
- 主色近似 `#1890ff`，成功/进行中为绿色或蓝色状态点，未发布/结束为灰色状态点；背景为浅灰 `#f5f7fa`，内容卡片白色。🤔📸
- 卡片圆角约 4–8px；输入框/按钮小圆角。🤔📸
- 页面标题 20–22px，卡片标题 16px，正文 14px，辅助文字 12–13px。🤔📸
- 图标以线性工具图标为主；分类树和表格操作使用齿轮、更多、搜索、加号等常规图标。✅📸
- 拖拽字段排序、树节点展开收起、抽屉叠加需要保留过渡但与主流程相比属于次级体验。🤔

## E. 技术线索与推断

- ✅ 原站为 hash 路由 SPA，URL 形如 `/ote/#/arrange/mgmt`、`/ote/#/examresultdetail?ueId=...`。
- ✅ DOM 类名大量使用 `yxt-` 前缀，如 `yxt-table`、`yxt-drawer`、`yxt-picker-panel`、`yxt-select-dropdown`，更像自研组件库或深度封装组件库。
- ✅ 运行时实测：Vue `2.6.12`，`YXTBIZ` 组件库 `2.0.29`，`YXTPC` `2.7.77`，应用 `otepc`，业务版本 `7.5.001-deploy`。
- ✅ 已完成核心读接口抓包：真实 API 主机、路径、字段命名、分页参数、考试状态枚举已确认；鉴权头只确认存在并已从抓包文件中剔除。
- ✅ 原站多个状态筛选下拉、分页、抽屉、日期时间选择器均呈现 Element 系交互。
- 🤔 试卷创建/编辑页大概率直接依赖原平台试卷模块的实体与接口；复刻时应通过现有试卷模块复用，不复制一套纸卷数据模型。

## F. 抓包记录

已在用户授权后，通过复制 Chrome 用户资料到临时目录，并用 Playwright 独立 Chrome 实例复用登录态进行只读采样。没有输入账号密码，没有绕过鉴权，没有提交写操作。

- 真实 API 主机：`https://api-phx-ali.yunxuetang.cn`
- 已采样：考试列表、考试详情、发布配置详情、考生列表、已安排学员、部门树、岗位、签名记录、试题分析、试题查看、统计分析、答卷详情、随机卷详情/策略、分类树、考试短链。
- 未提交：创建、发布、结束、删除、复制、添加/移除考生、通知、导入、导出。
- 真实请求/响应保存在 `抓包/live-capture.json`；敏感鉴权头已剔除。
- 生产 JS chunk 保存在 `抓包/js/`，用于提取未实际触发的写接口路径。
- 实测字段、枚举、分页形状及与原设计的映射见 `抓包/实测接口与字段.md`。

关键实测结论：

- 列表/考生/试题统计使用 `{ datas, paging }`，不是 `{ list, total, page, size }`。
- 考试状态实测值为 `0 未发布 / 2 进行中 / 3 已结束`；审核状态为 `0 未发布 / 2 已通过`。
- 考生筛选字段为 `status / passed / userStatus / joinMethod`，不是 `examStatus / passStatus`。
- 试题分析使用 `quesType / submitQty / correctQty / correctRate`。
- 统计分析使用 `baseInfo / scoreInfo / accuracyRate` 三段结构。
- 答卷详情路径为 `/ote/ue/{ueId}/result/admin/view`。
- 写接口路径已从生产 JS 中找到，但未发请求提交，payload 仍需实现时以业务表单和现有字段映射为准 🤔。
