# 抓包记录

已获得用户授权，并完成核心读接口采样：

- `live-capture.json`：考试管理核心页面的真实请求/响应。
- `实测接口与字段.md`：字段、枚举、分页、接口映射和差异结论。
- `js/`：原站生产 JS chunk，用于提取未提交的写接口路径。
- `write-probes.json`：写接口拦截探针结果；本次未产生有效写请求，也未修改原站数据。

采样原则：

- 只读页面与 XHR/Fetch。
- 不输入账号密码、不绕过鉴权。
- 不提交考试、删除、复制、通知、导入等写操作。
- 不保存 Cookie、Authorization、token 等敏感头。

后续如需补写接口 payload，可继续通过路由拦截或页面 JS 注入拦截，不实际提交原站写请求。
