## 0. 比例证明：截图像素 = CSS 像素（1:1）

不能假定截图是 1:1，否则整套数值都会差一个缩放系数。用文档里已有的 DOM 实测值反校：

| 交叉验证项 | 文档里的 DOM 实测 | 本文从截图像素测得 | 结论 |
|---|---|---|---|
| 签名 canvas | `getBoundingClientRect` 472×266 | **472×264** | 宽度完全吻合，高度差 2px（测量噪声） |

**结论：截图为 1:1 CSS px。** 后续所有像素读数可以直接当 CSS 值用。
高度取截图值 472×264（更保守，且与宽度同源测量）。
