## 1. 项目概述

复刻绚星云学习平台的「AI实战训练场」应用的**管理端**部分。本次范围界定遵循以下原则：

1. **只做「训练主题」菜单**：左侧菜单中「数据分析、素材库、设置」三个菜单仅做占位展示，不做交互逻辑。
2. **AI 相关功能全部不做**：创建新主题（AI 助手生成）、「通过 AI 助手添加」场景单元、AI 设计助手按钮等仅展示入口，不实现逻辑。原因：AI 功能点与其他功能耦合度低，且调用会产生费用，后续单独迭代。
3. **强依赖人员信息的功能只占位**：学员管理、数据分析真实查询、统计板块等因人员信息功能尚未实现，本次只做 UI 结构与视觉，数据库留占位字段。
4. **人工可改的部分做真实逻辑**：主题列表查询、主题详情展示、暂停/结束、主题设置五表单的保存与版本管理（保存后版本+1 成为当前版本；回滚=切换当前版本指针）。

## 2. 术语与角色

| 术语 | 含义 |
|------|------|
| 训练主题 | 一套完整的实战训练项目，含场景单元、训练配置、版本记录 |
| 场景单元 | 主题下的一次业务场景演练，如"初次拜访：系统定位与六大场景全景介绍" |
| 评估维度 | 场景单元评估标准下的评分项，含名称/权重/解释/三档评分标准 |
| 版本 | 主题设置的每次整体保存产生一个新版本；当前版本指针决定生效配置 |
| 主题模式 | 日常训练 / 通关考核 / 训考一体，由演练模式开关组合推导 |
| 管理员 | 当前唯一操作角色（登录/权限体系不在本次范围，沿用现有前端会话） |

**状态机（发布状态）**：`0草稿 → 1发布中 → 2发布失败 / 3已发布`；`3已发布 ⇄ 4已暂停`（暂停可恢复）；`3/4 → 5已结束`（终态，不可逆）。

#### FP-04 五个筛选条件

- **功能描述**：列表上方筛选栏含五个条件，全部展示：

| # | 筛选项 | 选项 | 前端是否传值 |
|---|--------|------|--------------|
| 1 | 归属 | 我管辖的 / 我负责的 | **不传**（占位展示） |
| 2 | 状态 | 所有状态 / 草稿 / 发布中 / 发布失败 / 已发布 / 已暂停 / 已结束 | 传 |
| 3 | 模式 | 所有模式 / 日常训练 / 通关考核 / 训考一体 | 传 |
| 4 | 来源 | 单独安排 / 项目安排 | **不传**（占位展示） |
| 5 | 关键词 | 按主题名称搜索（placeholder"搜索主题..."） | 传 |

- 条件 1、4 虽前端不传值，但**后端查询参数实体和主题表必须有这两个字段**（jurisdictionType / sourceType），供后续迭代启用。
- **证据**：截图 02；用户描述 3.1。
- **验收标准**：
  - Given 列表页渲染 Then 五个筛选控件全部可见，默认值分别为：归属无选中（或"我管辖的"）、"所有状态"、"所有模式"、来源无选中、关键词为空
  - Given 选择状态=已发布 When 触发查询 Then 列表仅展示 status=已发布 的主题
  - Given 选择模式=训考一体 When 触发查询 Then 仅展示 theme_mode=训考一体 的主题
  - Given 输入关键词"柔性" When 触发查询 Then 仅展示名称含"柔性"的主题
  - Given 变更归属/来源筛选值 When 触发查询 Then 前端不将该值加入请求参数（占位不传）

#### FP-05 主题卡片列表

- **功能描述**：以卡片网格展示主题，每张卡片：标题、状态徽章（右上角，绿色=已发布等颜色映射）、主题描述（超长省略）、两个标签（主题模式标签绿色 + 来源标签灰色）、底部统计行"学员 N 人 · 更新时间"。卡片点击进入主题详情。列表底部展示"已加载全部数据"（无分页器，一次全量或简单分页加载均可，后端仍提供分页参数）。
- **证据**：截图 02（三张卡片：柔性智造销售话术训练/低绩效员工沟通管理/智能仓储销售演练）。
- **验收标准**：
  - Given 后端返回 N 条主题 When 列表渲染 Then 展示 N 张卡片，字段映射正确
  - Given 点击任一卡片 Then 跳转 `/sparring/freesimulate/theme/{id}`
  - Given 无数据 Then 展示空状态提示

#### FP-06 列表查询后端接口

- **功能描述**：分页查询主题列表，支持 status/themeMode/keyword 过滤；查询实体含 jurisdictionType/sourceType 占位字段（接收但不参与过滤或参与过滤均可，字段必须在）。
- **验收标准**：
  - Given 任意筛选组合 When 调用接口 Then 返回 `{code:0, data:{total, records}}` 结构，records 字段含 id/themeName/themeDesc/status/themeMode/sourceType/participantCount/updatedAt

### 3.3 主题详情页（上半部）

#### FP-07 主题信息展示（真实数据）

- **功能描述**：详情页头部展示：

  - 主题名称（大标题）+ 四个徽章：发布状态（已发布绿）、分配模式（指定分配蓝/全体学员）、难度等级（★★正常，星级+文字）、主题模式（日常训练紫/通关考核/训考一体）
  - 主题描述、创建时间、更新时间
- **证据**：截图 03、04。
- **验收标准**：
  - Given 打开详情页 When 渲染 Then 名称/描述/创建时间/更新时间与数据库当前版本一致，四个徽章按枚举正确渲染（难度：★☆☆简单/★★☆正常/★★★困难）
  - Given 点击面包屑「训练主题」Then 返回列表页

#### FP-08 四个统计板块（只展示，DB 占位）

- **功能描述**：头部下方四张统计卡：
  1. 主题通过率：大数字+N%，底部进度条，脚注"通过 N 人 / 参与 N 人"
  2. 场景单元：N 个（此值由当前版本场景单元数实时统计）
  3. 平均得分：N 分
  4. 训练总次数：N 次
  通过率/参与人数/平均得分/训练总次数为**占位字段**（act_theme 表存值，前端直接展示）；场景单元数实时 count。每卡右上角 ⓘ 图标（占位）。
- **证据**：截图 03、04；用户决策"只展示不做真实逻辑但数据库表要有字段占位"。
- **验收标准**：
  - Given 详情数据返回 When 渲染 Then 四卡展示后端返回值；场景单元数=当前版本场景单元 count
  - Given 数据库占位字段为空/0 Then 展示 0%/0 个/0 分/0 次（不报错）

#### FP-09 五个操作按钮

- **功能描述**：

| 按钮 | 处理 |
|------|------|
| 暂停 | **真实逻辑**：已发布状态下点击 → 确认弹窗 → 状态变为已暂停，按钮变为"恢复"；已暂停时点击 → 恢复为已发布 |
| 结束 | **真实逻辑**：已发布/已暂停下点击 → 确认弹窗 → 状态变为已结束（终态），此后暂停/结束按钮禁用 |
| 分享 | 只展示，点击弹"功能建设中"提示 |
| 导出报表 | 只展示，点击弹"功能建设中"提示 |
| AI 设计助手 | 只展示（蓝色主按钮），点击弹"功能建设中"提示 |

- **证据**：截图 03、04；线上确认弹窗（确认暂停/确认结束）。
- **验收标准**：
  - Given 主题为已发布 When 点击「暂停」并确认 Then 状态变为已暂停，头部徽章与列表同步更新，按钮变为「恢复」
  - Given 主题为已暂停 When 点击「恢复」并确认 Then 状态回到已发布
  - Given 主题为已发布或已暂停 When 点击「结束」并确认 Then 状态变为已结束，暂停/结束按钮禁用
  - Given 主题为已结束 When 再次进入详情 Then 不可暂停/恢复/结束
  - Given 点击分享/导出报表/AI设计助手 Then 仅提示，无业务动作

#### FP-11 场景单元管理（只读展示）

- **功能描述**：顶部左侧"共 N 个场景单元"，右侧蓝色链接「+ 通过 AI 助手添加」（占位，点击提示"功能建设中"）。场景单元列表：
  - **收起态**：紫色序号徽章 + 名称（"A：B"格式）+ 适用人群标签（紫）+ 时长标签（橙，"N 分钟"）+ 右侧「展开 ⌄」
  - **展开态**：在收起态基础上依次展示（每个区块带彩色底色面板，配色参照截图 05）：
    1. 业务目标（浅蓝紫面板）
    2. 关联冰山模型要素（标签云，多个彩色 pill）
    3. 业务影响（绿）与 失败代价（红）左右两栏
    4. 核心冲突（粉红全宽）
    5. 常见失败模式（红，列表）与 困难挑战（红，列表）左右两栏
    6. 禁止行为（红，× 前缀列表）与 时间限制（紫，"N 分钟"）左右两栏
    7. 评估标准：标题旁标注「通过分 N」（存于场景单元表 pass_score）。下方维度列表，每个维度含：维度名称、权重百分比（蓝色进度条+右侧百分数）、维度解释、三档评分标准（优秀 90-100 分：解释 / 良好 70-89 分：解释 / 需改进 <70 分：解释）
  - 同一主题下**各场景单元的维度列表可以不一样**（维度表按场景单元存储，非主题级复用）。
  - 场景单元内容由 AI 助手维护（本次无编辑入口，纯只读）。
- **证据**：截图 05（场景单元 1 展开全貌）、用户描述 4.1.3。
- **验收标准**：
  - Given 当前版本有 5 个场景单元 When 渲染 Then 列表展示 5 项，"共 5 个场景单元"
  - Given 点击某单元「展开」Then 展示 13 项完整内容（业务目标~评估标准），权重百分数与后端一致
  - Given 点击「收起」Then 回到收起态（仅序号/名称/适用人群/时长）
  - Given 两个场景单元配置了不同维度列表 When 分别展开 Then 各自渲染各自的维度
  - Given 点击「+ 通过 AI 助手添加」Then 仅占位提示

#### FP-18 保存与版本机制

- **功能描述**：主题设置页五个分区**共用底部一个「保存设置」按钮**（这五个表单即人工可修改的全部范围；场景单元管理 Tab 内容由 AI 助手维护，本页不含）。任一分区修改后点保存 = 五个分区**整体保存** → 创建一条新的主题版本记录（version_no = max+1，复制五个表单全部字段）→ 主题表 current_version_no 指向新版本 → 场景单元数据**复制到新版本**（内容不变，保证回滚与后续 AI 修改的版本隔离）→ 主题表冗余字段（theme_name/theme_mode/assign_mode/difficulty/updated_at）同步。「取消」= 放弃修改回到当前版本值。
- **证据**：用户原话确认"主题设置tab下的五个大表单公用一个保存"；线上行为。
- **验收标准**：
  - Given 修改任一分区字段 When 点「保存设置」Then 返回成功，详情页头部信息与版本号 tab 徽标同步+1，「版本历史」Tab 新版本出现在最顶部并带「当前版本」徽章
  - Given 修改后未保存 When 点「取消」或切换分区/Tab Then 修改丢弃（重新进入表单恢复当前版本值）
  - Given 保存 When 后端处理 Then 新版本的场景单元与维度数据完整（数量、内容与旧版本一致）

#### FP-19 版本历史

- **功能描述**：说明行"查看主题的完整版本历史，了解每次更新的内容和影响范围"。版本卡片列表，**越靠上版本越新（按版本创建时间倒序，回滚不改变排序）**。每张卡片：
  - 左上：版本号（加粗大数字）；当前版本带「当前版本」蓝色徽章
  - 右上：版本创建时间（yyyy-MM-dd HH:mm:ss）
  - 中部三列统计：使用人数 / 已完成（绿）/ 进行中（蓝）——**只展示不做逻辑**（读版本表占位字段）
  - 左下：创建者：管理员（写死）
  - 右下：非当前版本展示「回滚到此版本」按钮（蓝描边）；当前版本无按钮
- **回滚**：点击 → 确认弹窗 → **将主题表 current_version_no 切换为该版本号**（不产生新版本号，不修改版本记录本身；各版本单独一条记录，回滚即切换指针）→ 详情页头部信息、场景单元、主题设置、内容概览全部按新当前版本呈现；版本列表排序不变。
- **证据**：截图 09；用户决策 6。
- **验收标准**：
  - Given 主题有 v1/v2 When 打开版本历史 Then v2 在上（当前版本徽章），v1 在下（带回滚按钮）
  - Given 点击 v1 的「回滚到此版本」并确认 Then current_version_no=1；头部/表单/场景单元/内容概览均展示 v1 内容；版本列表顺序不变，v1 变为当前版本
  - Given 回滚后 When 再次保存设置 Then 产生 v3（=v1 内容的副本+本次修改），成为当前版本，排序仍在最上
  - Given 回滚后 When 查看学员管理与数据分析 Then 行为不变（占位/mock）

#### FP-20 数据分析（结构+视觉，mock 数据）

- **功能描述**：左侧「场景单元」菜单（当前版本的场景单元列表，01~05 序号+名称，点击切换），右侧固定结构：
  - **总体概览**：三卡——已练习学员 N / M、练习总次数 N 次、场景通过率 N%（脚注"通过 N / 参与 N"）。口径：统计全部历史版本、次日更新（文案提示照线上）。
  - **统计范围**：三选一 segmented：最近一次（默认）/ 首次 / 全部记录。只作用于下方总分分布/维度掌握情况。
  - **总分分布**：五段横向条形（<60 / 60-69 / 70-79 / 80-89 / 90-100）+「均分 N 分」。口径为首次/最近一次时单位是**人**；全部记录时单位是**百分比**（条形与数字都随口径切换）。±n 增减标记（与首次相比）。
  - **维度掌握情况**：仅展示**当前版本**该场景单元配置的维度（从场景单元接口取维度列表）。每维度一行：维度名 + 均分 + 三档（<70 / 70-89 / 90-100）分布条（人/百分比随口径）。无练习数据的维度显示"该维度暂无练习数据"。
  - **维度掌握变化**：表格（维度 / 首次 → 最近 / 变化幅度条），"未练第 2 次"标记、"该维度暂无练习数据"态。
  - **实现方式**：全部用**前端固定 mock 数据**驱动（三口径切换、菜单切换、图表联动均可见效果），不调后端接口。mock 数据需覆盖：有数据维度、无数据维度、未练第 2 次、三口径差异等形态。
- **证据**：截图 12；用户提供的官方口径说明（全部照录于 4.1.7，实现时文案以此为准）。
- **验收标准**：
  - Given 打开数据分析 Then 左侧列出当前版本全部场景单元，默认选中第 1 个
  - Given 切换左侧场景单元 Then 右侧整体数据刷新（mock 联动）
  - Given 切换统计口径为"全部记录" Then 总分分布/维度掌握的单位变为百分比；切回"首次/最近一次"则为人
  - Given 某维度无数据 Then 维度掌握情况显示"该维度暂无练习数据"，维度掌握变化同行显示同文案
  - Given 版本回滚/保存 When 重新进入数据分析 Then 左侧菜单与维度列表跟随当前版本
