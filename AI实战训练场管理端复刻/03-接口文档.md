# AI实战训练场（管理端）复刻接口文档

> 版本：v1.0 ｜ 日期：2026-09-16 ｜ 服务：AtualCombatTraining（端口 8082，经网关访问）
> 配套：01-需求文档.md、02-技术实现方案.md

---

## 1. 通用约定

- **Base URL**：`http://localhost:8080/api/act`（网关 8080 将 `/api/act/**` 转发至 `lb://AtualCombatTraining`；服务内 Controller 路径以 `/api/act` 开头）
- **鉴权**：无（与 SpeechTraining 现状一致，登录体系不在本次范围）
- **统一响应结构**：

```json
{ "code": 0, "message": "success", "data": { } }
```

- `code=0` 成功；`code=1` 业务失败（message 为用户可读中文，如"主题已结束，无法操作"）
- **分页参数**：`page`（从 1 起）、`pageSize`（默认 10）
- **时间格式**：`yyyy-MM-dd HH:mm:ss`（字符串）
- **ID 约定**：所有 id、versionNo 均为字符串序列化（防前端精度丢失）
- **枚举总表**：

| 枚举 | 值 |
|------|-----|
| status 发布状态 | 0 草稿、1 发布中、2 发布失败、3 已发布、4 已暂停、5 已结束 |
| themeMode 主题模式 | 1 日常训练、2 通关考核、3 训考一体 |
| assignMode 分配模式 | 1 指定分配、2 全体学员 |
| difficulty 难度 | 1 简单、2 正常、3 困难 |
| jurisdictionType 归属（占位） | 1 我管辖的、2 我负责的 |
| sourceType 来源（占位） | 1 单独安排、2 项目安排 |
| joinMode 加入方式 | 1 仅指派、2 指派+完全公开 |
| aiResponseMode AI 响应模式 | 1 专家、2 快速 |
| scenePassType 场景通过类型 | 1 累计达标、2 连续达标 |

- **错误码**：本项目仅用统一 code=1 + message，无细分错误码（与 SpeechTraining 一致）。

## 2. 接口列表（模块：训练主题管理）

### 2.1 FP-06 分页查询主题列表

- **Method / Path**：`GET /api/act/admin/theme/list`
- **请求参数**（query）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 默认 1 |
| pageSize | int | 否 | 默认 10 |
| status | int | 否 | 发布状态枚举；不传=全部 |
| themeMode | int | 否 | 主题模式枚举；不传=全部 |
| keyword | string | 否 | 主题名称模糊搜索 |
| jurisdictionType | int | 否 | **占位字段**：归属；本次前端不传，后端接收实体中必须存在 |
| sourceType | int | 否 | **占位字段**：来源；本次前端不传，后端接收实体中必须存在 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 1,
    "records": [
      {
        "id": "1948010293847565011",
        "themeName": "柔性智造销售话术训练",
        "themeDesc": "基于六大场景知识库，训练销售精准讲解方案价值并应对客户质疑",
        "status": 3,
        "themeMode": 1,
        "sourceType": 1,
        "participantCount": 4,
        "updatedAt": "2026-09-16 10:31:34"
      }
    ]
  }
}
```

```json
    "status": 3,
    "themeMode": 1,
    "assignMode": 1,
    "difficulty": 2,
    "currentVersionNo": "2",
    "createdAt": "2026-05-26 15:32:12",
    "updatedAt": "2026-09-16 10:31:34",
```

> stats 各字段读 act_theme 占位字段（本次不做真实统计）；scenarioUnitCount=当前版本单元数；versionCount=版本总数（供「版本历史 (N)」Tab 标）。

### 2.3 FP-09 暂停 / 恢复

- **Method / Path**：`POST /api/act/admin/theme/{id}/pause`
- **说明**：已发布(3)→已暂停(4)；已暂停(4)→已发布(3)。其余状态返回 code=1。
- **请求示例**：无 body
- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "id": "1948010293847565011", "status": 4 } }
```

- **失败示例**：`{ "code": 1, "message": "当前状态不允许暂停或恢复", "data": null }`

### 2.4 FP-09 结束

- **Method / Path**：`POST /api/act/admin/theme/{id}/finish`
- **说明**：已发布(3)/已暂停(4)→已结束(5)，终态不可逆；已结束重复调用返回 code=1。
- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "id": "1948010293847565011", "status": 5 } }
```


> - `perSceneLimit: null` 表示不限；`practiceMethods` 为枚举数组：`case` 案例练习 / `custom` 自定义练习 / `random` 随机练习（数据库以 CSV 存储，接口层转换为数组返回/接收）。

### 2.7 FP-18 保存主题设置（整体保存，版本+1）

- **Method / Path**：`PUT /api/act/admin/theme/{id}/settings`
- **说明**：五个分区整体保存。服务端流程：插入新版本（versionNo=max+1，creator 固定'管理员'）→ 复制当前版本场景单元+维度到新版本 → 切换 current_version_no → 同步主题表冗余字段（themeName/themeDesc/themeMode/assignMode/difficulty/updatedAt）。主题状态为已结束(5)时拒绝保存。
- **请求示例**：

```json
{
  "basic": {
    "themeName": "柔性智造销售话术训练",
    "themeDesc": "基于六大场景知识库，训练销售精准讲解方案价值并应对客户质疑",
    "ownerUserId": "admin",
    "planStartTime": "2026-10-01 00:00:00",
    "planEndTime": null
  },
  "access": {
    "totalDrillCount": 3708,
    "perSceneLimit": null,
    "joinMode": 1,
    "guestAccessEnabled": false
  },
  "strategy": {
    "aiResponseMode": 1,
    "trainingModeEnabled": true,
    "assessmentModeEnabled": false,
    "coachReviewEnabled": true,
    "suggestionEnabled": false,
    "practiceMethods": ["case", "custom", "random"],
    "difficulty": 2,
    "allowCustomDifficulty": true,
    "antiCheat": {
      "faceCheckEnabled": false,
      "faceCheckStage": null,
      "screenSwitchMode": "forbid",
      "screenSwitchLimit": 0
    }
  },
  "passStandard": {
    "scenePassType": 1,
    "scenePassCount": 1
  }
}
```

> 注意：`ownerUserId` 为占位字段（前端当前不传，传了也仅落库不生效）。`practiceMethods` 取值：`case` / `custom` / `random`。

- **服务端校验**：themeName 非空≤50；themeDesc≤100；totalDrillCount≥1；perSceneLimit 为 null 或 ≥1；演练模式至少启用一种；trainingModeEnabled=true 时 coachReviewEnabled 必须为 true；practiceMethods 非空。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": { "id": "1948010293847565011", "versionNo": "3", "themeMode": 1, "assignMode": 1 }
}
```

- **失败示例**：`{ "code": 1, "message": "至少启用一种演练模式", "data": null }`

### 2.8 FP-19 版本列表

- **Method / Path**：`GET /api/act/admin/theme/{id}/versions`
- **说明**：按版本号倒序（新在上，回滚不改变排序）；当前版本带 `current: true`。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "versionNo": "2",
      "current": true,
      "createdAt": "2026-06-02 07:55:17",
      "usedUserCount": 1,
      "completedCount": 0,
      "inProgressCount": 1,
      "creator": "管理员"
    },
    {
      "versionNo": "1",
      "current": false,
      "createdAt": "2026-05-26 15:37:48",
      "usedUserCount": 0,
      "completedCount": 0,
      "inProgressCount": 0,
      "creator": "管理员"
    }
  ]
}
```

> usedUserCount/completedCount/inProgressCount 读版本表占位字段（不做真实统计）；creator 写死"管理员"。

### 2.9 FP-19 回滚到指定版本

- **Method / Path**：`POST /api/act/admin/theme/{id}/version/{versionNo}/rollback`
- **说明**：将 current_version_no 切换为目标版本（不产生新版本号、不修改任何版本记录内容），并同步主题表冗余字段。目标版本不存在或主题已结束时返回 code=1。
- **请求示例**：无 body
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": { "id": "1948010293847565011", "currentVersionNo": "1" }
}
```

- **失败示例**：`{ "code": 1, "message": "目标版本不存在", "data": null }`
