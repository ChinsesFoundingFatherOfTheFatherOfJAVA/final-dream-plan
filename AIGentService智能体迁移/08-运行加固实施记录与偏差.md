# Native Runtime 运行加固实施记录与偏差

> 日期：2026-10-23
> 范围：内部接口鉴权、基础 Prometheus 指标、Redis L2、DB L3
> 结论：四项均已实现并有单测/运行态证据；本文件与代码冲突时以代码为准。

## 1. 内部接口鉴权

| 项 | 最终口径 |
|---|---|
| AIGent 保护范围 | `/internal/**` |
| Atual 保护范围 | `/api/act/internal/memory/**` |
| 请求头 | `X-Internal-Token` |
| 共享变量 | `AGENT_INTERNAL_TOKEN` |
| token 不匹配 | HTTP 401 |
| token 未配置 | HTTP 503，fail-closed |
| 开关 | `AGENT_INTERNAL_AUTH_ENABLED`，默认 true |
| 公共端点 | AIGent Actuator；Atual Dify 工具端点 |

- AIGent 端由 `InternalAuthFilter` 实现，Atual 端由 `InternalMemoryAuthFilter` 实现。
- `NativeAgentClient`、两侧 `NativeWorkflowClient`、AIGent `AssistantHttpToolClient` 和
  `DbSessionStore` 均携带共享 token。
- Atual `/api/act/internal/tools/**` 当前继续供 Dify fallback 调用，未强制 token；若后续收紧，
  必须同步调整 Dify 工具配置，否则 fallback 会失效。

## 2. 监控指标

Actuator 暴露 `health,metrics,prometheus`。

| Prometheus 指标 | 含义 |
|---|---|
| `agent_chat_requests_total` / `agent_chat_failures_total` | chat 请求与失败 |
| `agent_chat_latency_seconds` | chat 耗时直方图 |
| `agent_workflow_requests_total{task}` / `agent_workflow_failures_total{task}` | workflow 请求与失败 |
| `agent_workflow_latency_seconds{task}` | workflow 耗时直方图 |
| `agent_llm_requests_total` / `agent_llm_failures_total` | LLM 请求与失败 |
| `agent_llm_outcomes_total{outcome}` | LLM 结果分类 |
| `agent_llm_failures_by_reason_total{reason}` | LLM 失败分类 |
| `agent_llm_latency_seconds{outcome}` | LLM 耗时直方图 |

- LLM outcome/reason 当前包含 `success`、`rate_limited`、`timeout`、`server_error`、
  `client_error`、`transport_error`、`configuration_error`、`invalid_response`、`interrupted`。
- P95 通过 Prometheus 直方图查询 `histogram_quantile(0.95, ...)`，不在应用侧固化告警阈值。
- 尚未接入 Prometheus 告警规则、Alertmanager 或外部告警平台。

## 3. 三层会话记忆

| 层 | 最终实现 |
|---|---|
| L1 | 进程内 `ConcurrentHashMap`，每会话最近 24 条 |
| L2 | Redis String JSON，key `agent:session:{sessionId}`，TTL 7 天 |
| L3 | `GET /api/act/internal/memory/{sessionId}` 读 `act_ai_message` |

- 读取：L1 命中直接用；否则读 L2；L2 miss 时读 L3，命中后回填 Redis。
- 写入：每轮问答结束同步写 L2；写失败忽略缓存故障，业务正常返回。
- L3 当前读取最近 1000 条消息，仅保留 content text 块；随后由 AIGent 截取最近 24 条进入 L1。
- L2 JSON 当前字段为 `messages`、`scenePlanDelivered`；不保存 `inputs`，未实现
  `agent:lock:*`、version 乐观锁、异步写和 L1 TTL 逐出。
- 上下文三变量仍由 AtualCombatTraining 每轮计算并随 chat 请求传入。
