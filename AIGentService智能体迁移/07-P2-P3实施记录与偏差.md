## 2. 最终取舍

| 项 | 最终方案 | 原因 |
|---|---|---|
| 文生图 | `avatar-gen` native + ModelScope | 用户提供 ModelScope key；插件源码确认异步 `/v1/images/generations` + `/v1/tasks/{id}`；模型使用 `Qwen/Qwen-Image-2.1-Turbo` |
| 工具调用 | 继续 HTTP，不 Dubbo 化 | P1 已按 HTTP 落地，P2/P3 不重复改工具链路 |
| provider 切换 | 启动配置生效 | Nacos 动态刷新尚未接入，文档保留为后续项 |
| P2 theme 流式 | 复用 `node_finished` 协议 | 消费端可渐进渲染场景、画像冰山、最终产物 |
| P3 输出 | 保持 DSL end 变量 | `sceneResult` / `outlineResult` / `scriptResult` / 评分字段不变 |
| 结构化输出 | Qwen `response_format=json_schema` | 已实测可用 |
| 长任务超时 | MVC 610s，Qwen 600s | P2 三节点真实生成超过 30s/120s 默认值 |

## 3. 实施中修正的问题

1. **MVC 异步超时**：默认 30s 会截断 theme-gen；已设置 `610000ms`。
2. **Qwen 读超时**：默认 120s 不能覆盖主题评估维度节点；已设置 `600000ms`。
3. **case-gen difficulty**：模型偶发省略 `difficulty`，但难度由 Java 请求决定；
   `CaseGenTask` 现在先注入请求难度再校验。
4. **工具 schema**：P1 已修正数组元素类型，P2/P3 继续复用真实 DTO 字段名。
