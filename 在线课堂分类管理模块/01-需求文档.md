## 1. 项目概述

复刻原平台"在线课堂"管理端的左侧导航骨架、**分类管理**、**课程设置**两个页面。课件管理、课程管理本次仅做占位入口（后续模块再实现）。

- 范围：管理端前端（front-end 工程，/kng 路由族）+ 后端（新建 OnlineClassroom 应用）
- 不在范围：学员端、课件管理页、课程管理页、购课管理、数据概览、企课堂、课程互动管理
- 关键平台行为实测结论（影响架构）：原平台分类列表整棵树一次拉取，展开/收起、名称搜索、课程数口径切换全部为**前端本地计算**，本模块照此实现

## 2. 术语与角色

| 术语 | 说明 |
|------|------|
| 主课堂 | 原平台的顶层课堂概念；本系统**只有一个主课堂**，作为虚拟根，不落库、不下拉选择 |
| 分类（目录） | kng_catalog，树形结构，最多 10 级 |
| 授权对象 | 分类权限的被授予方：内置三行（超级管理员&分类创建者/课堂管理员/课堂成员）+ 部门 / 岗位 / 角色 |
| 权限点 | 分发、维护、浏览、允许下载课件、App缓存课件（自编号 1~5） |

**角色**：管理端登录用户（沿用 StaffManagement 的 JWT 登录态与 sys_user / sys_permission 权限体系）。

## 3. 功能需求

### 3.1 模块：入口与导航

#### FP-01 首页入口与左侧导航
- **功能描述**：首页"常用应用"区新增"在线课堂"卡片（粉红圆形图标+副标题"专业的企业学习资源运营"），点击进入 `/kng` 路由族；在线课堂页面为独立布局，左侧栏四项：**课件管理、课程管理、分类管理、课程设置**（同级平铺，课程设置**不**收进"更多管理"）。
- **前置条件**：用户已登录管理端且拥有对应权限点。
- **页面/组件拆解**：
  - `Home.vue` 新增应用卡片（跳转 `/kng/catalog`）
  - `OnlineClassroomLayout.vue`：左侧栏（图标+菜单项）+ 右侧内容区（router-view）
  - 菜单权限：`kng:courseware` / `kng:course` / `kng:catalog` / `kng:setting` 四条权限点入 sys_permission（DataInitializer 补齐），左栏菜单与路由守卫按权限码显隐
- **交互流程**：点卡片 → 默认进入分类管理页；点左栏项切换路由；无权限的菜单项不显示。
- **占位页**：课件管理（`/kng/courseware`）、课程管理（`/kng/course`）为空白占位页，居中提示"功能建设中"。
- **验收标准**：
  - Given 已登录且有 kng:catalog 权限 When 点击首页"在线课堂"卡片 Then 进入 `/kng/catalog` 且左栏四项可见
  - Given 无 kng:setting 权限 When 打开左栏 Then "课程设置"项不显示，直接访问 `/kng/setting` 被守卫拦截

#### FP-02 课程设置页
- **功能描述**：复刻原平台课程参数设置页（`/kng/#/param/set`），含学分发放设置与防挂机设置两块。
- **前置条件**：拥有 `kng:setting` 权限。
- **页面/组件拆解**：`CourseSetting.vue`（路由 `/kng/setting`）。
- **交互流程**：
  1. 进入页面读取 `GET /api/kng/admin/setting` 回显
  2. 学分设置：单选项"学完课程时发放所有课件的学分"（radio，当前唯一选项，预留扩展）+ 下方两条"注"文案 + 【应用】按钮
  3. 防挂机设置：开关"开启防挂机功能"；模式一（默认选中）"系统在 [N] 分钟确认学员是否在线，如不在线则停止播放"；模式二"系统在 [N] 分钟确认学员是否在线，学员需要在 [M] 秒内点击确认，如未确认本次学习无效"；两处 N 与 M 为数字输入框；提示语 textarea（"确认学员是否在线提示语"，≤250 字，右下角字数统计）
  4. 点【应用】调用 `PUT /api/kng/admin/setting` 保存，成功后提示"已保存"
- **默认值**：防挂机关闭；模式一；N=3；M=120；提示语="已触发防挂机验证，请点击"继续学习"，否则学习将被停止"
- **不做**：原平台"特殊设置"链接、人脸识别联动。
- **验收标准**：
  - Given 首次进入 When 页面加载 Then 显示默认值
  - Given 修改模式二并填写 M=90 When 点击应用 Then 保存成功且刷新后回显一致
  - Given 提示语输入 251 字 Then 输入被截断/校验拦截，字数统计不超过 250

### 3.2 模块：分类管理（列表）

#### FP-03 分类列表（树形表格）
- **功能描述**：分类管理主页（`/kng/catalog`），上方功能按钮区 + 下方分类树形表格。
- **前置条件**：拥有 `kng:catalog` 权限。
- **页面/组件拆解**：`CatalogManage.vue`。
- **数据加载**：进入页面调用 `GET /api/kng/admin/catalog/tree` **一次拉取整棵树**（含各级统计字段），此后展开/收起、搜索、口径切换全部本地计算，不再发请求。
- **表格列**：

| 列 | 说明 |
|----|------|
| 分类名称 | 宽列（约 40% 列宽，层级深时名称长）；有子分类的行名称左侧显示 ">" 展开箭头，点击展开/收起子级（缩进渲染，按层级缩进） |
| 层级 | "N 级" |
| 课程数 | 口径见 FP-04；本模块无课件/课程数据，恒为 0（字段预留） |
| 更新日期 | yyyy-MM-dd |
| 操作 | 链接：查看、编辑、"更多"（hover 弹出菜单：删除、创建子分类、批量创建子分类、移动此分类（含课程）、移动此分类下的课程） |

- **初始状态**：只渲染一级分类；子级默认收起。
- **行选中**：点击行任意位置选中该行（淡蓝色背景，单选），选中态供 FP-06/FP-15 的"所属分类"取值；再点一次取消选中。
- **验收标准**：
  - Given 一级分类"营销话术"有子分类 When 页面加载 Then 仅显示一级行且名称左侧有">"；点击">"后子级缩进展开，箭头变为"∨"
  - Given 点击某行 When 选中 Then 该行淡蓝背景；再点取消
  - Given 分类无子分类 Then 名称列不显示箭头

#### FP-04 课程数口径切换
- **功能描述**：按钮区"课程数统计"下拉（两项：**包含子分类**（默认）/ 仅当前分类），切换影响列表"课程数"列取值：包含子分类=该分类及全部后代聚合值；仅当前分类=仅本级值。纯前端本地切换。
- **验收标准**：Given "服务话术"本级 0、含子级 35 When 切换"仅当前分类" Then 该行显示 0；切回"包含子分类"显示 35（本模块当前均为 0，逻辑须按此实现，未来有数据后自动生效）。

#### FP-05 分类名称搜索
- **功能描述**：搜索框输入关键字，**模糊匹配**（label 包含关键字）；命中的分类连同其**全部祖先链**整链展开显示；未命中的分类行隐藏。纯前端本地过滤。
- **交互**：输入即过滤（或回车/点击搜索图标触发，实现取其一并在文档注明）；清空恢复默认一级视图。
- **验收标准**：
  - Given 搜索"杰克" When 3 级分类"杰克成套"命中 Then 显示其祖先 1 级"服务话术"→2 级"杰克"→"杰克成套"整链，且默认展开
  - Given 清空关键字 Then 恢复只显示一级分类的初始视图

#### FP-06 新增分类（顶部按钮）
- **功能描述**：点"新增分类"右侧弹出抽屉，表单同 FP-08 编辑抽屉（创建模式：分类名称为必填输入框，无创建人/所属分类只读回显中的创建人）。
- **所属分类规则**：列表**未选中**行 → 所属分类="主课堂"（新分类为一级）；**选中**某行 → 所属分类=该行完整链路（如"主课堂/服务话术"），新分类创建在该分类之下。
- **验收标准**：
  - Given 未选中任何行 When 打开新增抽屉 Then 所属分类显示"主课堂"，保存后新分类出现在一级列表末尾
  - Given 选中"服务话术" When 打开新增抽屉 Then 所属分类显示"主课堂/服务话术"，保存后新分类成为其子分类且该行出现">"

### 3.3 模块：分类管理（查看/编辑/权限）

#### FP-07 查看（操作-查看）
- **功能描述**：点击"查看"右侧弹出抽屉（只读）。
- **内容**：
  - **基本信息**：所属分类（父链路，一级显示"主课堂"）、创建人（`姓名/工号`+"（创建人有该目录的所有权限）"括注）、分类名称、发布时间（=创建时间，`yyyy-MM-dd`，用户指定字段，原平台截图未显示）、默认课程顺序（枚举名）、前后缀设置（未配置显示"--"；已配置显示"前缀：xxx / 日期后缀：yyyy-MM-dd"）
  - **权限设置**：按授权对象分行，只读展示各对象拥有的权限点名（如"浏览/允许下载课件/App缓存课件"）
- **操作**：右下角【编辑】按钮 → 打开编辑抽屉（FP-08）。
- **验收标准**：Given "营销话术"配置了三类默认权限 When 点击查看 Then 抽屉正确展示基本信息与权限文本；点【编辑】打开编辑抽屉且数据一致。

#### FP-08 编辑抽屉（三个入口共用：查看→编辑、操作-编辑、更多-创建子分类）
- **功能描述**：右侧抽屉编辑分类；"更多-创建子分类"= 同抽屉的创建模式（所属分类=目标分类链路，分类名称必填）。顶部"新增分类"（FP-06）也复用本抽屉。
- **表单项**：

| 项 | 类型 | 规则 |
|----|------|------|
| 所属分类 | 只读文本 | 主课堂/父链路 |
| 创建人 | 只读文本（编辑已有分类时显示；创建模式不显示） | 姓名/工号 |
| 分类名称 | input，必填 | ≤50 字，计数 0/50；建议 6 字以内（placeholder 提示） |
| 默认课程顺序 | radio 四选一 | 发布时间（默认）/ 更新时间 / 名称 / 学习人数 |
| 前后缀设置-前缀 | checkbox + input | 勾选后输入框可用；内容 ≤50 字 |
| 前后缀设置-日期 | checkbox + 下拉 | 格式三选项：yyyy-MM-dd / yyyy/MM/dd / yyyyMMdd（推断，待验证） |
| 权限设置 | 见 FP-09 | |

- **说明**：前后缀设置本次仅做**存储与回显**，不实现给课件/课程标题实际加前后缀（无消费方）。
- **底部**：【取消】【确定】。确定=保存基本信息+权限矩阵（一个接口）。
- **验收标准**：
  - Given 名称留空 When 点击确定 Then 名称输入框红框+错误提示"请输入分类名称，建议6个字以内"，不提交
  - Given 修改默认课程顺序为"学习人数" When 保存 Then 成功后查看抽屉显示"学习人数"
  - Given 勾选前缀并输入"【杰克】" When 保存 Then 再次编辑回显勾选态与内容

#### FP-09 权限设置矩阵
- **功能描述**：编辑抽屉下半部分。
- **默认三行（不可删除行）**，映射到本系统：
  1. **超级管理员&分类创建者** = sys_user 中 is_super_admin=1 的用户 + 该分类的创建者
  2. **课堂管理员** = 拥有 `kng:catalog` 权限点的用户
  3. **课堂成员** = 全体 sys_user
- **列**：全选（含半选态）/ 分发 / 维护 / 浏览 / 允许下载课件 / App缓存课件（自编号 1~5）
- **默认勾选**（新增/创建子分类时，对齐原平台实测模板）：超管&创建者全选；课堂管理员全选；课堂成员=浏览+允许下载课件+App缓存课件。
- **添加对象**：点"+ 添加用户权限"（虚线按钮）→ FP-10 抽屉勾选部门/岗位/角色 → 确定后矩阵追加对应行（可勾选权限点，默认全不勾）；**新增行最右侧有小按钮可移除该行**；默认三行无移除按钮。
- **继承区**（仅编辑已有分类时显示，见 FP-11）。
- **验收标准**：
  - Given 打开新增抽屉 Then 矩阵显示三行默认勾选
  - Given 通过 FP-10 勾选"人力资源部" When 确定 Then 矩阵新增"人力资源部"行且行尾有移除按钮；点移除按钮该行消失
  - Given 行内部分勾选 Then 全选列显示半选态

#### FP-10 添加用户权限抽屉
- **功能描述**：选择授权对象（最小单元=部门/岗位/角色，**不选具体人**）。
- **页面**：抽屉顶部三个 tab（部门/岗位/角色，无"用户组/快速选人"）：
  - **部门**：树形（数据源 sys_department），默认展开一级；支持名称搜索（过滤树+命中展开）
  - **岗位**：分页列表（数据源 sys_user 的 position distinct），列：勾选框/岗位名/人数；支持名称搜索；分页条
  - **角色**：分页列表（数据源 sys_role），列：勾选框/角色名/备注/人数；支持名称搜索；分页条
- **右侧"已选"面板**：显示已勾选对象（含 tab 间累积），可逐个移除。
- **底部**：【取消】【确定】→ 把已选对象加入 FP-09 矩阵。
- **验收标准**：
  - Given 部门 tab 搜索"供应链" Then 树过滤显示命中节点及其祖先
  - Given 在部门 tab 勾选 A 部门后切到岗位 tab 勾选岗位 P When 确定 Then 矩阵同时新增"部门A"与"岗位P"两行
  - Given 已在矩阵中存在的对象 When 再次打开抽屉 Then 该对象显示已勾选；重复确定不产生重复行

#### FP-11 继承选项（三项）
- **功能描述**（均在编辑抽屉权限设置区底部；实现方式=**保存时快照**，已拍板）：
  1. **继承父分类权限**（checkbox）："勾选后使用父分类权限覆盖当前分类权限，不允许修改"。实现：抽屉内勾选后权限矩阵区置灰只读（显示父分类当前权限快照预览）；保存时把父分类权限复制为本分类权限；取消勾选后矩阵恢复可编辑（内容保持上次覆盖值）。
  2. **所有子分类继承当前分类权限**（checkbox）："勾选后所有子分类权限被当前分类权限覆盖"。实现：保存时把当前分类权限**递归下推覆盖**到全部子孙分类（并同样置灰这些子分类？——不下发置灰标志，仅覆盖权限数据；子分类自身的"继承父分类权限"勾选态不变）。
  3. **在父分类中添加当前分类权限**：说明文案 + 【一键执行】按钮。实现：把当前分类的全部权限对象按**并集**合并进父分类（父分类已有对象合并权限点，新对象直接追加），执行后提示成功。
- **验收标准**：
  - Given 勾选"继承父分类权限"保存 Then 本分类权限=父分类权限副本；抽屉内矩阵为只读
  - Given 勾选"所有子分类继承"保存 Then 任意子分类的权限都等于当前分类权限
  - Given 点击【一键执行】 Then 父分类权限=原权限∪当前分类权限，当前分类权限不变

### 3.4 模块：分类管理（增删移批）

#### FP-12 删除（更多-删除）
- **功能描述**：点"更多-删除"→ 二次确认弹窗（"确定删除分类「xxx」吗？"）→ 确认后删除。
- **规则**：分类下**还有子分类 → 阻止删除**，提示"该分类下存在子分类，请先处理子分类"；删除成功同时物理删除其权限关联记录（无课程数据需清理）。
- **验收标准**：
  - Given "营销话术"下有子分类 When 确认删除 Then 提示阻止，分类仍在
  - Given 叶子分类 When 确认删除 Then 列表移除该行，其权限记录同步清除

#### FP-13 批量创建子分类（更多-批量创建子分类）
- **功能描述**：抽屉显示：所属分类（只读）+ 分类内容 textarea + 填写说明。
- **填写说明**（照原平台）：
  1. 课程分类总层级最多支持 10 级，超出后无法创建成功
  2. 每级子分类需与上级分类保持一个以上空格的缩进
  3. 批量创建的分类，权限默认继承所属分类（=父分类权限快照）
  4. 分类名称 50 字以内
- **解析规则**（后端实现，整体事务）：
  - 按行解析，行前空格数推算层级（缩进深度=父级深度+1，**跳级报错**）
  - 缩进以空格计（1 空格=1 级差），非空格缩进（Tab）报错
  - 同级同名 → 报错；名称为空行/超 50 字 → 报错
  - 层级数+现有深度 > 10 → 报错
  - **任一行失败 → 全部回滚**，错误信息带行号
- **验收标准**：
  - Given 提交 `分类A\n 子分类A1\n  子分类A11` When 确定 Then 一次创建 3 级共 3 个分类，权限均为"服务话术"权限快照
  - Given 第 3 行跳级缩进 When 确定 Then 返回"第 3 行缩进层级错误"，无任何分类被创建

#### FP-14 移动此分类（含课程）/ 移动此分类下的课程
- **功能描述**：两个"更多"菜单项，抽屉 UI 完全一致：待移动分类（只读）+ 蓝色提示条"被共享的课件暂不支持移动"（照原平台文案；本系统无共享概念，文案保留）+ "移动至"搜索框 + 目标分类树。
- **目标树**：`GET /api/kng/admin/catalog/tree` 复用整树接口；**排除待移动分类自身及其全部子孙**（防环）；支持名称搜索（过滤+展开）；树根显示"主课堂"。
- **不做**："请选择课堂"下拉（只有一个主课堂）。
- **行为差异**：
  - **移动此分类（含课程）**：整棵子树挂到目标分类下（目标=主课堂 则变为一级分类）
  - **移动此分类下的课程**：分类树不动，把该分类**直属**课程移到目标分类（当前无课程数据，接口预留，提交返回"已移动 0 条"并提示）
- **验收标准**：
  - Given 移动"营销话术"到"产品话术"下 When 确定 Then "营销话术"整棵子树成为"产品话术"子级，层级数字相应 +1
  - Given 打开"营销话术"的移动抽屉 Then 目标树中不出现"营销话术"及其子级
  - Given 目标选中自身子孙 When 提交 Then 后端校验拒绝（前端已隐藏，后端兜底）

#### FP-15 批量新增分类（顶部按钮）
- **功能描述**：抽屉与 FP-13 完全一致；**支持列表选中行变换所属分类**：未选中→所属分类"主课堂"（批量创建一级及以下）；选中行→所属分类=选中链路。权限默认继承=所选父分类权限快照。
- **验收标准**：Given 选中"服务话术" When 打开批量新增 Then 所属分类显示"主课堂/服务话术"；创建的分类挂在"服务话术"下且权限继承其快照。

## 4. 非功能需求

- 分类树规模：当前 11 个一级、数十节点；接口按全量树 ≤ 数百节点设计，一次拉取 < 200ms
- 所有 id 前后端以字符串传输（防 JS 精度丢失，全站约定）
- 时间格式：列表"更新日期"= `yyyy-MM-dd`；其余 `yyyy-MM-dd HH:mm:ss`
