# 在线课堂（管理端）复刻接口文档 —— 分类管理 + 课程设置

> 版本：v1.0 ｜ 日期：2026-09-29 ｜ 服务：OnlineClassroom（新建，经网关访问）
> 配套：01-需求文档.md、02-技术实现方案.md

---

## 1. 通用约定

- **Base URL**：`http://localhost:8080/api/kng`（网关 8080 将 `/api/kng/**` 转发至 `lb://OnlineClassroom`，**该路由必须声明在 `/api/**` 兜底路由之前**；服务内 Controller 路径以 `/api/kng` 开头）
- **鉴权**：沿用全站登录态（与 SpeechTraining / AtualCombatTraining 现状一致，本模块不做额外鉴权逻辑）；菜单可见性由前端按 sys_permission 权限码守卫
- **统一响应结构**：

```json
{ "code": 0, "message": "success", "data": { } }
```

- `code=0` 成功；`code=1` 业务失败（message 为用户可读中文，如"该分类下存在子分类，请先处理子分类"）
- **分页参数**：`page`（从 1 起）、`pageSize`（默认 10）
- **时间格式**：树节点 `updateTime` 为 `yyyy-MM-dd`；其余 `yyyy-MM-dd HH:mm:ss`
- **ID 约定**：所有 id 均为字符串序列化（防前端精度丢失）
- **枚举总表**：

| 枚举 | 值 |
|------|-----|
| orderType 默认课程顺序 | 1 发布时间、2 更新时间、3 名称、4 学习人数 |
| dateSuffixFormat 日期后缀格式 | yyyy-MM-dd、yyyy/MM/dd、yyyyMMdd |
| subjectType 授权对象类型 | 1 超级管理员&分类创建者(内置)、2 课堂管理员(内置)、3 课堂成员(内置)、4 部门、5 岗位、6 角色 |
| permCode 权限点 | 1 浏览、2 允许下载课件、3 分发、4 维护、5 App缓存课件 |
| antiIdleMode 防挂机模式 | 1 模式一、2 模式二 |

- 权限点码与原平台（0浏览/1允许下载课件/2分发/4维护/6App缓存课件）的映射：0→1、1→2、2→3、4→4、6→5（重编号为连续值，见决策记录表）
- **错误码**：统一 code=1 + message，无细分错误码

## 2. 接口列表

### 2.1 模块：分类管理（FP-03/04/05）

#### FP-03 分类树（整树一次拉取）
- **Method / Path**：`GET /api/kng/admin/catalog/tree`
- **说明**：返回整棵分类树。前端展开/收起、搜索过滤、课程数口径切换全部本地计算，不重复请求。**参照原平台抓包**（POST /kng/classificate/list 的整树行为）。
- **请求参数**：无
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": "1948010293847565011",
      "name": "营销话术",
      "level": 1,
      "orderIndex": 0,
      "kngCount": 0,
      "courseCount": 0,
      "allKngCount": 0,
      "allCourseCount": 0,
      "updateTime": "2026-09-29",
      "children": [
        {
          "id": "1948010293847565012",
          "name": "LTC流程方法论",
          "level": 2,
          "orderIndex": 0,
          "kngCount": 0,
          "courseCount": 0,
          "allKngCount": 0,
          "allCourseCount": 0,
          "updateTime": "2026-09-29",
          "children": []
        }
      ]
    },
    {
      "id": "1948010293847565020",
      "name": "服务话术",
      "level": 1,
      "orderIndex": 1,
      "kngCount": 0,
      "courseCount": 0,
      "allKngCount": 0,
      "allCourseCount": 0,
      "updateTime": "2026-09-29",
      "children": []
    }
  ]
}
```

- **字段说明**：`data` 为**一级分类数组**（虚拟根"主课堂"不返回）；`kngCount/courseCount`=本级数（预留恒 0）；`allKngCount/allCourseCount`=含全部子孙聚合值（后端后序遍历求和）；`children` 按同层级 `orderIndex` 升序。

- **说明**：查看抽屉与编辑抽屉共用的数据源。**参照原平台抓包**（POST /kng/kngCatalog/info）。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "1948010293847565011",
    "parentId": null,
    "name": "营销话术",
    "parentPath": "主课堂",
    "level": 1,
    "orderType": 1,
    "prefixEnabled": true,
    "prefixContent": "【杰克】",
    "dateSuffixEnabled": true,
    "dateSuffixFormat": "yyyy-MM-dd",
    "inheritParent": false,
    "createTime": "2026-04-13 10:20:00",
    "createUser": { "name": "董瑞", "account": "40023266" },
    "permissions": [
      { "subjectType": 1, "subjectId": null, "subjectName": "超级管理员&分类创建者", "permCodes": [1, 2, 3, 4, 5] },
      { "subjectType": 2, "subjectId": null, "subjectName": "课堂管理员", "permCodes": [1, 2, 3, 4, 5] },
      { "subjectType": 3, "subjectId": null, "subjectName": "课堂成员", "permCodes": [1, 2, 5] },
      { "subjectType": 6, "subjectId": "3001", "subjectName": "培训管理员", "permCodes": [1, 2, 3, 4] },
      { "subjectType": 4, "subjectId": "4001", "subjectName": "人力资源部", "permCodes": [1, 2] }
    ]

```

- **字段说明**：`parentId`=直属父分类；`parentPath`=父链路（一级显示"主课堂"，二级如"主课堂/营销话术"）；`createTime`=创建时间，即查看抽屉的"发布时间"字段（前端按 yyyy-MM-dd 展示）；`permCodes` 为权限点枚举数组（原平台为 CSV 字符串，本系统改数组，见决策记录表）；`subjectType` 1/2/3 的 `subjectId` 恒为 null。

#### FP-08/09/11 新增分类
- **Method / Path**：`POST /api/kng/admin/catalog`
- **说明**：新增分类（顶部"新增分类"与"更多-创建子分类"共用）。保存成功后固定插入三行内置权限（若请求未携带则按默认模板补齐）。整体事务。
- **请求参数**（body，JSON）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| parentId | string/null | 是 | 父分类 id；**null=一级分类** |
| name | string | 是 | 分类名称，1~50 字 |
| orderType | int | 是 | 默认课程顺序枚举 |
| prefixEnabled | boolean | 否 | 默认 false |
| prefixContent | string | prefixEnabled=true 时必填 | ≤50 字 |
| dateSuffixEnabled | boolean | 否 | 默认 false |
| dateSuffixFormat | string | dateSuffixEnabled=true 时必填 | 枚举 |
| permissions | array | 否 | 权限行数组（结构同 detail 的 permissions 元素）；缺省=默认模板三行 |

- **请求示例**：

```json
{
  "parentId": "1948010293847565020",
  "name": "通用类",
  "orderType": 1,
  "prefixEnabled": false,
  "dateSuffixEnabled": false,
  "permissions": [
    { "subjectType": 1, "subjectId": null, "subjectName": "超级管理员&分类创建者", "permCodes": [1, 2, 3, 4, 5] },
    { "subjectType": 2, "subjectId": null, "subjectName": "课堂管理员", "permCodes": [1, 2, 3, 4, 5] },
    { "subjectType": 3, "subjectId": null, "subjectName": "课堂成员", "permCodes": [1, 2, 5] }
  ]
}
```

- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "id": "1948010293847565030" } }
```

- **失败示例**：`{ "code": 1, "message": "同级已存在同名分类「通用类」", "data": null }`

#### FP-08/09/11 编辑保存
- **Method / Path**：`PUT /api/kng/admin/catalog/{id}`
- **说明**：保存基本信息 + **整表替换**权限矩阵 + 处理两个继承标志。整体事务。
- **请求参数**（body）：同新增接口，另加：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| inheritParent | boolean | 是 | 继承父分类权限标志（true 时后端忽略 permissions 入参，改存父分类权限快照） |
| childrenInherit | boolean | 是 | 所有子分类继承当前分类权限标志（true 时保存后递归下推覆盖全部子孙的权限） |

- **处理规则**：
  1. `inheritParent=true` → 删除本分类权限，复制父分类权限行为本分类权限（subject_type 1/2/3 保持内置行语义）；`inheritParent=false` → 按 permissions 整表替换（内置三行缺失则拒绝：code=1"权限设置缺少内置授权对象"）
  2. `childrenInherit=true` → 对全部子孙分类执行与 1 相同的覆盖（以**本分类保存后的权限**为准）
  3. 同级同名校验（排除自身）
- **响应示例**：`{ "code": 0, "message": "success", "data": { "id": "1948010293847565011" } }`

#### FP-11 在父分类中添加当前分类权限（一键执行）
- **Method / Path**：`POST /api/kng/admin/catalog/{id}/merge-to-parent`
- **说明**：把当前分类的全部权限行按**并集**合并进父分类（父分类已有同对象 → permCodes 取并集；没有 → 插入该行）。一级分类（父=主课堂虚拟根）调用返回 code=1。
- **响应示例**：`{ "code": 0, "message": "success", "data": { "count": 2 } }`（count=实际新增的权限行数）

### 2.3 模块：删除/移动/批量（FP-12/13/14/15）

#### FP-12 删除分类
- **Method / Path**：`DELETE /api/kng/admin/catalog/{id}`
- **说明**：物理删除分类及其权限记录。有子分类则拒绝。
- **响应示例**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "该分类下存在子分类，请先处理子分类", "data": null }`

#### FP-13/15 批量创建子分类
- **Method / Path**：`POST /api/kng/admin/catalog/batch`
- **说明**：解析缩进文本批量创建。整体事务：任一行失败全部回滚，message 携带行号。权限默认=父分类（或所选父分类）权限快照。
- **请求参数**（body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| parentId | string/null | 是 | 所属父分类；null=一级 |
| content | string | 是 | 分类内容文本（\n 分行，行前空格=缩进） |

- **请求示例**：

```json
{
  "parentId": "1948010293847565020",
  "content": "分类名称1\n 子分类名称01\n分类名称2"
}
```

- **响应示例**：`{ "code": 0, "message": "success", "data": { "count": 3 } }`
- **校验规则（后端）**：
  1. 空行忽略；行首空格数为 0/1/2/…，每 +1 空格=下一级；**缩进跳级（如 0 直接 2）**→ `第 N 行缩进层级错误`
  2. Tab 缩进 → `第 N 行请使用空格缩进`
  3. 同级同名（含与已有分类同名）→ `第 N 行同级已存在同名分类「xxx」`
  4. 名称空/超 50 字 → `第 N 行分类名称不能为空/超出 50 字`
  5. 父分类 level + 文本最大相对深度 > 10 → `超出 10 级层级限制`
- **失败示例**：`{ "code": 1, "message": "第 3 行缩进层级错误", "data": null }`

#### FP-14 移动此分类（含课程）
- **Method / Path**：`POST /api/kng/admin/catalog/{id}/move`
- **说明**：整棵子树挂到目标分类下；后端递归更新子孙 level。**预留**：移动时同步迁移本分类下挂的课件/课程归属（当前无数据，无实际动作）。
- **请求参数**（body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| targetParentId | string/null | 是 | 目标父分类；null=移动到一级（主课堂下） |

- **响应示例**：`{ "code": 0, "message": "success", "data": { "count": 5 } }`（count=子树节点总数）
- **失败示例**：
  - `{ "code": 1, "message": "不能移动到自身或其子分类下", "data": null }`（后端防环兜底）
  - `{ "code": 1, "message": "同级已存在同名分类「xxx」", "data": null }`
  - `{ "code": 1, "message": "目标层级超出 10 级限制", "data": null }`

#### FP-14 移动此分类下的课程（预留接口）
- **Method / Path**：`POST /api/kng/admin/catalog/{id}/move-courses`
- **说明**：把该分类**直属**课程移动到目标分类（分类树不动）。当前无课程数据，恒返回 count=0；未来课件/课程模块上线后在此接口补实现。**预留**。
- **请求参数**：同上（targetParentId 语义=目标分类 id，非父分类）。
- **响应示例**：`{ "code": 0, "message": "success", "data": { "count": 0 } }`
- **前端提示**：提交成功后提示"已移动 0 条课程"。

### 2.4 模块：选人数据（FP-10）

#### FP-10 部门树
- **Method / Path**：`GET /api/kng/admin/subjects/dept-tree`
- **说明**：返回 sys_department 全量树。**参照原平台抓包**（GET /udp/depts/tree）。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": "5001",
      "name": "杰克科技股份",
      "userCount": 35,
      "children": [
        { "id": "5002", "name": "智能成套产品军团", "userCount": 12, "children": [] },
        { "id": "5003", "name": "人力资源部", "userCount": 5, "children": [] }
      ]
    }
  ]
}
```

- **字段说明**：`userCount`=该部门直属人数（sys_user 统计）；前端搜索过滤与展开为本地计算。

#### FP-10 岗位分页
- **Method / Path**：`GET /api/kng/admin/subjects/positions`
- **请求参数**（query）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 默认 1 |
| pageSize | int | 否 | 默认 10 |
| name | string | 否 | 岗位名模糊搜索 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 25,
    "records": [
      { "name": "品牌市场策划工程师", "userCount": 6 },
      { "name": "后勤专员", "userCount": 1 }
    ]
  }
}
```

- **字段说明**：数据源=sys_user 的 position distinct + 分组计数；**岗位无 id，以 name 为唯一标识**（权限表 subject_id 存岗位名）。

#### FP-10 角色分页
- **Method / Path**：`GET /api/kng/admin/subjects/roles`
- **请求参数**（query）：同岗位（name=角色名模糊搜索）。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 8,
    "records": [
      { "id": "3001", "name": "导师", "remark": "", "userCount": 0 },
      { "id": "3002", "name": "培训管理员", "remark": "负责培训管理", "userCount": 3 }
    ]
  }
}
```

- **字段说明**：数据源=sys_role；`userCount`=该角色关联用户数（sys_user_role 统计）。

### 2.5 模块：课程设置（FP-02）

#### FP-02 读取课程设置
- **Method / Path**：`GET /api/kng/admin/setting`
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "creditMode": 1,
    "antiIdleEnabled": false,
    "antiIdleMode": 1,
    "checkIntervalMinutes": 3,
    "confirmSeconds": 120,
    "promptText": "已触发防挂机验证，请点击\"继续学习\"，否则学习将被停止"
  }
}
```

#### FP-02 保存课程设置
- **Method / Path**：`PUT /api/kng/admin/setting`
- **请求参数**（body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| creditMode | int | 是 | 1=学完课程时发放所有课件的学分（预留） |
| antiIdleEnabled | boolean | 是 | 防挂机开关 |
| antiIdleMode | int | 是 | 1/2 |
| checkIntervalMinutes | int | 是 | 1~60 |
| confirmSeconds | int | antiIdleMode=2 时必填 | 30~600 |
| promptText | string | 是 | ≤250 字；antiIdleEnabled=true 时非空 |

- **响应示例**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "提示语不能超过 250 字", "data": null }`
