## 1. 背景与范围

- v1.0 的 FP-02 按简化口径实现（单 radio + 防挂机基础项）。本次按原平台完整页面扩展：**8 个设置区块中做 4 个**（学分策略、防挂机含特殊设置抽屉、课程播放、人脸识别），不做 4 个（课程评论、课程审核、课程属性、课程模板设置——用户明确不做）。
- 全部设置项均为**仅存储 + 回显**（用户拍板），不实现学分计算/防作弊/倍速控制等引擎逻辑，未来学员端模块消费。
- 前置：v1.0 分类管理已由 code agent 实现完成；本扩展会**重构** CourseSetting 页面与 kng_setting 表（见 06/08）。

## 2. 功能需求

### FP-02a 页面框架（区块卡片 + 展开/收起 + 独立应用）
- **功能描述**：课程设置页（路由 `/kng/setting`，沿用 v1.0）由纵向排列的区块卡片组成；每个区块=标题（左侧蓝色竖条）+ 右侧"展开/收起"链接 + 展开后的具体设置项 + 底部【应用】按钮。
- **交互流程**：
  1. 进入页面调 `GET /api/kng/admin/setting` 一次拉取全部四个区块配置
  2. 区块**默认收起**（对齐原平台实测：初始显示"展开"链接）；点击标题栏或链接切换展开/收起
  3. 修改某区块内设置 → 点击该区块底部【应用】→ 调该区块独立保存接口 → 提示"已保存"
  4. 各区块保存互不影响；未点应用离开页面不保存（无自动保存，人脸识别除外，见 FP-02f）
- **验收标准**：
  - Given 首次进入 When 页面加载 Then 四个区块全部收起，点击可展开
  - Given 修改 A 区块并应用、B 区块也改了未应用 When 刷新 Then 仅 A 区块变更生效

### FP-02b 学分策略设置
- **功能描述**：五类课件学分规则 + 应用范围 + 学分发放时间。
- **表单项**（每行为一条规则，`[]` 为数字输入框）：

| 行 | 设置项 | 输入 |
|----|--------|------|
| 视频/音频 | 每 [N] 分钟计 [M] 个学分（视频和音频上传时会自动获取时长） | N、M |
| 文档 | 每 [N] 页计 [M] 个学分，标准学习时长 [H] 分钟，每个文档最高学分不超过 [X] 个学分 | N、M、H、X |
| 微课 | 每 [N] 分钟计 [M] 个学分，每个微课最高学分不超过 [X] 个学分 | N、M、X |
| Scorm | 每 [N] 分钟计 [M] 个学分 | N、M |
| HTML | 每 [N] 分钟计 [M] 个学分 | N、M |

- 每行右侧**应用范围 radio 二选一**：`应用于新的{类型}` ｜ `应用于所有跟随学分策略设置的{类型}`（默认前者）。
- 课程行：纯说明文字"课程：课程学分为课件学分相加"（无输入）。
- **学分发放时间** radio 二选一：`每学完一个课件任务就会获得课件的学分`（默认）｜ `学完课程时发放所有课件的学分`。
- 两条注文案（照原平台）：
  1. 如学员已学过这个课件并获得课件的学分，那么在课程包中学习该课件不会重复获得该课件的学分
  2. 修改后已经学习课程的学员不受影响，仅针对新课程、或未学习过课程的学员生效
- **默认值**（原平台抓包）：视频/音频 10分钟/1学分；文档 1页/0.1学分/1分钟/上限6；微课 10分钟/1学分/上限10；Scorm 10分钟/1学分；HTML 10分钟/1学分；发放时间=每学完一个课件任务。
- **校验**：N/M/H/X 为正数（文档/微课的 M、X 允许小数一位）；N ≤ 1440；X ≥ M。
- **验收标准**：
  - Given 展开区块 When 页面加载 Then 五行规则与发放时间 radio 正确回显默认值
  - Given 微课最高学分填 0.5 When 应用 Then 报错"学分需为正数"且不保存
  - Given 修改文档规则为"应用于所有跟随学分策略设置的文档" When 应用 Then 保存成功且回显选中该项

### FP-02c 防挂机设置
- **功能描述**：防挂机 + 防多课程 + 禁止拖拽，一个区块一个【应用】。
- **表单项**：

| 项 | 类型 | 说明 |
|----|------|------|
| 开启防挂机功能 | toggle | 右侧蓝色"特殊设置"链接（FP-02d） |
| 说明文字 | 静态 | "系统检测到学员疑似挂机后，会弹出是否在线的弹框，让学员确认是否在学习，可配合人脸识别功能使用，开启人脸识别后，学员触发防挂机时，需要进行人脸识别" |
| 模式一（默认） | radio + 数字 | "学员在学习过程时，系统在 [N] 分钟确认学员是否在线，如不在线则停止播放" |
| 模式二 | radio + 两个数字 | "学员在学习课程时，系统在 [N] 分钟确认学员是否在线，学员需要在 [M] 秒内点击确认，如未确认本次学习无效（已学完的课程不存在回退学习进度，触发防挂机时系统会暂停播放）" |
| 确认学员是否在线提示语 | textarea ≤250 | 右下角字数统计 n/250；防挂机开启时必填非空 |
| 开启防多课程同时学习功能 | toggle | 下方说明："同一时间只对一个课程记录学习进度及学分，防止学习者同时打开多个课程学习而获得学习进度及学分" |
| 禁止拖拽学习 | toggle | 下方两条注：1. 仅对视频、音频生效；2. 开启后，学员可以在已经看过的内容区拖拽进度条（举例：视频有60分钟，学员看到了40分钟，那么可以在1-40分钟间拖拽进度） |

- **默认值**（原平台抓包）：防挂机开、模式一、N=3、M=120、提示语="已触发防挂机验证，请点击"继续学习"，否则学习将被停止"、防多课程开、禁止拖拽开。
- **校验**：N 为 1~60 整数；M 为 30~600 整数（模式二时必填）。
- **验收标准**：
  - Given 防挂机关闭 When 应用 Then 保存成功；模式/数字/提示语仍随表单保存（原样存储）
  - Given 选模式二、秒数填 10 When 应用 Then 报错"确认时限需在 30~600 秒之间"
  - Given 防挂机开、提示语清空 When 应用 Then 报错"请输入提示语"

### FP-02d 特殊设置抽屉（防挂机区块内）
- **功能描述**：点防挂机区块"特殊设置"链接，右侧弹出抽屉。
- **内容**：
  - 顶部蓝色提示条："特殊设置仅针对移动端学习生效，后台播放不会确认学员是否在线"
  - "App学习"区块：toggle "允许音频、视频课程后台播放"
  - 底部【取消】【确定】
- **保存语义**（拍板）：**确定即单独保存**该开关（`PUT /api/kng/admin/setting/special`），与防挂机区块的【应用】互不影响；取消不保存。
- **验收标准**：
  - Given 打开抽屉、开启后台播放、确定 When 重新打开 Then 开关为开，且刷新后仍为开
  - Given 打开抽屉改开关后点取消 Then 不保存

### FP-02e 课程播放设置
- **表单项**：

| 项 | 类型 | 说明 |
|----|------|------|
| 开启倍速播放功能 | toggle | |
| 使用范围 | radio 二选一 | `所有课件、课程都支持倍速播放` ｜ `跟随课件或课程各自的功能设置`（默认） |
| 倍速播放时学习时长也倍速计算 | toggle | 全局学时倍速开关（**v2.1 新增**，对应原平台 kv/multiple/conf 的 multipleStudy 字段；控制课件编辑页"学时计算"开关的上限） |

> **v2.1 修订（2026-09-30，联动勘误）**：playConf 新增 `speedHoursCalc` 字段。动机：课件管理模块的发布表单有课件级"倍速播放/学时计算"开关，需与课程播放设置做两级联动（全局关→课件级强制关禁用；范围=所有→强制开禁用；范围=跟随→可编辑），原 v2.0 漏定义了全局学时倍速开关。该字段为新增，不动旧字段，向后兼容。

- **默认值**（原平台抓包）：开 + 跟随课件或课程各自的功能设置。
- **验收标准**：Given 切换使用范围为"所有课件、课程都支持倍速播放" When 应用 Then 保存并回显正确。

### FP-02f 人脸识别设置
- **功能描述**：单开关"开启人脸识别功能（仅App端支持人脸识别）"。
- **保存语义**：**无应用按钮，切换即保存**（对齐原平台：该区块无应用按钮；开关 change 即调 `PUT /api/kng/admin/setting/face`）。
- **默认值**：关。
- **验收标准**：Given 打开开关 When 无任何其他操作 Then 立即保存；刷新后仍为开。
