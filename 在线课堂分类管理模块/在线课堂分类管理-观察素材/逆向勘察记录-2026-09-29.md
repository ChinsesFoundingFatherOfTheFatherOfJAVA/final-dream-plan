## 2. 抓包还原的真实接口

### 2.1 分类列表（树 + 统计口径）
- **POST /kng/classificate/list**
- 请求：`{"pmType":"4","collegeId":"<课堂id>"}`
- 响应：树数组（根节点=主课堂），节点字段：
  - `id` / `parentId` / `label`（分类名）/ `children[]`
  - `kngCount`（本级课件数）/ `courseCount`（本级课程数）/ `allKngCount`（含子级课件数）/ `allCourseCount`（含子级课程数）
  - `routingPath`（"010.001" 物化路径）/ `orderIndex` / `orderType`（默认课程顺序）/ `updateTime`（yyyy-MM-dd）
  - `catalogCode` / `mainCollege` / `rootPath`
- 实测：列表页"课程数"列显示 = 包含子分类时 `allKngCount`、仅当前分类时 `kngCount`（注意：列名虽叫"课程数"，实际是课件 kng 口径）
- 实测：切换口径下拉、展开/收起节点、名称搜索**均不发请求**，整棵树一次拉取后前端本地计算

### 2.2 分类详情（查看/编辑抽屉数据源）
- **POST /kng/kngCatalog/info**
- 请求：`{"collegeId":"...","id":"<分类id>","parentId":"<父分类id，一级传空>"}`
- 响应关键字段：
  - `id` / `name` / `parentId` / `parentAllName` / `routingPath` / `orderType`（默认课程顺序）
  - `permissionMode` / `extend` / `parentExtend` / `opened` / `enableAudit`
  - `catalogPermissions[]`：`{userGroupId, groupType, userGroupName, permissionTypes:"0,1,2 CSV", includeChildDept}`
    - groupType：0=superAdmin（超级管理员）、4=collegeAdmin（课堂管理员）、3=collegeUser（课堂成员）、7=自定义角色（如"培训管理员"）
    - permissionTypes 码表（confBeans 还原）：0=浏览、1=允许下载课件、2=分发、4=维护、6=App缓存课件（3/5 为平台内部码，superAdmin 持全量 0-6）
  - `confBeans[]`：权限点菜单配置 `[{permType, permName, orderIndex}]`（分发/维护/浏览/允许下载课件/App缓存课件）
  - `catalogNameConfList[]`：前后缀设置（空=未配置）
  - `createUserId` / `createFullname`（董瑞）/ `createUserName`（40023266）
- 同一抽屉打开会发两次（组件双调用，实现时可忽略）

### 2.3 移动抽屉的目标分类树
- **POST /kng/kngCatalog/tree** 请求 `{"collegeId":"...","pmType":"4"}` → 轻量树（无统计字段，kngCount/courseCount=null）
- **GET /kng/college/listWithMaintain** → `[{"id","collegeName":"主课堂","mainCollege":1,"orderIndex":0}]`（课堂下拉；我们只有一个主课堂，不做）

### 2.4 添加用户权限抽屉（选授权对象）

## 3. 页面行为实测结论

1. 列表初始只渲染一级；有子分类的行显示 ">"，点击展开（前端本地）
2. 搜索"杰克"：结果为匹配节点 + 其祖先链，整链展开显示（3级/4级行可见），前端本地过滤
3. 行可点击选中（淡蓝背景），选中态影响"新增分类/批量新增分类"抽屉的所属分类（如"主课堂/服务话术"）
4. 每行左侧有拖拽手柄（六点），原平台支持同级拖拽排序
5. "更多"悬浮菜单：删除/创建子分类/批量创建子分类/移动此分类（含课程）/移动此分类下的课程/分享
6. 查看抽屉字段：基本信息（所属分类、创建人"董瑞/40023266（创建人有该目录的所有权限）"、分类名称、默认课程顺序、前后缀设置）+ 权限设置（四类对象 × 权限点）；培训管理员行尾有"查看人员列表"链接
7. 编辑抽屉：分类名称必填（0/50）、"设为公开"开关、默认展示顺序六选项（我们只做四项）、前后缀设置（前缀勾选+输入、日期勾选+格式下拉）
8. 权限矩阵：全选（半选态）/分发/维护/浏览/允许下载课件/App缓存课件；"+ 添加用户权限"虚线按钮；三个继承选项（继承父分类权限、所有子分类继承当前分类权限、在父分类中添加当前分类权限-一键执行）
9. 批量创建子分类：textarea 缩进示例 + 填写说明（最多10级、≥1空格缩进、权限默认继承所属分类、50字以内）
10. 课程设置页（/kng/#/param/set）：学分发放 radio + 防挂机设置（开关、特殊设置链接、模式一/模式二带分钟/秒数字输入、提示语 textarea 27/250）
