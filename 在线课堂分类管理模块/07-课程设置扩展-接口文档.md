# 在线课堂（管理端）课程设置扩展接口文档

> 版本：v2.0 ｜ 日期：2026-09-30 ｜ 服务：OnlineClassroom（经网关访问）
> 配套：05-需求文档、06-技术实现方案、08-建表与迁移 SQL
> **本文件取代 v1.0 接口文档 §2.5（课程设置）**；v1.0 其余接口不变。

---

## 1. 通用约定

同 v1.0 接口文档 §1（Base URL `http://localhost:8080/api/kng`、统一响应 `{code, message, data}`、code=1 业务失败中文 message、id 字符串化）。本扩展新增枚举：

| 枚举 | 值 |
|------|-----|
| rewardType 学分发放时间 | 0 每学完一个课件任务就会获得课件的学分、1 学完课程时发放所有课件的学分 |
| mode 防挂机模式 | 1 模式一、2 模式二 |
| speedScope 倍速使用范围 | 1 所有课件、课程都支持倍速播放、2 跟随课件或课程各自的功能设置 |
| speedHoursCalc 学时倍速计算（v2.1 新增） | true/false；课件编辑页"学时计算"开关受此压制 |

## 2. 接口列表（模块：课程设置）

### FP-02a 读取课程设置（一次拉全部四块）
- **Method / Path**：`GET /api/kng/admin/setting`
- **说明**：返回四个区块的完整配置；任一块未配置时返回代码内默认值（与示例一致）。
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "scoreConf": {
      "videoAudio":   { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
      "document":     { "pagesPerScore": 1, "score": 0.1, "standardMinutes": 1, "maxScore": 6.0, "applyToAll": false },
      "microcourse":  { "standardMinutes": 10, "score": 1.0, "maxScore": 10.0, "applyToAll": false },
      "scorm":        { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
      "html":         { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
      "rewardType": 0
    },
    "cheatConf": {
      "antiIdleEnabled": true,
      "mode": 1,
      "checkMinutes": 3,
      "confirmSeconds": 120,
      "promptText": "已触发防挂机验证，请点击\"继续学习\"，否则学习将被停止",
      "multiCourseEnabled": true,
      "forbidDragEnabled": true,
      "audioBackgroundPlay": false
    },
    "playConf": { "speedEnabled": true, "speedScope": 2, "speedHoursCalc": true },
    "faceConf": { "enabled": false }
  }
}
```

### FP-02b 保存学分策略（学分策略区块【应用】）
- **Method / Path**：`PUT /api/kng/admin/setting/score`
- **请求参数**（body = scoreConf 完整对象）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| videoAudio.standardMinutes | int | 是 | 1~1440 |
| videoAudio.score | decimal | 是 | >0，一位小数 |
| videoAudio.applyToAll | boolean | 是 | false=应用于新的视频/音频，true=应用于所有跟随学分策略设置的 |
| document.pagesPerScore | int | 是 | ≥1 |
| document.score | decimal | 是 | >0 |
| document.standardMinutes | int | 是 | ≥1 标准学习时长 |
| document.maxScore | decimal | 是 | ≥score |
| document.applyToAll | boolean | 是 | 同上（文档） |
| microcourse.standardMinutes / score / maxScore / applyToAll | — | 是 | 同上（微课，maxScore≥score） |
| scorm.standardMinutes / score / applyToAll | — | 是 | 同上（Scorm） |
| html.standardMinutes / score / applyToAll | — | 是 | 同上（HTML） |
| rewardType | int | 是 | 0/1 |

- **请求示例**：

```json
{
  "videoAudio": { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
  "document": { "pagesPerScore": 1, "score": 0.1, "standardMinutes": 1, "maxScore": 6.0, "applyToAll": false },
  "microcourse": { "standardMinutes": 10, "score": 1.0, "maxScore": 10.0, "applyToAll": false },
  "scorm": { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
  "html": { "standardMinutes": 10, "score": 1.0, "applyToAll": false },
  "rewardType": 0
}
```

- **响应示例**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "文档最高学分不能低于每页学分", "data": null }`

### FP-02c 保存防挂机设置（防挂机区块【应用】）
- **Method / Path**：`PUT /api/kng/admin/setting/cheat`
- **说明**：只更新以下 7 个防挂机字段；**audioBackgroundPlay 由服务端保留原值**（该字段走 FP-02d 独立接口）。
- **请求示例**：

```json
{
  "antiIdleEnabled": true,
  "mode": 2,
  "checkMinutes": 5,
  "confirmSeconds": 90,
  "promptText": "已触发防挂机验证，请点击\"继续学习\"，否则学习将被停止",
  "multiCourseEnabled": true,
  "forbidDragEnabled": false
}
```

- **校验**：checkMinutes 1~60；mode=2 时 confirmSeconds 30~600 必填；antiIdleEnabled=true 时 promptText 非空且 ≤250 字。
- **响应示例**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "确认时限需在 30~600 秒之间", "data": null }`

### FP-02d 保存特殊设置（抽屉【确定】）
- **Method / Path**：`PUT /api/kng/admin/setting/special`
- **说明**：仅更新 cheatConf.audioBackgroundPlay。
- **请求示例**：`{ "audioBackgroundPlay": true }`
- **响应示例**：`{ "code": 0, "message": "success", "data": null }`

### FP-02e 保存课程播放设置（课程播放区块【应用】）
- **Method / Path**：`PUT /api/kng/admin/setting/play`
- **请求示例**：`{ "speedEnabled": true, "speedScope": 1, "speedHoursCalc": true }`
- **校验**：speedScope ∈ {1, 2}；speedHoursCalc 为 v2.1 新增（全局学时倍速开关，缺省 true 兼容旧数据）。
- **响应示例**：`{ "code": 0, "message": "success", "data": null }`

### FP-02f 保存人脸识别设置（开关切换即保存）
- **Method / Path**：`PUT /api/kng/admin/setting/face`
- **请求示例**：`{ "enabled": true }`
- **响应示例**：`{ "code": 0, "message": "success", "data": null }`
