## 四、Service层设计

### 4.1 TrainingProjectService (扩展)

```java
@Service
public class TrainingProjectServiceImpl extends ServiceImpl<TrainingProjectMapper, TrainingProject>
    implements TrainingProjectService {

    @Autowired
    private ScoringDimensionService scoringDimensionService;
    @Autowired
    private VirtualTrainerService virtualTrainerService;
    @Autowired
    private TrainingEdgeService trainingEdgeService;

    @Override
    @Transactional
    public Long createProject(ProjectSaveReq req) {
        // 1. 保存项目基本信息
        TrainingProject project = new TrainingProject();
        BeanUtils.copyProperties(req, project);
        project.setStatus(0); // 未发布
        project.setCreatedAt(LocalDateTime.now());
        project.setCreatedBy(getCurrentUserId());
        project.setCreatedByName(getCurrentUserName());
        save(project);

        // 2. 保存评分维度
        if (req.getScoringDimensions() != null) {
            scoringDimensionService.saveDimensions(project.getId(), req.getScoringDimensions());
        }

        // 3. 保存虚拟陪练者设置
        if (req.getVirtualTrainer() != null) {
            virtualTrainerService.saveTrainer(project.getId(), req.getVirtualTrainer());
        }

        return project.getId();
    }

    @Override
    @Transactional
    public void publishProject(Long id) {
        TrainingProject project = getById(id);
        if (project == null) throw new BizException("项目不存在");

        // 检查是否有流程节点
        List<TrainingNode> nodes = nodeMapper.selectList(
            new LambdaQueryWrapper<TrainingNode>().eq(TrainingNode::getProjectId, id)
        );
        if (nodes.isEmpty()) {
            throw new BizException("请先设置流程设计");
        }

        project.setStatus(1);
        project.setUpdatedAt(LocalDateTime.now());
        project.setUpdatedBy(getCurrentUserId());
        updateById(project);
    }

    @Override
    @Transactional
    public void saveFlow(Long projectId, FlowSaveReq req) {
        // 1. 环检测
        if (hasCycle(req.getNodes(), req.getEdges())) {
            throw new BizException("流程图中存在环，请检查连线");
        }

        // 2. 删除旧节点和连线
        nodeMapper.delete(new LambdaQueryWrapper<TrainingNode>()
            .eq(TrainingNode::getProjectId, projectId));
        trainingEdgeService.remove(new LambdaQueryWrapper<TrainingEdge>()
            .eq(TrainingEdge::getProjectId, projectId));

        // 3. 保存新节点
        Map<Long, Long> idMapping = new HashMap<>();
        for (NodeItemReq nodeReq : req.getNodes()) {
            TrainingNode node = new TrainingNode();
            BeanUtils.copyProperties(nodeReq, node);
            // 关键：前端传的 id 只是用于连线引用的临时ID，必须清空，否则会与已有节点主键冲突
            node.setId(null);
            node.setProjectId(projectId);
            nodeMapper.insert(node);
            // 记录「前端临时ID → 数据库真实ID」映射，供连线替换使用
            if (nodeReq.getId() != null) {
                idMapping.put(nodeReq.getId(), node.getId());
            }
        }

        // 4. 保存新连线（用映射表把临时ID替换为真实节点ID）
        for (EdgeItemReq edgeReq : req.getEdges()) {
            TrainingEdge edge = new TrainingEdge();
            edge.setProjectId(projectId);
            edge.setSourceNodeId(idMapping.getOrDefault(edgeReq.getSourceNodeId(), edgeReq.getSourceNodeId()));
            edge.setTargetNodeId(idMapping.getOrDefault(edgeReq.getTargetNodeId(), edgeReq.getTargetNodeId()));
            edge.setWeight(edgeReq.getWeight());
            trainingEdgeService.save(edge);
        }
    }

    private boolean hasCycle(List<NodeItemReq> nodes, List<EdgeItemReq> edges) {
        // 拓扑排序检测环
        Map<Long, List<Long>> adjacency = new HashMap<>();
        for (EdgeItemReq edge : edges) {
            adjacency.computeIfAbsent(edge.getSourceNodeId(), k -> new ArrayList<>())
                .add(edge.getTargetNodeId());
        }

        Map<Long, Integer> inDegree = new HashMap<>();
        for (NodeItemReq node : nodes) {
            inDegree.putIfAbsent(node.getId(), 0);
        }
        for (EdgeItemReq edge : edges) {
            inDegree.merge(edge.getTargetNodeId(), 1, Integer::sum);
        }

        Queue<Long> queue = new LinkedList<>();
        for (Map.Entry<Long, Integer> entry : inDegree.entrySet()) {
            if (entry.getValue() == 0) queue.add(entry.getKey());
        }

        int count = 0;
        while (!queue.isEmpty()) {
            Long nodeId = queue.poll();
            count++;
            for (Long neighbor : adjacency.getOrDefault(nodeId, Collections.emptyList())) {
                inDegree.merge(neighbor, -1, Integer::sum);
                if (inDegree.get(neighbor) == 0) queue.add(neighbor);
            }
        }

        return count != nodes.size();
    }
}
```

```java
    @Autowired
```

```java
        Map<String, Object> inputs = new HashMap<>();
        inputs.put("description", description);

        // 解析结果为节点列表
        return parseResult(outputs);
    }
}
```

#### 5.2.1 封面图片上传策略

- 前端以 `multipart/form-data` 提交项目，图片文件字段名优先识别 `coverImage`（兼容 `cover` / `file` / `image`）。
- 后端由 `ProjectFormParser` 将请求解析为 `ProjectSaveReq`，再由 `FileStorageService.saveCoverImage` 将文件落盘到服务器 `/coverImage` 目录（`app.upload.cover-image-dir` 可配置）。
- 数据库 `cover_image` 字段只存访问路径（如 `/coverImage/a1b2c3d4.png`），不存文件本身。
- `WebMvcConfig` 将 `/coverImage/**` 与 `/api/coverImage/**` 映射为该目录的静态资源。前端经网关（`/api` 前缀）访问，因此需通过 `GET {baseUrl}/api/coverImage/{filename}` 取图；直连服务时 `GET {baseUrl}/coverImage/{filename}` 亦可。
- 数据库存的是相对路径，前端展示时需拼接接口基地址（如 `http://localhost:8080/api`）；前端统一由 `resolveAssetUrl()`（`src/api/request.ts`）完成补全。
- 更新项目时若未上传新文件，`cover_image` 保留原值不变（由 `TrainingProjectServiceImpl.updateProject` 保证）。

## 六、Dify集成

### 6.1 AI话术生成Agent

**Dify工作流配置**:
- 输入: `description` (对话场景), `rounds` (对话轮次), `first_speaker` (先说话的一方，可空)
- 输出: JSON格式的节点列表
- 处理逻辑: 根据场景和轮次生成对话流程

**工作流节点链路**: `开始 → LLM生成话术（结构化输出）→ 解析话术数据（代码节点）→ 结束`

**生成结构约定（每轮一个大节点）**:

每一轮对话对应**一个**大节点，节点内同时包含陪练者一侧与学员一侧：

| 字段 | 说明 |
|------|------|
| `nodeType` | 由 `first_speaker` 决定：`trainer`（默认）为 `2`（陪练者问学员），`student` 为 `3`（学员问陪练者） |
| `nodeName` | 与 `nodeType` 对应：「陪练者问学员说」/「学员问陪练者说」 |
| `trainerQuestion` | 陪练者的话术（问句），由 LLM 生成 |
| `standardScript` | 学员的标准话术（对该轮问题的回答） |
| `keyPoints` | 学员话术要点数组，3-5 个，含 `content`/`order` |
| `analysis` | 学员话术解析 |
| `positionX`/`positionY` | 画布坐标，代码节点按轮次垂直排布 |

- LLM 只输出「轮次数组」（每轮含 `round`/`trainerQuestion`/`standardScript`/`keyPoints`/`analysis`），**不输出**开始/结束节点、节点类型与坐标。
- 代码节点负责：解析 `first_speaker` 决定大节点的 `nodeType`/`nodeName`、按 `rounds` 截断轮数、按 `kp-{轮索引}-{要点索引}` 生成要点 ID、补齐「开始 + N 轮大节点 + 结束」的完整节点列表与连线、按 `BIG_NODE_STEP=260` 计算坐标。
- `first_speaker` 取值兼容 `trainer`/`student` 及中文「陪练者」「学员」，为空时默认 `trainer`。
- 连线 `source`/`target` 为节点数组下标，保存流程时由后端映射为真实节点 ID。
- 智能体文件：`复刻话术训练模块/dify话术生成智能体_修复版.yaml`（本方案的实际来源，修改提示词后可重新导入 Dify）。

## 八、环境注意事项

### 8.1 日期反序列化使用 Jackson 3（Spring Boot 4）

本项目基于 Spring Boot 4，HTTP 消息转换器使用 **Jackson 3（`tools.jackson`）**，
而 `com.fasterxml.jackson`（Jackson 2）的 `@JsonFormat`、`@JsonDeserialize` 等注解在请求体解析时**不生效**。

因此：

- 请求体中的 `LocalDateTime` 由 `JacksonConfig` 注册的全局 `JsonMapperBuilderCustomizer` 处理，
  支持 `2026-09-15T00:00:00`（ISO）、`2026-09-15 00:00:00`（空格）、`2026-09-15`（仅日期）三种格式。
- 自定义反序列化器需实现 `tools.jackson.databind.ValueDeserializer`，
  见 `FlexibleLocalDateTimeJackson3Deserializer`。
- `FlexibleLocalDateTimeDeserializer`（Jackson 2 版）仅供 `ProjectFormParser` 中手工创建的
  Jackson 2 `ObjectMapper` 解析 FormData 使用，两者不可混用。

### 8.2 流程保存的节点主键

`saveFlow` 中前端上传的 `nodes[].id` 是**临时ID**（用于与 `edges` 建立引用），
插入前必须 `node.setId(null)` 交由数据库自增，否则会触发
`Duplicate entry '1' for key 'training_node.PRIMARY'`。
模板流程 `saveFlow` 同理。
