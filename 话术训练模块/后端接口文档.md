## 一、项目管理

### 1.1 获取项目列表

**GET** `/admin/training-project/list`

**Query参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| pageSize | int | 否 | 每页数量，默认20 |
| status | int | 否 | 状态: 0=未发布, 1=已发布 |
| projectType | int | 否 | 类型: 0=日常训练, 1=通关考试 |
| responsible | string | 否 | 负责人ID |
| keyword | string | 否 | 搜索关键词(名称) |

**响应**:
```json
{
  "code": 0,
  "data": {
    "records": [
      {
        "id": 1304796610522828850,
        "name": "AI-10话术考试",
        "projectType": 1,
        "status": 1,
        "assignType": 0,
        "startTime": "2026-04-21T00:00:00",
        "endTime": "2026-05-31T00:00:00",
        "responsiblePersonName": "管理员",
        "coverImage": "https://..."
      }
    ],
    "total": 5
  }
}
```

**POST** `/admin/training-project/{id}/nodes`

```json
{
  "nodes": [
    {
      "id": null,
      "nodeType": 1,
      "nodeName": "开始",
      "positionX": 100,
      "positionY": 100,
      "sortOrder": 0
    }
  ],
  "edges": [
    {
      "sourceNodeId": 1,
      "targetNodeId": 2,
      "weight": 1
    }
  ]

```

```json
{"code": 0, "data": null}
```

```json
{
  "code": 1,
  "message": "流程图中存在环，请检查连线"
}
```

## 四、AI功能

### 4.1 AI生成话术

**POST** `/admin/ai/generate-script`

**请求体**:
```json
{
  "description": "保险销售电话开场白，客户是年轻妈妈",
  "rounds": 5
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "nodes": [
      {"nodeType": 1, "nodeName": "开始"},
      {"nodeType": 3, "nodeName": "学员说", "standardScript": "...", "keyPoints": [...]},
      {"nodeType": 3, "nodeName": "学员说", "standardScript": "...", "keyPoints": [...]},
      {"nodeType": 4, "nodeName": "结束"}
    ],
    "edges": [
      {"source": 0, "target": 1, "weight": 1},
      {"source": 1, "target": 2, "weight": 1}
    ]
  }
}
```

### 4.2 上传文件生成话术

**POST** `/admin/ai/generate-script/upload`

**请求**: `multipart/form-data`
| 字段 | 类型 | 说明 |
|------|------|------|
| description | string | 场景描述 |
| file | file | 参考文件(PDF/docx) |
