# AI生成话术闭环升级接口文档

> 版本：v2.0（升级）｜ 日期：2026-10-08 ｜ 服务：SpeechTraining（经网关 /api/sparring 前缀，路径以 /admin/ai 开头——对齐现有 AI 接口）
> **取代 v1.0 §4.1 generate-script 与 §4.2 generate-script/upload**（旧接口处置见 §4）。
> 通用约定：{code,message,data}、code=1 中文 message、id 字符串、Dify 转发沿用现有 key 鉴权模式。

---

## 1. 接口列表

### SG-03a 本地素材抽取
- **Method / Path**：`POST /admin/ai/material/extract`（multipart/form-data）
- **参数**：`file`（.doc/.docx/.ppt/.pptx/.pps/.pdf，≤100M）
- **行为**：Tika 抽取文本，30k 字截断。
- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "fileName": "快反王2产品介绍V7.0.ppt", "text": "……抽取文本……", "truncated": false, "chars": 18234 } }
```

- **失败示例**：`{ "code": 1, "message": "不支持的文件格式", "data": null }`

### SG-03b 在线课堂文档类课件列表（选择抽屉数据源）
- **Method / Path**：`POST /admin/ai/material/kng-list?page=1&pageSize=20`
- **请求参数**（body）：`{"keyword": ""}`（名称模糊）
- **响应示例**：

```json
{
  "code": 0, "message": "success",
  "data": {
    "total": 42,
    "records": [
      { "id": "1948010293847565100", "title": "大学生培训-PRM系统宣讲", "credits": 1.7, "durationText": "17分0秒", "createdByName": "陈鑫豪" }
    ]
  }
}
```

- **说明**：仅返回 已发布+上架 且存在文档类源文件的课件（列=抽屉所需四列）。

### SG-03c 课件素材抽取
- **Method / Path**：`GET /admin/ai/material/kng-extract?coursewareId=xxx`
- **行为**：取该课件第一个文档类源文件 → Tika 抽取（同 SG-03a）。
- **响应**：同 SG-03a（fileName=源文件名）。

### SG-04 场景生成（工作流①）
- **Method / Path**：`POST /admin/ai/gen-scene`
- **请求示例**：

```json
{
  "sessionId": "f81d4fae-7dec-11d0-a765-00a0c91e6bf6",
  "description": "学员需要向客户介绍快反王2",
  "firstSpeaker": "trainer",
  "materials": [
    { "fileName": "快反王2产品介绍V7.0.ppt", "text": "……", "truncated": false }
  ]
}
```

- **firstSpeaker**：`student`｜`trainer`。
- **响应示例**：

```json
{
  "code": 0, "message": "success",
  "data": {
    "scene": "服装加工厂会议室，采购负责人刘总与缝纫设备销售专员张伟会面……",
    "trainerRole": "服装加工厂采购负责人刘总",
    "trainerProfile": "经营中小型服装加工厂，关注设备效率与成本……",
    "studentRole": "缝纫设备销售专员张伟",
    "goal": "向客户清晰介绍快反王2的核心技术、产品优势……",
    "elapsedMs": 8342
  }
}
```

### SG-05 大纲生成（工作流②）
- **Method / Path**：`POST /admin/ai/gen-outline`
- **请求示例**：

```json
{
  "sessionId": "f81d4fae-...",
  "sceneHash": "a3f5...",
  "scene": { "scene": "…", "trainerRole": "…", "trainerProfile": "…", "studentRole": "…", "goal": "…" },
  "materials": [ { "fileName": "…", "text": "…" } ]
}
```

- **说明**：`sceneHash`=场景生成返回数据（或用户编辑后数据）的摘要，服务端与会话表比对，不一致返回 code=1"场景信息已变更，请重新生成大纲"。materials 可省略（第一步的素材继续生效）。
- **响应示例**：

```json
{
  "code": 0, "message": "success",
  "data": {
    "outlines": [
      { "name": "需求确认与场景切入", "assessmentPoints": "识别客户意图，建立专业信任……", "strategy": "礼貌回应，倾听确认具体生产困难……" },
      { "name": "核心技术原理阐述", "assessmentPoints": "……", "strategy": "……" }
    ]
  }
}
```

- **说明**：默认 5 环节；用户编辑（增删改排序）发生在前端，编辑后的大纲直接传给 gen-script-v2。

### SG-07 话术生成（工作流③）
- **Method / Path**：`POST /admin/ai/gen-script-v2`
- **请求示例**：

```json
{
  "sessionId": "f81d4fae-...",
  "sceneHash": "a3f5...",
  "scene": { "…同上…" },
  "outlines": [ { "name": "需求确认与场景切入", "assessmentPoints": "…", "strategy": "…" } ],
  "language": "zh",
  "firstSpeaker": "trainer"
}
```

- **language**：`zh` 普通话｜`en` 英语。
- **firstSpeaker**（v1.1 新增）：`student`｜`trainer`——第一步选择的对话开启者**透传给 Dify 工作流③**（提示词控制第 1 轮发言结构：学员先说=第 1 轮学员主动开场+陪练者回应），同时仍用于后续 import-script 编排（大节点类型）。两处消费同一入参。
- **轮次语义（v1.2）**：每轮=一次发言交换，**发言句式不限**——陪练者发言可为陈述句（抱怨/诉求/条件），不再是"必须疑问句"；响应增加 `narration` 字段（见下）。
- **响应示例**：

```json
{
  "code": 0, "message": "success",
  "data": {
    "narration": "你是缝纫设备销售专员张伟，刘总刚走进展厅，请你主动上前开场",
    "rounds": [
      {
        "round": 1,
        "trainerQuestion": "张经理你好，之前电话里听你说这款快反王2挺适合我们……",
        "standardScript": "刘总您好，非常感谢您给我这个机会……",
        "keyPoints": [ { "content": "礼貌回应并感谢客户", "order": 1 }, { "content": "通过提问确认客户痛点", "order": 2 } ],
        "analysis": "面对客户的主动询问，不急于抛出产品参数……"
      }
    ],
    "elapsedMs": 41230
  }
}
```

- **说明**：轮数=outlines 数；语言=en 时 trainerQuestion/standardScript 为英文，keyPoints/analysis 中文。**`narration`（v1.2）**：开场旁白——firstSpeaker=student 时 AI 必填（第二人称处境+任务交代），trainer 时为空字符串。陈述句轮次示例：trainerQuestion 可为"昨天刚买的缝纫机，今天就坏了，质量太差了，我不要了"（抱怨+诉求，非疑问句）。

### SG-08 导入（编排）
- **Method / Path**：`POST /admin/ai/import-script`
- **请求示例**：

```json
{
  "sessionId": "f81d4fae-...",
  "firstSpeaker": "trainer",
  "narration": "",
  "rounds": [ { "round": 1, "trainerQuestion": "…", "standardScript": "…", "keyPoints": [ … ], "analysis": "…" } ]
}
```

- **行为**：Java 侧编排（语义=新 DSL parse_json）：firstSpeaker=student→大节点=学员问陪练者答，否则=陪练者问学员答；开始节点→各轮大节点→结束节点直线边。**v1.2：narration 非空时在开始节点与首个大节点之间插入旁白节点**（nodeType=5，nodeName="旁白"，字段 narration=文本）。返回**现有流程设计器的流程 JSON 结构**（nodes/edges，对齐前端画布既有存储格式——与旧 generate-script 响应同构）。
- **响应示例**：

```json
{
  "code": 0, "message": "success",
  "data": {
    "nodes": [ { "nodeType": 1, "nodeName": "开始", "positionX": 300, "positionY": 100 } ],
    "edges": [ { "source": 0, "target": 1, "weight": 1 } ]
  }
}
```

- **说明**：前端拿此 JSON 走现有导入落流程逻辑（不改）；BIG_NODE_STEP=260 与画布常量一致。

## 3. DDL（增量）

```sql
CREATE TABLE IF NOT EXISTS `sparring_ai_gen_record` (
  `id`          VARCHAR(32)  NOT NULL COMMENT '雪花ID',
  `session_id`  VARCHAR(64)  NOT NULL COMMENT '前端生成会话uuid',
  `step`        TINYINT      NOT NULL COMMENT '1场景 2大纲 3话术',
  `request_hash` VARCHAR(64) NOT NULL COMMENT '上一步result摘要(步骤一致性校验)',
  `request_json`  TEXT        NULL,
  `result_json`   MEDIUMTEXT  NULL,
  `created_by`  VARCHAR(32)  NULL,
  `created_at`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_session` (`session_id`, `step`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='话术训练-AI生成三步会话留痕';
```
