## 1. 通用约定

1. 响应体统一 {code, message, data}，code=0 成功，业务失败 HTTP 200 + 非零 code（后端架构总纲 第 4 节）。
2. 时间格式 yyyy-MM-dd HH:mm:ss；id 一律 string；时长单位：入参秒、出参小时（保留 2 位小数）。
3. 每域端点只返回本域字段，不返回他域数据（01-需求文档.md 第 2 节）。
4. 时间区间超过配置项 stat.home.max-range-days（默认 730 天）时截断并置 range.truncated = true（01-需求文档.md 第 5 节）。

### 1.1 公共请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| from | string | 是 | 统计开始时间，yyyy-MM-dd HH:mm:ss，含 |
| to | string | 是 | 统计结束时间，yyyy-MM-dd HH:mm:ss，含 |
| granularity | string | 否 | day / week / month，缺省 day |

### 1.2 公共响应结构（四域业务端点）

    {
      "range":    { "from": "2026-11-01 00:00:00", "to": "2026-11-17 23:59:59",
                    "granularity": "day", "truncated": false },
      "activity": { "activeUsers": 12, "activeHours": 3.45,
                    "series": [ { "bucket": "11-01", "activeUsers": 3, "activeHours": 0.5 } ] },
      "cards":    { ...本域指标... }
    }

- activity.activeUsers：本域本期去重活跃人数（判定规则见 01-需求文档.md 第 2.6 节）。
- activity.activeHours：本域本期活跃时长，小时，2 位小数。
- activity.series：按 granularity 分桶，桶标签 day/week 为 MM-DD，month 为 YYYY-MM；无数据的桶补 0，不省略。

## 2. 接口清单

### 2.1 启用人数（StaffManagement，路径 /api/sm/admin/stat/users）

GET /api/sm/admin/stat/users

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | —— | —— | 该指标不随时间区间变化（01-需求文档.md 第 2.1 节） |

响应 data：

    { "enabledUsers": 8641, "totalUsers": 8648 }

- enabledUsers：sys_user.status = 1 的记录数。
- totalUsers：sys_user 记录总数。

### 2.2 课程情况与学习趋势（OnlineClassroom，路径 /api/kng/admin/stat/home）

GET /api/kng/admin/stat/home?from=&to=&granularity=

响应 data.cards：

| 字段 | 类型 | 说明 |
|---|---|---|
| courseTotal | long | 课程总量，全量（不限区间） |
| courseNew | long | 本期新增课程数 |
| studyVisits | long | 学习人次 |
| studyHours | number | 学习时长（小时） |
| finishedVisits | long | 完成人次（study_status = 1） |
| commentCount | long | 评论数，恒 0；配置项 stat.home.comment-count-enabled 为 true 时才可能非 0，本期恒 false（DER-03） |

响应示例：

    {
      "code": 0, "message": "success",
      "data": {
        "range": { "from": "2026-11-01 00:00:00", "to": "2026-11-17 23:59:59", "granularity": "day", "truncated": false },
        "activity": { "activeUsers": 12, "activeHours": 3.45, "series": [ { "bucket": "11-01", "activeUsers": 3, "activeHours": 0.5 } ] },
        "cards": { "courseTotal": 1, "courseNew": 0, "studyVisits": 0, "studyHours": 0.00, "finishedVisits": 0, "commentCount": 0 }
      }
    }

### 2.3 项目情况与训练趋势（SpeechTraining，路径 /api/admin/stat/home）

GET /api/admin/stat/home?from=&to=&granularity=

响应 data.cards：

| 字段 | 类型 | 说明 |
|---|---|---|
| projectTotal | long | 项目总量，全量 |
| projectNew | long | 本期新增项目数 |
| coveredUsers | long | 覆盖人次，distinct project_student.user_id |
| studyVisits | long | 学习人次 |
| finishedVisits | long | 完成人次（training_session.status = 1） |
| studyRate | number | 学习率 = studyVisits / coveredUsers，0 时返回 0 |
| finishRate | number | 完成率 = finishedVisits / coveredUsers，0 时返回 0 |

### 2.4 练习活跃（AtualCombatTraining，路径 /api/act/admin/stat/home）

GET /api/act/admin/stat/home?from=&to=&granularity=

响应 data.cards：

| 字段 | 类型 | 说明 |
|---|---|---|
| practiceVisits | long | 练习人次（不含 status = ready） |
| finishedVisits | long | 完成人次（status = completed） |
| practiceHours | number | 练习时长（小时） |

### 2.5 考试情况与参考趋势（ExamService，路径 /api/exam/admin/stat/home）

GET /api/exam/admin/stat/home?from=&to=&granularity=

响应 data.cards：

| 字段 | 类型 | 说明 |
|---|---|---|
| examTotal | long | 考试总量（exam_arrange.deleted = 0，全量） |
| examNew | long | 本期新增考试数 |
| coveredUsers | long | 覆盖人次（exam_arrange_student.deleted = 0） |
| attemptVisits | long | 参考人次 |
| passedVisits | long | 通过人次（pass_status = 1） |
| passRate | number | 通过率 = passedVisits / attemptVisits，0 时返回 0 |

## 3. 枚举与时间口径

### 3.1 granularity

| 值 | 桶标签 | 使用条件 |
|---|---|---|
| day | MM-DD | 区间跨度 ≤ 62 天 |
| week | MM-DD（周一） | 63 ~ 400 天 |
| month | YYYY-MM | > 400 天 |

选择规则由前端执行（DER-01），后端只按传入值分桶。

### 3.2 status 枚举对照

| 表 | 字段 | 取值 |
|---|---|---|
| kng_study_record | study_status | 1 已完课；其余值为学习中 |
| training_session | status | 0 进行中 / 1 已完成 / 2 未完成退出 |
| act_practice_attempt | status | ready / paused / completed / cancelled / failed（字符串） |
| exam_attempt | status | 0 未开始 / 1 考试中 / 2 批阅中 / 3 已完成 / 4 已作废 |
| exam_attempt | pass_status | 0 不通过 / 1 通过 |

### 3.3 计入「参考/完成」的判定

| 域 | 计入条件 |
|---|---|
| 考试参考人次 | exam_attempt.status in (2,3) and deleted = 0 |
| 考试通过人次 | 参考条件 and pass_status = 1 |
| 在线课堂完成人次 | kng_study_record.study_status = 1 |
| 话术训练完成人次 | training_session.status = 1 |
| 实战练习完成人次 | act_practice_attempt.status = 'completed' |

### 3.4 归属时间字段

| 域 | 时间字段 |
|---|---|
| 在线课堂 | kng_study_record.start_study_time |
| 话术训练 | training_session.start_time |
| 实战训练场 | COALESCE(act_practice_attempt.started_at, created_at) |
| 测练中心 | COALESCE(exam_attempt.submit_at, created_at) |
| 课程新增 | kng_course.created_at |
| 项目新增 | training_project.created_at |
| 考试新增 | exam_arrange.created_at |

### 3.5 活跃人数的身份字段

| 域 | 去重字段 | 说明 |
|---|---|---|
| 在线课堂 | kng_study_record.user_id | sys_user.id |
| 话术训练 | training_session.user_id | 存的是 sys_user.account（TBD-02） |
| 实战训练场 | act_practice_attempt.user_id | 存的是 sys_user.id |
| 测练中心 | **exam_attempt.user_id** | 用 user_id 而非 student_id：student_id 指向 exam_arrange_student 行主键，重考会换行，按它会把人按场次数成多个（DER-13） |

## 4. 错误码

| code | HTTP | 场景 |
|---|---|---|
| 40001 | 200 | from / to 缺失或格式不是 yyyy-MM-dd HH:mm:ss |
| 40002 | 200 | from 不早于 to |
| 40003 | 200 | granularity 取值非法 |
| 40004 | 200 | 分桶数超过 stat.home.series-max-buckets |
| 40101 | 401 | 网关边缘鉴权失败（既有约定） |

补充说明：

1. 40004 的阈值来自配置项 stat.home.series-max-buckets（默认 400），与 01-需求文档.md 第 5 节一致。
2. **校验顺序固定为「参数合法性 → 区间截断 → 分桶数校验」**：先按 stat.home.max-range-days 把区间截断，再算分桶数；
   截断后仍超过上限则返回 40004，不做自动上卷（避免后端偷偷改前端选的粒度，见 DER-09）。
3. 40001~40004 在本服务内是**统计端点专用码段**；测练中心既有文档中 40002/40003/40004 另有含义，
   前端按域区分处理，不要跨域复用同一文案映射（见 DER-10）。

## 5. 与需求口径的字段映射

| 01-需求文档.md 第 2 节指标 | 接口字段 | 端点 |
|---|---|---|

| 学习人数 | data.activity.activeUsers | 第 2.2 节 |
| 学习时长(h) | data.cards.studyHours（卡片）；data.activity.activeHours（折线） | 第 2.2 节 |

| 项目总量 / 本期新增 / 覆盖人次 / 学习人次 / 完成人次 / 学习率 / 完成率 | data.cards 同名字段 | 第 2.3 节 |
| 考试总量 / 本期新增 / 覆盖人次 / 参考人次 / 通过人次 / 通过率 | data.cards 同名字段 | 第 2.5 节 |
| 活跃人数（合计） | 四域 activity.activeUsers 之和 | 第 2.2~2.5 节 |
| 活跃时长（合计） | 四域 activity.activeHours 之和 | 第 2.2~2.5 节 |
| 总学分 | 不提供 | —— |
