## 7. 四类易错边界：明确结论

### 7.1 零值（无数据域）

- **实际调用**：在线课堂 kng_study_record 全表 0 行（`SELECT COUNT(*) FROM kng_study_record` → 0，两轮均为 0），端点仍返回 `activeUsers=0, activeHours=0.00, studyVisits=0, studyHours=0.00, finishedVisits=0, commentCount=0`，series 17 个桶全 0。**结论：零值不落成 null、不省略，符合 02 §5「空数据不得显示 NaN」。**
- kng cards.studyHours 与 activity.activeHours 均为 `0.00`（BigDecimal scale=2），未出现 `0` 与 `0.00` 混用。
- act 域第二轮复算也覆盖了「有记录但时长为 0」的情形：5 条未结束记录 active_seconds 记为 0，SUM 不为 NULL（合计行返回 10570.9250 而非 NULL）。

### 7.2 除零（比率分母为 0）

- **静态推导（有代码证据）**：
  - SpeechTraining `HomeStatServiceImpl#rate`：`if (denominator <= 0) return BigDecimal.ZERO.setScale(4, HALF_UP);` → 0.0000。
  - ExamService `HomeStatServiceImpl#ratio`：`if (denominator <= 0) return BigDecimal.ZERO.setScale(4, HALF_UP);` → 0.0000。
  - 在线课堂无比率字段；act 域无比率字段。
- 现库数据下无法构造分母 0 的真实场景（project_student 全量 13 人、exam attempt 8 人次），故**分母 0 的实测缺失，仅有代码级结论**；建议后续用空库或单测覆盖（两域已有 StatService 单测分支）。
- 非零场景实测/推导：exam passRate = 0/8 = 0.0000（分子 0 不产生 NaN）；speech studyRate = 41/13 = 3.1538（>1，符合 DER-12 不封顶）。

### 7.3 区间补零（series 不省略空桶）

- **实际调用** kng day：区间 A 返回 **17** 个桶，标签 11-01…11-17 连续，无跳号 → 与区间天数一致。
- **实际调用** kng week：区间 A 返回 **4** 个桶（10-26、11-02、11-09、11-16）；区间 B month 返回 **11** 个桶（2026-01…2026-11），与月数一致。
- **实际调用** kng 累积口径（from=2000-01-01，day）：截断后 731 桶 → `40004`（DER-09「先截断再校验桶数、不自动上卷」），未静默截断。
- **静态推导 + SQL 实测**：st/exam/act 三域均在 Service 侧用「先生成全量桶键，再贴回 SQL 结果，缺桶补 0」的方式补零（HomeStatServiceImpl#buildActivity、AdminStatServiceImpl#buildActivity 用 TreeMap 预置 0），逻辑一致；act/exam 另有「桶键不在生成序列内仍返回」的分支，不会丢数据。第二轮 act 复算证实 SQL 侧只返回 7 个有数据的 day 桶（区间共 48 天），其余 41 个桶由 Service 补 0。

### 7.4 week 桶标签（DER-07：桶键=该周周一，标签 MM-DD，禁用 %x-%v）

- **实际调用** kng week（2026-11-01 为周日）：标签 `10-26 / 11-02 / 11-09 / 11-16` —— 全部是周一日期裁成 MM-DD，符合 DER-07；未出现 ISO 年周的 `2026-44` 之类写法。
- **SQL 实测**（第二轮复算 act 窗口，2026-10-01 起）：week 桶键为 `2026-10-26 / 2026-11-02 / 2026-11-09`，三个都是该周周一，标签层裁成 `10-26 / 11-02 / 11-09`。
- **SQL 侧同口径证据**（用有数据的表验证同一表达式 `DATE_SUB(dt, INTERVAL WEEKDAY(dt) DAY)`）：
  ```sql
  SELECT DATE_FORMAT(DATE_SUB(start_time, INTERVAL WEEKDAY(start_time) DAY),'%Y-%m-%d') wk, COUNT(*), COUNT(DISTINCT user_id)
  FROM training_session WHERE start_time BETWEEN '2026-11-01 00:00:00' AND '2026-11-17 23:59:59' GROUP BY wk;
  -- 2026-11-09  3  1   （2026-11-09 是周一，会话均落该周）

  SELECT d, monday FROM (SELECT DATE_FORMAT(eff,'%Y-%m-%d') d,
         DATE_FORMAT(DATE_SUB(eff, INTERVAL WEEKDAY(eff) DAY),'%Y-%m-%d') monday
         FROM (SELECT COALESCE(started_at,created_at) eff FROM act_practice_attempt …) t) x LIMIT 3;
  -- 2026-11-02  2026-11-02（周一自映射，WEEKDAY 偏移正确）
  ```
- 代码位置：四域 Service 的桶键生成（`TemporalAdjusters.previousOrSame(MONDAY)` / `minusDays(getDayOfWeek().getValue()-1)`）与各 Mapper XML 的 `date_sub(… interval weekday(…) day)` 完全同构，桶键能对上、不会多出空桶。
- **结论：DER-07 符合。**
