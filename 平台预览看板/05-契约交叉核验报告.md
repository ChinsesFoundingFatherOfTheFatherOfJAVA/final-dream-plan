## 5. 附录：校验脚本

一次性脚本（已删除，内容如下，供复查时重建）：

    # 抽取并比对六类引用
    # 1) 章节号：「XX 第 N 节」→ 目标文档标题集合
    # 2) 接口路径：接口文档 (GET|POST) /api/... ↔ 技术方案提及集合 双向比对
    # 3) 错误码：接口文档表格首列 4xxxx ↔ 全文出现集合
    # 4) 配置键：需求文档表格首列 stat.* → 技术方案/接口文档必须出现

    # 6) 编号：DER-xx / TBD-xx 引用 → 需求文档定义行
    # 附加：索引 SQL 的 ALTER TABLE 表名 → 契约引用的表名集合
