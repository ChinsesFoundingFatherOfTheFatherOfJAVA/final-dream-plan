# 复刻平台前端 - 技术实现方案

**项目名称**: 杰克数字人陪练平台前端复刻
**版本**: v1.0
**日期**: 2026-09-10
**技术栈**: Vue 3 + Vite + Element Plus + Vue Router + Pinia

---

## 一、技术选型

### 1.1 核心框架

| 技术 | 版本 | 选择理由 |
|------|------|----------|
| Vue 3 | 3.4+ | 组合式API, 更好的TypeScript支持, 性能优化 |
| Vite | 5.0+ | 快速开发服务器, 即时热更新, 优化的构建 |
| Vue Router | 4.0+ | 官方路由, 支持Hash模式, 嵌套路由 |
| Pinia | 2.0+ | 官方状态管理, 更简洁的API |
| Element Plus | 2.4+ | 丰富的UI组件, 与原平台视觉风格接近 |

**证据强度**: 🤔 基于观察推断, 原平台可能使用Vue 2 + Element UI

### 1.2 辅助库

| 技术 | 用途 | 说明 |
|------|------|------|
| ECharts | 数据图表 | 折线图、饼图、漏斗图、环形图 |
| @element-plus/icons-vue | 图标库 | Element Plus 官方图标 |
| Axios | HTTP请求 | 预留数据接口 |
| Sass/SCSS | 样式预处理 | 更灵活的样式编写 |

## 三、路由设计

### 3.1 路由配置

```typescript
// router/index.ts
import { createRouter, createWebHashHistory } from 'vue-router'

const routes = [
  // 管理端路由
  {
    path: '/',
    component: () => import('@/layouts/AdminLayout.vue'),
    redirect: '/homepage',
    children: [
      {
        path: 'homepage',
        name: 'AdminHome',
        component: () => import('@/views/admin/Home.vue'),
        meta: { title: '首页', activeMenu: 'homepage' }
      },
      {
        path: 'sparring/newmanage',
        name: 'SparringManage',
        component: () => import('@/views/admin/AICombat/index.vue'),
        meta: { title: 'AI对练', activeMenu: 'sparring' }
      },
      // ... 其他管理端路由
    ]
  },
  // 学员端路由
  {
    path: '/study',
    component: () => import('@/layouts/StudentLayout.vue'),
    redirect: '/study/userhome',
    children: [
      {
        path: 'userhome',
        name: 'StudentHome',
        component: () => import('@/views/student/MyPractice.vue'),
        meta: { title: '我的陪练', activeMenu: 'userhome' }
      },
      // ... 其他学员端路由
    ]
  },
  {
    path: '/sparring',
    component: () => import('@/layouts/StudentLayout.vue'),
    children: [
      {
        path: 'web/speech/list',
        name: 'SpeechList',
        component: () => import('@/views/student/AICombat/SpeechList.vue'),
        meta: { title: 'AI对练', activeMenu: 'speech' }
      },
      // ... 其他学员端路由
    ]
  }
]

const router = createRouter({
  history: createWebHashHistory(),
  routes
})

export default router
```

### 3.2 路由跳转实现

| 触发位置 | 跳转目标 | 实现方式 |
|----------|----------|----------|
| 管理端首页"AI对练"卡片 | `/sparring/#/newmanage` | `<router-link>` 或 `router.push()` |
| 管理员下拉"前往学员端" | `/study/#/userhome` | `router.push()` |
| 学员端顶部"AI对练" | `/sparring/#/web/speech/list` | `<router-link>` |
| 学员端顶部"我的陪练" | `/study/#/userhome` | `<router-link>` |

## 七、图表实现

### 7.1 ECharts封装

```vue
<!-- components/common/BaseChart.vue -->
<template>
  <div ref="chartRef" class="base-chart" :style="{ width, height }"></div>
</template>

<script setup lang="ts">
import { ref, onMounted, onUnmounted, watch } from 'vue'
import * as echarts from 'echarts'

interface Props {
  option: echarts.EChartsOption
  width?: string
  height?: string
}

const props = withDefaults(defineProps<Props>(), {
  width: '100%',
  height: '300px'
})

const chartRef = ref<HTMLElement>()
let chart: echarts.ECharts | null = null

onMounted(() => {
  if (chartRef.value) {
    chart = echarts.init(chartRef.value)
    chart.setOption(props.option)
  }
})

watch(() => props.option, (newOption) => {
  chart?.setOption(newOption)
}, { deep: true })

onUnmounted(() => {
  chart?.dispose()
})

// 响应式调整
const handleResize = () => chart?.resize()
window.addEventListener('resize', handleResize)
onUnmounted(() => window.removeEventListener('resize', handleResize))
</script>
```

## 十、风险与对策

### 10.1 技术风险

| 风险 | 影响 | 对策 |
|------|------|------|
| 图表库学习曲线 | 开发效率 | 提前熟悉ECharts API, 封装通用组件 |
| 响应式适配 | 移动端体验 | 优先保证桌面端, 移动端渐进增强 |
| 浏览器兼容 | 用户覆盖 | 使用Autoprefixer, 测试主流浏览器 |

### 10.2 视觉还原风险

| 风险 | 影响 | 对策 |
|------|------|------|
| 颜色偏差 | 视觉一致性 | 使用CSS变量, 统一管理颜色 |
| 间距不准确 | 布局协调 | 参考设计规范, 使用统一间距变量 |
| 字体差异 | 阅读体验 | 使用系统字体栈, 保持一致性 |

| 风险 | 影响 | 对策 |
|------|------|------|
| 首屏加载慢 | 用户体验 | 路由懒加载, 图片优化 |
| 图表渲染卡顿 | 交互流畅度 | 数据量大时使用 Canvas 渲染器 |
| 内存泄漏 | 长期稳定性 | 组件卸载时清理事件监听和图表实例 |
