## 五、技术观察

### 5.1 路由模式

- 使用Hash路由模式 (`#/`)
- 不同模块使用不同子域名路径:
  - 管理端首页: `/#/homepage`
  - AI对练: `/sparring/#/...`
  - 学员端学习: `/study/#/...`

**证据强度**: ✅ 亲见

### 5.2 UI框架推断

- 组件样式特征: 下拉菜单、按钮、卡片、分页器等
- 推断使用 Element UI 或 Element Plus
- 颜色主题: 蓝色为主色调 (#409EFF 或类似)

**证据强度**: 🤔 推断

### 5.3 布局模式

- 管理端: 顶部导航 + 左侧菜单 + 主内容区 (经典后台布局)
- 学员端: 顶部导航 + 左侧用户信息 + 主内容区 (学习平台布局)

**证据强度**: ✅ 亲见
