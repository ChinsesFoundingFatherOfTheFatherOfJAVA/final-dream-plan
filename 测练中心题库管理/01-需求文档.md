## 1. 范围与背景

复刻测练中心的**题库管理**模块（左侧菜单其余五项——组卷/考试管理/练习管理/题目反馈/字段设置——本期不做，点击进 PlaceholderPage"功能建设中"）。

核心实体链：**分类树 → 题库 → 试题（六题型）/考核点**，附正确率统计、导入导出、查重、三种建题方式、三层权限体系。

| `/exam/queslib` | 题库管理主页（左分类树+右题库列表） | 02、05 |

## 3. 功能需求

### FP-01 应用与路由骨架（QB-27）

- **功能描述**：front-end 新增 `/exam` 路由段与页面目录；后端新建 ExamService 微服务，网关路由 `/api/exam/**`。
- 侧边菜单结构照截图02：题库分组（题库管理子项）+ 五个未建设菜单项。
- **验收**：Given 登录管理端 When 点击首页"测练中心" Then 进入题库管理页且菜单渲染正确；点击"组卷"显示"功能建设中"卡片。

### FP-02 数据模型（九表，DDL 见 04）

`exam_catalog`（分类树，10级 routing_path）+ `exam_catalog_admin`（分类管理员）+ `exam_lib`（题库）+ `exam_lib_share`（共享范围：部门/人）+ `exam_question`（试题，parent_id 支持组合题子题自关联）+ `exam_question_item`（选项）+ `exam_question_point`（试题-考核点多对多）+ `exam_point`（考核点，每库唯一默认考点）+ `exam_answer_stat`（正确率轻量聚合表，数据由考试模块上线后回填）。

### FP-03 分类树区（QB-01/02/04/05，含 QB-26 分类管理员）

- **树展示与联动**：根节点"默认题库分类"+子分类；节点展开/收起；分类名搜索过滤；点击分类 → 右侧题库列表按 catalogId+routingPath 过滤。
- **新建题库分类抽屉**（截图03）：
  - 批量文本框：一行一分类、空格缩进表层级（缩进≥1空格=子级）、≤10级、一次≤50个、单名≤200字；填写须知文案照截图03（4条）。
  - 所属分类：默认根分类；若左侧已选中分类则预填该分类。
  - 权限设置：添加管理员（选人抽屉，见FP-05）+ 两个复选框（继承一级分类权限/所有子分类继承当前分类权限，各自注释文案照截图03）。
- **齿轮菜单**（悬浮子分类显示齿轮，hover 展开，截图05）：新建（同上抽屉）/编辑/删除/禁用/移动。
  - **编辑抽屉**（截图06）：只读信息（所属分类/题库数量/创建时间/创建者）+ 分类名单行输入 + 权限设置（管理员 tag 可删 + 两复选框）。
  - **移动抽屉**（截图07）：分类树单选 + 搜索；**树节点支持展开与收起（默认只展开第一层）——此前有做全展开不闭合的教训，必守**；移动=修改 parent_id 并重算 routing_path。
  - 删除/禁用：有子分类或挂有题库时删除弹确认阻止；禁用后分类置灰（子分类题库列表是否隐藏待实施时以截图05置灰行为为准）。
- **验收（Given/When/Then）**：
  - Given 批量文本输入 3 行 2 级缩进 When 确认 Then 一次创建父1子2 且层级正确。
  - Given 移动抽屉打开 When 点击父节点箭头 Then 子节点收起/展开可切换。
  - Given 分类挂有题库 When 点删除 Then 弹阻止确认。

### FP-04 题库列表区（QB-06/07/08/09/10）

- **列表字段全做**（截图02）：题库名称（链接色，保密橙色tag）/试题数（可排序）/考核点数/创建人（姓名(工号)）/更新日期（可排序）/启用状态（绿点；文字"启用"，悬浮显示"禁用"，点击切换状态）/操作（管理→详情页；更多→hover 菜单）。
- **更多菜单六项**：编辑（抽屉同新建）/删除（**非创建者置灰**，创建者点击弹确认）/正确率（跳详情页正确率tab）/共享（抽屉：只读名称分类+共享范围选人）/转移（抽屉：只读信息+原创建者+新创建人选人，所有权变更）/修改分类（分类树抽屉单选）。
- **筛选**：全部题库（全部/我创建的/共享给我的）/创建人（选人器）/启用状态/题库名称搜索/导出数据（Excel）。
- **批量操作**（勾选后）：删除、转移（统一转给一人）、修改分类；**批量分享不做**。
- **新建题库抽屉**（同截图32）：题库分类（树选择）+ 题库名称（≤200字）+ 题库保密（公开/保密单选；保密注释"仅支持创建者及超级管理员可编辑"）。
- **验收**：Given 非创建者用户 When 打开更多菜单 Then 删除项置灰不可点；Given 点击"启用" When 请求成功 Then 该行变"禁用"（状态翻转）。

### FP-05 权限体系（QB-03/26，三层）

1. **分类管理员**：exam_catalog_admin；管理员可管理该分类（增删改子分类/题库）。抽屉中"继承一级分类权限"勾选后用一级分类权限覆盖且不可改；"所有子分类继承当前分类权限"勾选后子分类权限被覆盖不可改。
2. **题库删除权**：仅创建者与超级管理员可删除；保密题库（secrecy=1）仅创建者及超管可编辑。前端置灰 + 后端校验双保险。
3. **共享范围**：exam_lib_share（部门/人两个维度）；被共享者可管理题库内试题但不可删除题库。共享抽屉"共享范围"点开选人抽屉。
- **快速选人抽屉（简化版，截图04）**：不做原平台四 tab 搜索模型；做：选择部门下拉 + 姓名/账号/工号单条件搜索 + 分页人员表格（姓名/账号/工号/部门/岗位列）+ 右侧已选回显（≤1000）。人员数据经 Dubbo 从 StaffManagement 查询。
- **验收**：Given 用户 A 把题库共享给用户 B When B 登录 Then B 可见该题库（共享给我的筛选）且更多菜单删除置灰。

### FP-06 题库详情页骨架（QB-11/13，含 QB-24 导出按钮入口）
- 页头：返回箭头 + 题库名称；右上共享题库/转移题库按钮。
- 基本信息区：题库名称/题库分类/题库保密 + 编辑基本信息链接 → 抽屉（截图32）：分类下拉（树选择）+名称+保密单选；取消/确认。
- 双 tab：试题详情（FP-07~15）/正确率（FP-16），切换下方功能按钮与列表。

### FP-07 试题列表（QB-12）

- 字段（除试题状态列，全做）：试题名称/题型/考核点（显示主考核点=关联表中 order_index 最小）/难度/创建人/创建日期/更新人/更新日期/操作（编辑/查看/删除）。
- 筛选：题型/难度/启用状态/默认考核点（多对多匹配）+ 试题名称或姓名/账号搜索。**试题状态筛选不做**。
- 操作：编辑→`/exam/quesdetail?id=`；查看→抽屉（FP-16）；删除→确认弹窗（FP-17 文案：试题删除后，需在随机试卷下手动同步试题，固定试卷不受影响）。
- 排序：创建日期/更新日期可切换排序。
- 批量：选择本页/清除所选；本期只对当前页勾选，不做跨页累加。

### FP-08 试题编辑/新建页（QB-14/16）

- **上半表单**：题库（只读）/难度级别（下拉：易/中/难）/考核点（多选下拉框，FP-09）/题型（编辑态只读；新建态六选一：单选/多选/判断/填空/问答/组合）。
- **下半表单按题型动态**：
  - 单选：题干 + 选项（A~L，拖拽排序/叉删除/+新增选项）+ 答案（单选钮，选项变化联动）
  - 多选：同单选，答案为复选
  - 判断：题干 + 正确选项内容/错误选项内容（两个文本框）+ 答案（正确/错误单选）；题干与解析使用统一富文本编辑器，可插入图片/视频/音频
  - 填空：题干（`_(n)_` 占位提示）+ 答案列表（答案1~N，增/删）+ "多个空之间的答案不分先后顺序"复选框；题干与解析使用统一富文本编辑器，可插入图片/视频/音频
  - 问答：题干 + 答案（大文本）+ 关键词列表（关键词+得分比例%，增/删）
  - 组合：题干 + 子题生成器（五个题型按钮：单选/多选/判断/填空/问答，点击追加子题表单块；子题块可收起/拖拽排序/删除）；**子题不可再嵌套组合题，组合题只有一层**（2026-10-21 决策，与 `QuesDtos` 扁平子题结构一致）
- **富文本与媒体**：题干/选项/解析统一使用富文本编辑器（WangEditor），支持图片/视频/音频插入；判断/填空题型同样支持，不再使用“视频/音频/富文本三模式”切换。媒体文件走 `/file/upload`，图片走编辑器内传。
- 右上角：保存并新增 / 保存。
- **验收**：Given 选项 A~D 删除 B When 保存 Then 选项重排 A/B/C 且答案可选项同步为 3 个；Given 题干切视频模式 When 保存后重进 Then 视频回显可播。

### FP-09 考核点管理（QB-15）

- 多选下拉框（FP-08 内嵌）：高度固定列表框（滚动）展示该题库已有考核点；点击选中（多选），选中项以 tag 形式回显输入框（可×移除）；底部"编辑"按钮。
- 编辑抽屉（截图12/13）：该题库已有考核点列表；底部"+添加考核点"→出现输入框+保存；每个考核点悬浮出现垃圾桶+铅笔图标（删除/编辑）；编辑→该行变为输入框+保存/取消；**保存即时入库**（不随试题保存）。
- 每库自动保证唯一"默认考点"（default_point=1），不可删除。
- 批量设置考核点抽屉（FP-15）：**只多选，不能编辑/新增**。

### FP-10 快速建题（QB-17）

- 入口：创建试题下拉 → 快速建题 → 详情页 tab 态切换（URL 不变）。
- 左区：格式化文本输入（≤10000字，字数统计）；"查看标准格式示例"链接 → 抽屉（截图23：规范说明 6 条 + 全部题型/单选/多选/判断/填空/问答 tab，示例文案照抄截图23）；"设为"（单选/多选/判断/填空/问答）与"难度"（易/中/难）文字按钮 → 在光标处插入 `[单选题][中]` 式标记。
- 生成试题：前端解析器逐题切分（换行分隔）→ 格式校验（题型/难度标记、答案必填、选项格式）→ 右区按序生成题目卡片；校验失败行标红提示原因，不阻断其他题。
- 右区卡片：折叠态（序号+题干摘要+题型tag+答案）+ 展开态（FP-08 同款表单，题型五选一无组合；考核点支持新增考核点入库）；每卡片可删除；底部"添加试题"（生成一个展开空卡片）+"批量操作"（勾选批量删除）；顶部状态条（"格式无误，共N题，X 单选题…"）。
- 右上角"确定录入"：批量保存所有卡片题目（含新增考核点）入当前题库。
- **验收**：Given 粘贴 3 题标准格式文本 When 点生成试题 Then 3 张卡片按序生成且状态条计数正确；Given 其中 1 题缺答案 When 生成 Then 该题标红提示、其余 2 题正常出卡。

### FP-11 AI建题（QB-18）

- 入口：创建试题下拉 → AI建题 → 同页 tab 态（左区切换为截图25形态）。
- 左区：素材文本粘贴（≤5000字）/ 本地文件上传（.doc/.docx/.ppt/.pptx/.pps/.pdf，单文件≤100MB，Tika 解析为文本）；"选择课件/选择知识"按钮**本期置灰**（tooltip"建设中"）；题型数量选择（单选/多选/判断/填空/问答各 0~35）。
- 生成试题：后端默认调 **AIGentService `exam-gen`**（DSL 仍是 `final_dream_difys/测练中心-AI出题.yml`）→ 返回题目 JSON 数组 → 右区复用 FP-10 卡片流（可编辑/删除/添加）→ 确定录入。`agent.exam-gen.provider=dify` 才回退旧工作流，同一轮不自动降级。
- **验收**：Given 粘贴 1000 字产品资料 When 设单选5多选2点生成 Then 生成 7 张卡片且题型正确（AI 生成质量不做验收硬指标）。

### FP-12 导入试题（QB-19）

- 导入试题下拉（Excel导入/Word导入）→ 抽屉（截图26）：步骤①下载模板（按钮）+ 红色警示文案照截图；步骤②拖拽/点击上传（.xlsx/.xls/.docx），系统校验数据正确性并提示错误数据。
- 模板：与导出模板同构（Excel 5 Sheet 按题型 + Word 模板），文件随应用分发（静态资源）。
- 后端 POI 逐行解析（逐行 try-catch），返回 ImportResult：成功数/失败数/逐行错误详情；**导入文本中的新考核点自动入库**。
- **验收**：Given 上传含 2 行错误数据的 xlsx When 导入 Then 返回错误行明细且正确行入库成功；Given 导入文本含新考核点 When 导入完成 Then 该考核点出现在考核点下拉中。

### FP-13 导出试题（QB-20）

- 导出试题下拉（Excel导出/Word导出），按当前筛选条件导出：
  - Excel：5 Sheet 按题型（单选/多选/填空/问答/判断），列=题目/考核点(分号分隔≤5)/难度/试题解析/正确答案(或填空顺序/答案：关键词)/答案A~I——结构与导出样例实证一致。
  - Word：按题型分节段落式：`序号、题干` → `A、选项` → `【正确答案】` → `【难易度】` → `【考核点】` → `【试题解析】`。
- 题库管理页"导出数据"：题库维度 Excel（题库名称/试题数/考核点数/创建人/更新日期/启用状态）。

### FP-14 试题查重（QB-21）

- 试题查重下拉：五题型（无组合题）；题库级查重条件状态持久化（`exam_lib.duplicate_condition` 位标记，进详情页时加载）。
- 点击题型 → 试题列表按 isDuplicate=1 过滤（重复题标记）；再次点击或切其他题型更新过滤。
- **算法（本期）**：题干文本归一化（去空格/去 HTML 标签）精确匹配即判重复；相似度算法（SimHash/编辑距离）为后续增强项，不在本期验收。

### FP-15 批量操作（QB-22）

更多操作下拉：批量启用/批量禁用/批量删除（确认弹窗）/批量换库（抽屉=截图27：新建题库按钮+分类筛选+名称搜索+题库单选列表+已选题库回显，勾选试题整体迁移）/设置考核点（抽屉=截图28：考核点多选，**不能编辑/新增**，确认后覆盖勾选试题的考核点关联）。

### FP-16 查看抽屉与正确率tab（QB-23/24）

- **查看抽屉**（截图15）：题干（含媒体渲染）/选项/答案/考点/难度/解析（蓝标签字段名）+ 更新人/更新日期 + 底部上一题/下一题（按当前列表顺序翻页）。
- **正确率tab**（截图29/30/31）：
  - 按试题统计：试题名称/题型/难度/引用次数/正解数/答题数/正确率（可排序）+筛选（题型/难度/试题名搜索）+查看→答题详情抽屉（题干+各选项占比进度条+人数+答案/难度/正确率/解析+上一题/下一题）。
  - 按考核点统计：考核点名称/试题总量/正解数六题型分列（单选/多选/判断/填空/问答/组合）/正确率（可排序）+考核点名搜索。
  - 导出数据按钮。
  - **数据来源**：exam_answer_stat 轻量聚合表；考试模块未建，上线后回填真实数据，演示阶段可插种子数据。

### FP-17 删除确认弹窗（QB-25，统一组件）

样式照截图36：橙色圆形警示图标（!）+ 标题 + 影响提示语 + 取消（白）/确定（蓝）。用于：试题删除（"试题删除后，需在随机试卷下手动同步试题，固定试卷不受影响"）/题库删除/分类删除/批量删除/禁用确认。各自文案在 03 接口文档定义。

## 4. 非功能需求

- 媒体文件（视频/音频/图片）存储 ExamService 服务器本地磁盘（`exam.files.root` 配置 + `/api/exam/files/**` 静态映射），本期不做转码。
- 富文本内容统一 HTML 存储（content 字段），纯文本摘要（summary）用于列表与查重归一化。
- 列表分页默认 10 条/页，可选 10/20/50/100。
- 全部接口走网关 `/api/exam/**`，鉴权沿用工程 token 体系。
