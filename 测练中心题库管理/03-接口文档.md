# 测练中心·题库管理复刻 接口文档

> 版本：v1.0 ｜ 日期：2026-10-12 ｜ 配套：01-需求文档.md、02-技术实现方案.md
> Base URL：`http://<gateway>:8080/api/exam` ｜ 鉴权：工程既有 token 体系（Header `token`）
> 响应包：`{ "code": 0, "message": "success", "data": { } }`，非 0 为业务失败
> 原平台真实契约参照：00b-Phase1勘察记录.md §2（抓包实证，写接口为本设计映射）

## 0. 通用约定

- 分页：query 参数 `current`（默认1）/`limit`（默认10，可选 10/20/50/100）；排序 `orderby`/`direction`（asc|desc）
- 时间格式：`yyyy-MM-dd HH:mm:ss`
- 人员引用统一：`userId` + 冗余 `userName`（工号）/`fullname`（对齐原平台响应风格）
- 媒体字段统一结构：`{ "fileId": "", "fileUrl": "/api/exam/files/xxx.mp4", "fileType": "video|audio", "fileName": "a.mp4" }`

## 1. 分类 Catalog

### 1.1 GET `/catalog/tree`
分类树（含权限合并后的管理员列表）。

```json
{ "code": 0, "data": { "id": "root", "name": "默认题库分类", "children": [
  { "id": "uuid", "name": "COE考试", "parentId": "root", "routingPath": "001",
    "libQty": 2, "childCatalogQty": 0, "disabled": 0, "orderIndex": 1,
    "users": [ { "userId": "uuid", "userName": "40020895", "fullname": "白福友", "deptName": "杰克科技股份" } ],
    "inheritParentAuth": 0, "childInheritCurrentAuth": 0, "children": null } ] } }
```

### 1.2 GET `/catalog/{id}`
分类详情（编辑抽屉）：同树节点单对象 + `createTime/createFullname/题库数量`。

### 1.3 POST `/catalog`（批量新建，抽屉确认）
```json
{ "parentId": "root", "catalogText": "分类A\n 子分类A1\n 子分类A2\n分类B",
  "adminUserIds": ["u1","u2"], "inheritParentAuth": 0, "childInheritCurrentAuth": 0 }
```
- 校验：行数≤50、缩进层级≤10、单名≤200字、父分类存在；错误返回逐行 `errors:[{line, reason}]`。
- `data`: `{ "createdCount": 4 }`

### 1.4 PUT `/catalog/{id}`（编辑）
`{ "name": "新名", "adminUserIds": [...], "inheritParentAuth": 0, "childInheritCurrentAuth": 0 }`

### 1.5 PUT `/catalog/{id}/move`
`{ "targetParentId": "uuid" }` —— 校验目标非自身子孙、层级≤10；成功后整棵子树 routing_path 重算。

### 1.6 PUT `/catalog/{id}/disable`
`{ "disabled": 1 }`

### 1.7 DELETE `/catalog/{id}`
前置校验：有子分类或有挂载题库 → `code=40001, message="分类下存在子分类或题库，无法删除"`。

## 2. 题库 Lib

### 2.1 POST `/lib/list?current=1&limit=10&orderby=updateTime&direction=desc`（分页参数在 query，筛选在 body）

```json
{ "queryType": 1, "keyword": "", "catalogId": "root", "routingPath": "",
  "creatorUserId": "", "disabled": -1 }
```
- queryType：0全部 1我创建的 2共享给我的
- 分页响应 `data = { records, total }`（`records[]` 为下列对象；ExamService 统一形状）：

```json
{ "id": "uuid", "name": "越南题目", "catalogId": "", "catalogName": "默认题库分类",
  "secrecy": 1, "defaultLib": 0, "disabled": 0,
  "pointQty": 31, "totalQuesQty": 30,
  "createUserId": "u1", "createFullname": "林婷婷", "createUserName": "40021816",
  "updateFullname": "林婷婷", "updateTime": "2026-10-09 15:26:42",
  "shared": 0,
  "permissions": { "canDelete": true, "canEdit": true } }
```
- `permissions` 由 PermissionService 按当前用户计算（前端据此控制更多菜单置灰）。

### 2.2 GET `/lib/{id}`
题库详情（详情页基本信息）：同上单对象 + `catDisabled`。

### 2.3 POST `/lib`（新建）/ PUT `/lib/{id}`（编辑基本信息，同构）
`{ "name": "题库名（≤200字）", "catalogId": "uuid", "secrecy": 0 }`
- 建库自动建"默认考点"。

### 2.4 PUT `/lib/{id}/disable`
`{ "disabled": 1 }`（启用列点击切换）

### 2.5 DELETE `/lib/{id}`
权限：仅创建者/超管（403 `code=40003 无删除权限`）。删除级联：库下试题/选项/考核点关联（逻辑删）。

### 2.6 PUT `/lib/{id}/share`
```json
{ "shares": [ { "targetType": 1, "targetId": "deptUuid" },
              { "targetType": 2, "targetId": "userUuid" } ] }
```
全量覆盖式提交。GET `/lib/{id}/share` 返回现有范围（含部门/人名称冗余）。

### 2.7 PUT `/lib/{id}/transfer`
`{ "toUserId": "uuid" }` —— 所有权转移（创建人变更）。

### 2.8 PUT `/lib/{id}/catalog`
`{ "catalogId": "uuid" }` —— 修改分类（单库）。

### 2.9 POST `/lib/batch`
`{ "action": "delete|transfer|changeCatalog", "libIds": [...], "toUserId": "", "catalogId": "" }`

### 2.10 GET `/lib/{id}/duplicate/condition`
`{ "singleStatus": 1, "multiStatus": 0, "answerStatus": 0, "fillStatus": 0, "judgeStatus": 0 }`

### 2.11 GET `/lib/export`（题库维度导出 Excel）
query 同 2.1 筛选；响应文件流 `Content-Disposition: attachment; filename=题库列表.xlsx`。

## 3. 试题 Ques

### 3.1 POST `/ques/list?limit=10&current=1&orderby=updateTime&direction=DESC`

```json
{ "libId": "uuid", "keyword": "", "type": -1, "levelType": -1,
  "disabled": -1, "pointId": "", "isDuplicate": 0 }
```
- `isDuplicate=1` 时仅返回查重命中的重复题（duplicate=1）。
- `data.datas[]`：

```json
{ "id": "uuid", "summary": "Máy may 1 kim là...", "type": 0, "levelType": 0,
  "disabled": 0, "duplicate": 0, "isMultiMediaType": 0,
  "mainPointName": "Yếu tố tạo mũi may của máy may 1 kim",
  "pointNames": "考核点1；考核点2",
  "createFullname": "林婷婷", "createUserName": "40021816", "createTime": "2026-10-09 15:25:57",
  "updateFullname": "林婷婷", "updateTime": "2026-10-09 15:25:57",
  "subQuesQty": 0 }
```

### 3.2 GET `/ques/{id}`（编辑页/查看抽屉共用）

```json
{ "id": "uuid", "libId": "uuid", "libName": "越南题目", "type": 0, "levelType": 0,
  "content": "<p>M&aacute;y may...</p>", "summary": "纯文本", "disabled": 0, "duplicate": 0,
  "stemPlay": { "fileId": "", "fileUrl": "", "fileType": "video" },
  "explainText": "解析HTML", "explainPlay": { },
  "questionItems": [ { "id": "uuid", "itemContent": "选项HTML", "answer": 1, "orderIndex": 1, "itemPlay": { } } ],
  "judgeAnswer": 0, "judgeCorrectOptionContent": "", "judgeWrongOptionContent": "",
  "answerContent": "问答题答案/填空答案换行分隔", "answerPlay": { },
  "answerKeywords": [ { "keyword": "关键词", "scoreRatio": 50 } ],
  "noOrderMark": 0,
  "points": [ { "pointId": "uuid", "name": "考核点", "orderIndex": 1 } ],
  "subQuestions": [ { "…同结构（组合题子题，不含 points/libName）" } ] }
```
- type=2 判断题读 judgeCorrectOptionContent/judgeWrongOptionContent；type=3 填空 answerContent 按行对应 `_(n)_`；type=5 组合题 subQuestions 有值。

### 3.3 POST `/ques`（新建，保存/保存并新增同接口）
body = 3.2 请求态（无 id/审计字段）；`saveAndNew` 由前端行为控制（保存成功后清空表单）。
- 校验失败 `code=40010, message="题干不能为空；选项至少2项"`（分号拼接逐项原因）。
- `data`: `{ "id": "uuid" }`

### 3.4 PUT `/ques/{id}`（编辑保存）
同 3.3；题库与题型字段忽略（不可改）。

### 3.5 DELETE `/ques/{id}`
单个删除；组合题级联删子题。确认弹窗文案由前端持有："试题删除后，需在随机试卷下手动同步试题，固定试卷不受影响"。

### 3.6 POST `/ques/batch`
`{ "action": "disable|delete|changeLib|setPoint", "quesIds": [...], "libId": "", "disabled": 1, "pointIds": [...] }`
- disable：`disabled=1` 禁用、`disabled=0` 启用（没有独立的 enable 动作）。
- changeLib：目标题库字段是 `libId`；组合题子题跟随迁移。
- setPoint：覆盖式重建勾选题的考核点关联，按 `pointIds` 顺序（第一个为主考核点）。

### 3.7 快速建题/AI建题 确定录入（无批量接口）
- **不存在 `/ques/batch-create`**：前端逐题调用 `POST /ques`，由前端汇总成功/失败条数。
- `points` 只接受已存在的 `pointId`；新考核点需先走 `POST /point/batch`。后端不会按 name 自动建点。

### 3.8 查重

- **POST `/ques/duplicate/check`**：`{ "libId": "uuid", "type": 0 }` —— 执行该题型查重并持久化 duplicate 标记与 condition 位；`data`: `{ "duplicateCount": 5 }`。
- 之后前端以 3.1 `isDuplicate=1` 拉取过滤列表。
- GET `/lib/{id}/duplicate/condition` 见 2.10。

## 4. 考核点 Point

### 4.1 GET `/point/list?libId=`
`data: [ { "id": "uuid", "name": "默认考点", "defaultPoint": 1 } ]`

### 4.2 POST `/point/batch`（编辑抽屉保存，全量覆盖）
```json
{ "libId": "uuid",
  "points": [
    { "id": "uuid", "name": "改名" },
    { "name": "新考核点" }
  ] }
```
- `id` 为空表示新增；未出现在 `points` 里的考点逻辑删除（默认考点豁免）。
- 返回 `ApiResponse<Void>`（`data: null`），不返回列表；前端保存后重新调 4.1 刷新。
- 删除考点时：清理 `exam_question_point` 关联；受影响试题若已无其他考点，自动落回该库默认考点。

## 7. AI 建题

### 7.1 POST `/ques/ai-generate`
```json
{ "materialText": "…素材文本（或文件解析后文本）", "counts": { "single": 5, "multi": 2, "judge": 0, "fill": 0, "answer": 0 } }
```
- 后端调 Dify AI出题工作流（blocking 120s）；`data`: `{ "questions": [ …QuestionDraft（3.2 请求态同构，type 无组合题） ] }`
- 失败：`code=50010, message="AI 生成失败：超时/格式错误"`。

### 7.2 POST `/file/parse`（AI建题文件上传解析，multipart）
`{ "text": "解析出的文本（Tika，≤20000字）" }`

## 10. 错误码约定

| code | 场景 |
|------|------|
| 40001 | 分类下存在子分类或题库，无法删除 |
| 40003 | 无删除/编辑权限（非创建者操作保密库等） |
| 40010 | 试题校验失败（message 内分号拼接明细） |
| 40020 | 默认考点不可删除 |
| 40030 | 分类层级超限（>10 级）/ 批量行数超限 |
| 50010 | Dify AI 生成失败 |
| 50020 | 导入文件解析异常（非模板格式/文件损坏） |

## 11. Dify「AI出题」工作流（配套资产，随实施配置）

- app name：测练中心-AI出题；mode：workflow
- start 变量：`material_text`（paragraph）、`single/multi/judge/fill/answer`（number 各 0~35）
- LLM：Qwen/Qwen3-30B-A3B-Instruct-2507（vllm），temperature 0.7
- system prompt 要点：依据素材出题、按题型数量输出、每题含 type/levelType/stem/options(单多选)/answer/keywords(问答)/analysis、不编造素材外知识
- structured_output schema：`{ "questions": [ { "type": 0-4, "levelType": 0-2, "stem": "", "options": ["",""], "answer": "A"|"ACD"|"正确"|"答案文本", "keywords": [{"keyword":"","scoreRatio":50}], "analysis": "" } ] }`
- DSL 文件随本模块交付时附于 `dify/AI出题.yml`（实施阶段由 code agent 按话术生成工作流同款模板创建）
