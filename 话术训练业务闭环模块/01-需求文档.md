# 话术训练业务闭环模块 需求文档

> 版本：v1.0（2026-09-24）
> 复刻来源：绚星云学习平台 train.chinajack.com（AI对练 → 话术训练）
> 勘察方式：浏览器逐页走查 + 网络抓包（17 个真实 API 契约，见 02 附录）+ 7 张截图 + 用户文字描述
> 定位：补齐"训练项目下发 → 学员训练 → 考核落库"业务闭环。技术基线 = 既有 SpeechTraining 模块（v1.3，含语音/评分维度/声学留存全部能力，全部保持不动）。
> 配套文档：02-技术实现方案、03-接口文档、07-DDL变更清单。

---

## 1. 范围与角色

**角色**：管理端用户（有 `sparring:manage` 权限，其中仅项目创建者可编辑该项目）、学员端用户（登录即可）。

**本模块交付四个前置能力（P1~P3+E1/E2）与三组页面功能（管理端概览 A、学员管理 B+学员详情 C、学员端 F/G/H）**，外加基本信息负责人修正（D）。

**不做的**（决策记录见附录A 疑点处置）：项目安排（按部门/岗位规则圈人，仅做单独安排手动邀请）、高级选人（用户组/导入/动态用户组）、小组管理及小组列/更换小组、消耗AI豆、催促学习、修改评分、概览页导出、人气榜。

## 2. 前置能力需求（P）

### FP-40 指派关系（P1）
- **功能描述**：新建指派关系表 `project_student`（project_id × user_id，唯一约束）。邀请学员=插入、批量删除=硬删（决策：单表+硬删）；学员被移除后其历史训练记录保留（报告仍可查，但不再出现在学员列表/统计/排名中）。
- **验收标准**：
  - Given 项目 P 已邀请学员 U When 学员端列表 Then 仅显示 P 等被指派项目；U 被移除后列表不再显示 P，但 U 的历史报告页直接访问仍可打开
  - Given 重复邀请同一学员 When 保存 Then 幂等无重复行（唯一约束兜底）
- **证据**：学员端列表实测仅见被指派的 1 个项目（sparringPages 接口只返回"复刻"）；管理端 AI-10 项目 907 人。

### FP-41 真实身份接入（P2）
- **功能描述**：学员端与管理端全面接入组织架构模块的登录体系（StaffManagement JWT + sys_user 员工表，9-23 已交付）。`UserContext` 从 mock_student_001 改为 JWT 解析（user_id=工号）；前端登录守卫与请求 token 头接入。
- **验收标准**：
  - Given 学员 U 登录 When 进入 AI对练 Then 其训练会话/报告的 user_id 为 U 的工号；不同账号互不可见对方记录
  - Given 未登录 When 访问学员端/管理端 Then 重定向登录页
- **证据**：代码 UserContext.java:32-42 mock 硬编码；组织架构模块文档（D:\JACK\plan\组织架构与角色权限模块）。

### FP-42 通关策略判定（P3）
- **功能描述**：补齐 `pass_strategy` 真实判定（当前字段无消费方，一律按"任一次达标"）：单次达标=任一报告总分≥pass_score；累计 N 次=达标次数≥pass_strategy_n；连续 N 次=按报告时间排序的最大连续达标段≥N。实时计算不落表（决策）。**仅考核类项目（projectType=考核）适用**；日常训练仍按完成标准（次数）。
- **验收标准**：
  - Given 考核项目 pass_strategy=连续3次/N=3、学员成绩序列 [达标,达标,不达标,达标,达标,达标] When 判定 Then 已达标（第 4~6 次构成连续 3 段）
  - Given 日常训练项目 When 判定 Then 沿用完成次数口径，策略字段忽略
- **证据**：原平台学员列表响应含 qualifiedTimes/qualifiedCount/consecutiveCount 字段（抓包）；我方代码 grep 无 pass_strategy 消费方。

### FP-43 权限适配与创建者私有（E1/E2）
- **功能描述**：
  - 模块级：组织架构权限体系新增权限点 `sparring:manage`（AI话术训练管理端入口），角色管理中勾选即时生效；学员端无需权限点（登录即可）。
  - 项目级：**仅创建者**可编辑/删除项目、邀请/移除学员（含概览/学员管理全部写操作入口按此显隐）；其他有 sparring:manage 权限的用户只读。后端接口双重校验（模块权限 + 创建者）。
- **验收标准**：
  - Given 用户 B 有 sparring:manage 但非项目 P 创建者 When 打开 P 的学员管理 Then 可看列表/详情，但"邀请学员/批量删除/编辑/删除项目"按钮不出现；直接调写接口 Then 返回权限错误
  - Given 创建者 A When 操作 Then 全部放行
- **证据**：用户描述（"哪怕别的用户有这个功能模块的所有权限也不能对别人的项目修改"）；组织架构模块权限表设计。

## 3. 管理端需求

### 3.1 项目详情页 - 整体概览（A，路由 `/sparring/newmanage/console/{projectId}/overview`）

#### FP-44 概览统计三卡（A1）
- **功能描述**：三张统计卡——①学员总数（副指标：实际学习人数=学习次数>0 的指派学员数）②学习次数（副指标：平均学习次数=总次数/学员总数，保留 1 位小数）③完成人数（副指标：完成率=完成人数/学员总数，百分比 1 位小数）。
- **口径**（决策）：学习次数=已生成报告的会话数（未完成退出不计次）；完成=按 FP-42 判定（日常=次数达标，考核=策略达标）。
- **验收**：Given 907 指派、72 人练过、82 次完成、72 人达标 When 打开概览 Then 907/72、82/0.1、72/7.9%（与原平台实测值同构）。

#### FP-45 学员按次平均分柱状图（A2）
- 横轴"第 n 次"（n=1..最大完成序号），纵轴平均分（0-100）；柱=该项目所有学员第 n 次训练的总分平均；悬浮提示"第 n 次\n平均分 m 分"；无数据空态文案"暂无学习数据"。

#### FP-46 学习雷达图（A3）
- **记录/总均分** tab 切换：总均分=全部报告各维度平均+总均分；记录=各学员**单次**记录的维度分（记录 tab 下可按学员切换？——**简化**：记录 tab 显示"第 1 次"的维度平均，与原平台 firstDataStatistics 语义一致）。维度=项目启用的评分维度（**动态**，含自定义维度）。
- 无数据空态。**不画 0 分雷达形**（决策）。

#### FP-47 学员活跃统计（A4）
- 折线图：横轴 00:00~23:00 整点，纵轴学习次数；口径=该会话 **start_time** 的小时分布（决策）；悬浮提示"HH:00\n学习 n 次"。

#### FP-48 概览-学员列表·学员模式（A5）+ 筛选（A7）
- 字段：姓名（禁用学员名旁"已禁用"橙色标签，取 sys_user 禁用状态）/账号/工号/部门（完整路径）/岗位/最高得分/最高排名/学习次数/学习时长(min)/完成状态（未开始/未完成/已完成）。
- 筛选：完成状态（下拉）/部门（弹窗勾选，复用组织架构部门树）/岗位（弹窗勾选）/姓名账号工号关键词。分页 10/条。
- 无数据字段显示 `--`（未开始学员得分/排名为 --，与原平台一致）。

#### FP-49 概览-学员列表·部门模式（A6）
- 字段：部门(完整路径)/学员人数/实际学习人数/参与率/总学习次数/人均学习次数/总均分/完成人数/完成率。按指派学员的部门聚合（取 deptFullName 完整路径聚合，同路径合并）。
- 分页同上。

### 3.2 项目详情页 - 学员管理（B，路由 `.../student`）

#### FP-50 学员管理列表与筛选（B1/B2）
- 字段：姓名(含禁用标签)/账号/工号/部门(完整)/岗位/学习次数/完成状态/操作(查看详情)。**不做小组列**。
- 筛选：完成状态/部门(弹窗勾选)/岗位(弹窗勾选)/**账号状态**(下拉：全部/正常/已禁用)/关键词。仅创建者可见邀请/批量删除/导出按钮（FP-43）。

#### FP-51 邀请学员（B3）
- 点击"邀请学员"弹出选人弹窗：**左侧部门树 + 右侧员工列表（姓名/账号/工号/部门/岗位）勾选 + 姓名搜索**（复用组织架构员工数据与既有弹窗多选交互，决策）；确认后插入指派表，已指派的置灰不可重复选。

#### FP-52 批量删除（B4）+ 导出数据（B5）
- 列表勾选 → 批量删除 → 二次确认 → 硬删指派行；导出=按当前筛选条件前端拉全量生成 **CSV**（UTF-8 BOM，决策）。

### 3.3 学员详情页（C，路由 `.../studentdetail?userId=xxx`）

#### FP-53 学员信息卡（C1）
- 头像（sys_user，无则首字头像）/姓名/ID(工号)/部门/岗位 + 右上完成状态章（绿色"已完成"/灰色未完成）+ 最高得分 + 排名（=该项目指派学员中该学员最高总分的名次，FP-42/排名口径）。

#### FP-54 训练分析折线图（C2）
- 横轴第 n 次，纵轴分值；**总分 + 各评分维度下拉切换**（维度动态取项目评分维度，决策）；无数据空态"学员尚未开始练习哦～"。

#### FP-55 第 n 次 tab + 雷达图 + 查看详情抽屉（C3/C4）
- 顶部"第 n 次"tab（该学员每次已完成训练），点击切换右侧雷达图（维度分=该次报告各维度分）；雷达旁"查看详情"打开**右侧抽屉**：AI 分析报告 / 对话记录两个 tab——**复用学员端报告页组件**（评分明细/对话记录/改进建议/点赞同源），容器为抽屉尺寸自适应（窄列布局，决策）；含"相比上次提升 N 分"。

#### FP-56 训练记录表（C5）
- 时间/次数/总分/各评分维度分（动态列）；分页。

### 3.4 基本信息（D）

#### FP-57 负责人=创建者
- 项目表单**删除"负责人"手填输入框**（决策）；所有展示处（管理端头部、列表）负责人固定显示创建者姓名（created_by_name）；字段 responsible_person 保留列不新写（历史数据兼容）。

## 4. 学员端需求

#### FP-58 项目列表按指派过滤（F）
- `/web/speech/list` 仅返回 **指派给我 ∩ 已发布 ∩ 时间有效** 的项目（决策）；状态筛选/已完成徽标沿用现有逻辑（徽标口径随 FP-42 更新）。

#### FP-59 练习记录页（G，路由 `/studentReport?pid={projectId}`）
- 点击详情页"我的记录-练习记录"跳转；**与管理端学员详情页（FP-53~56）同构复用**（同一页面组件，仅数据入口=当前登录学员）。原平台经一次性 code 换 token 的机制**不照抄**（我方后端直接鉴权，决策见 02）。

#### FP-60 个人排名弹窗（H）
- 详情页"个人排名"点击右侧弹窗：顶部 tab = **总分 + 各评分维度**（动态，决策）；每个 tab 独立榜单（按该维度**最高分**降序，同分同名次）；每行：名次/学员(头像+姓名+"(我)"标记)/部门/分数；支持**姓名搜索**；副标题"取学员总分最高分记录进行排名"。**仅评分榜**（不做人气榜）。
- 排名范围=该项目指派学员中的已练者（决策：未练者不进榜不计分母；已被移除指派的历史学员不进榜）。

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 权限 | 全部管理端接口校验 sparring:manage；写操作加创建者校验；学员端接口校验登录态且数据隔离（仅本人/本指派项目） |
| 性能 | 概览统计接口在 1000 指派学员量级 < 1s（SQL 聚合，不逐行内存计算） |
| 兼容 | 既有 v1.3 功能（语音/报告/评分维度）零回归；mock 学员的历史数据保留可查 |
| 字号 | 沿用工程标准（正文 14px、统计数字 28px 等） |
