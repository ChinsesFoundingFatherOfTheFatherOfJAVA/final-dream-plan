# 话术训练业务闭环模块 接口文档

> 版本：v1.0（2026-09-24）。全部接口为 SpeechTraining 工程新增/改造，信封约定 `{code, data, message}`（code=0 成功），HTTP 状态恒 200（全站既有约定）。
> 鉴权：Authorization: Bearer {JWT}（组织架构模块签发）。管理端接口需权限点 `act:speech`（当前实现同时接受 `act:template`/`act:training`，三选一即放行）；带 ⚒ 的写操作额外要求**创建者**。
> 错误码：`401001 未登录或登录已过期` / `403001 无 AI话术训练管理权限` / `403002 仅项目创建者可执行此操作` / `1 {业务错误文案}`。
> 分页约定：请求 `page`(1起)/`pageSize`(默认10)；响应 `PageResult{records, total}`（`after-end-common` 统一形状）。

## 1. 指派管理（FP-40/51/52）

### 1.1 学员管理列表（B1/B2）
- **POST** `/admin/projects/{projectId}/students/list`
- 权限：act:speech
- **请求**：
```json
{ "keyword": "", "finishStatus": null, "deptIds": [], "postIds": [], "accountStatus": null, "page": 1, "pageSize": 10 }
```
| 字段 | 类型 | 说明 |
|------|------|------|
| keyword | string | 姓名/账号/工号模糊 |
| finishStatus | int? | 0 未开始 / 1 未完成 / 2 已完成 |
| deptIds / postIds | string[] | 弹窗多选 |
| accountStatus | int? | null 全部 / 1 正常 / 0 已禁用 |

- **响应 data**：`PageResult<ProjectStudentRow>`，行结构：
```json
{ "userId": "40022966", "fullname": "周承浩", "username": "40022966", "userNo": "40022966",
  "deptFullName": "杰克科技股份->营销军团->非洲战区->渠道业务组", "positionName": "渠道销售经理",
  "userStatus": 1, "learnTimes": 1, "finishStatus": 2, "finishStatusText": "已完成",
  "highestScore": 82.3 }
```
- `userStatus`：1 正常 / 0 已禁用（前端渲染"已禁用"标签）。`highestScore` null 时返回 `--`（空数据行保留姓名等信息——UI 规范）。

### 1.2 邀请学员 ⚒
- **POST** `/admin/projects/{projectId}/students`
- **请求**：`{ "userIds": ["40022966", "40028497"] }`
- **响应**：`{ "inserted": 5, "skipped": 1 }`（已指派的跳过，幂等）
- **错误**：`1 请选择学员` / `1 学员不存在`

### 1.3 批量移除 ⚒
- **DELETE** `/admin/projects/{projectId}/students`
- **请求**：`{ "userIds": ["40022966"] }`
- **响应**：`{ "removed": 1 }`；说明：硬删指派行；该学员历史会话/报告保留（可直链访问）。

### 1.4 选人数据源（B3 弹窗）
- **GET** `/admin/projects/{projectId}/student-candidates?deptId=&keyword=&page=1&pageSize=10`
- 返回项目**未指派**的员工分页：`{ userId, fullname, username, userNo, deptFullName, positionName }`。
- 部门树复用组织架构模块既有接口（`GET /dept/tree`，不在本文档范围）。

## 2. 概览统计（A，全部 GET，权限 act:speech）

### 2.1 FP-44 三卡
- **GET** `/admin/projects/{projectId}/statistics/summary`
- **响应**：
```json
{ "totalStudentNum": 907, "learnStudentNum": 72, "totalLearnTimes": 82,
  "percapitaLearnTimes": "0.1", "completedPeoples": 72, "completionRate": "7.9%" }
```

### 2.2 FP-45 按次平均分
- **GET** `/admin/projects/{projectId}/statistics/times-averages`
- **响应**：`{ "datas": [ { "times": 1, "average": 77.41 }, { "times": 2, "average": 78.08 } ] }`（仅当前指派学员的报告；空=空态）

### 2.3 FP-46 雷达
- **GET** `/admin/projects/{projectId}/statistics/radar`
- **响应**：
```json
{ "dimensions": ["话术一致性", "表达流利", "态度积极", "表述清晰"],
  "overall": { "totalScore": 78.08, "dimScores": { "话术一致性": 76.12, "表达流利": 80.12 } },
  "first":   { "totalScore": 77.41, "dimScores": { "话术一致性": 75.07 } } }
```
- `dimensions` 动态=项目启用维度；`first`=记录 tab（第 1 次报告维度平均）；无报告时 overall/first 为 null（空态）。

### 2.4 FP-47 活跃统计
- **GET** `/admin/projects/{projectId}/statistics/active`
- **响应**：`{ "datas": [ { "hour": 0, "count": 0 }, { "hour": 1, "count": 0 }, ... ] }`（恒 24 项；会话 start_time 小时分布）

### 2.5 FP-48 学员模式列表（POST 分页筛选）
- **POST** `/admin/projects/{projectId}/statistics/students`
- **请求**：`{ "keyword": "", "finishStatus": null, "deptIds": [], "postIds": [], "page": 1, "pageSize": 10 }`
- **响应行**：
```json
{ "userId": "40022966", "fullname": "周承浩", "username": "40022966", "userNo": "40022966",
  "deptFullName": "...", "positionName": "渠道销售经理", "userStatus": 1,
  "highestScore": 82.3, "highestRank": 37, "learnTimes": 1, "learnDurationMin": 12, "finishStatus": 2, "finishStatusText": "已完成" }
```
- 未开始学员 highestScore/highestRank 为 null（前端 `--`）。

### 2.6 FP-49 部门模式列表
- **POST** `/admin/projects/{projectId}/statistics/depts`
- **请求**：`{ "deptIds": [], "page": 1, "pageSize": 10 }`
- **响应行**：
```json
{ "deptFullName": "杰克科技股份->营销军团->刺绣机战区", "studentCount": 1, "learnCount": 1,
  "participationRate": "100.0%", "totalLearnTimes": 1, "percapitaLearnTimes": "1.0",
  "averageScore": 58.3, "completedCount": 1, "completionRate": "100%" }
```

## 3. 学员详情（C，权限 act:speech；路径 userId=工号）

### 3.1 FP-53 信息卡（tops）
- **GET** `/admin/projects/{projectId}/students/{userId}/tops`
- **响应**：
```json
{ "fullname": "周承浩", "userNo": "40022966", "deptFullName": "...", "positionName": "渠道销售经理",
  "userStatus": 1, "finishStatus": 2, "finishStatusText": "已完成",
  "highestScore": 82.3, "rank": 37, "reportCount": 1 }
```

### 3.2 FP-54 训练分析折线
- **GET** `/admin/projects/{projectId}/students/{userId}/practice-analysis?dimension=`
- `dimension` 空=总分；否则维度名（须为项目启用维度）。
- **响应**：`{ "datas": [ { "times": 1, "score": 82.3, "reportId": 4, "time": "2026-05-28 13:08:31" } ] }`

### 3.3 FP-55 第 n 次列表与雷达
- **GET** `/admin/projects/{projectId}/students/{userId}/attend-record?page=1&pageSize=10`
- **响应行**（训练记录表 C5 同源）：`{ "reportId": 4, "times": 1, "time": "...", "totalScore": 82.3, "dimScores": { "话术一致性": 79.0, "表达流利": 100.0 } }`
- 雷达取该行 `dimScores` 前端组装（不单设接口；维度集合取项目启用维度，null 维度不画——口径同学员端雷达）。

### 3.4 FP-55 报告抽屉
- **GET** `/student/reports/session/{sessionId}`（**既有接口改造**：新增可选 `userId` 查询参数）
- 管理端场景传 userId：服务端校验调用者 act:speech 且 sessionId 对应会话的 user_id == userId（或放行创建者）；不传=学员端原行为（仅本人）。响应结构不变（trainerAvatar/维度明细/评语/对话记录入口全套复用）。
- 对话记录/点赞复用既有接口不变。

## 4. 学员端（F/G/H）

### 4.1 FP-58 项目列表（既有接口改造）
- **GET** `/student/projects`（契约不变）：服务端改为 `status=1 ∩ 有效期 ∩ project_student 含当前登录人`；响应字段不变（completed 徽标内部口径改走 PassStrategyService）。

### 4.2 FP-59 详情（既有接口小改）
- **GET** `/student/projects/{projectId}`：响应新增 `participantCount`（指派学员数，参与人数展示）。

### 4.3 FP-60 排名
- **GET** `/student/projects/{projectId}/rank?dimension=&keyword=`
- `dimension` 空=总分 tab；否则维度名。`keyword` 姓名过滤（可空）。
- **响应**：
```json
{ "dimensions": ["", "话术一致性", "表达流利"],
  "rankList": [ { "rankIndex": 1, "userId": "40022966", "fullname": "周承浩",
                  "deptName": "杰克科技学习平台", "score": 91.0, "isMe": false } ],
  "myRank": { "rankIndex": 1, "score": 91.0 } }
```
- 范围=当前指派学员中已生成报告者；排序=该维度（总分=training_report.total_score，维度=training_report_dimension.score）**最高分**降序，DENSE_RANK 同分并列；`myRank` 为空=我未练。

## 5. 鉴权与登录（P2，对接组织架构模块）

- **POST** `/auth/login` 等：组织架构模块既有接口（StaffManagement），本文档不重复；SpeechTraining 只消费其 JWT。
- **GET** `/me`（SpeechTraining 新增轻量接口）：`{ "userId": "40022966", "fullname": "周承浩", "permissions": ["act:speech"] }` —— 前端路由守卫用。
- 无 Authorization：dev profile 回落 mock_student_001 + WARN（联调兼容），prod profile 返回 401001。

## 6. 接口与数据模型对应

| 接口 | 主要读表 | 写表 |
|------|----------|------|
| POST /admin/projects/{id}/students/list ⚒无（只读） | project_student ⋈ sys_user + training_report/session 聚合 | — |

| DELETE /admin/projects/{id}/students ⚒ | — | project_student |
| GET .../statistics/*（6 个） | project_student ⋈ sys_user + training_report/dimension/session + scoring_dimension | — |
| GET .../students/{uid}/*（3 个） | 同上 + training_report_dimension | — |
| GET /student/reports/session/{id}?userId= | training_report + virtual_trainer | — |
| GET /student/projects（改造） | + project_student | — |
| GET /student/projects/{id}/rank | project_student + training_report(_dimension) + sys_user | — |
| GET /me | JWT claims + 权限表 | — |
