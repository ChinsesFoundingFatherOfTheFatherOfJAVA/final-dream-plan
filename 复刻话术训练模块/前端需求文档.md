### 3.3 评分维度表单

#### 3.3.1 默认维度

| 维度名称 | 默认权重 | 评分规则类型 |
|----------|----------|-------------|
| 话术一致性 | 40% | 三选一：精准逐字匹配/要点表达/混合模式 |
| 表达流利 | 10% | 分级评分(0/40/60/80/100) |
| 语速适中 | 10% | 公式计算(150-250字/分钟为满分) |
| 礼貌用语 | 10% | 分级评分(0/40/60/80/100) |
| 态度积极 | 10% | 分级评分(0/40/60/80/100) |
| 表述清晰 | 10% | 分级评分(0/40/60/80/100) |
| 违禁词 | 10% | 扣分制(每出现一次扣N分) |

#### 3.3.2 维度规则

- 所有选中维度的权重之和必须等于100%
- 每个维度可以单独启用/禁用（checkbox）
- 可以添加自定义维度
- 权重可编辑（输入框+百分号）

#### 3.3.3 话术一致性详细规则

三种模式（单选）：
1. **与标准话术精准逐字匹配**: 将学员话术和标准话术对比，按词匹配比例得分
2. **按照标准话术的要点表达即可**: 无需完全一致，仅需表达出对应要点即可（默认选中）
3. **部分话术需要精准逐字匹配，其他按照要点表达即可**: 可对每轮对话单独设置

### 4.4 流程设计页面

#### 4.4.1 无流程时的空状态

当项目还没有设置流程时，显示四种创建方式（去掉"导入数据"）：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│         [AI生成话术]  [手动创建流程]  [选择话术模板]    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**按钮说明**:
1. **AI生成话术**: 弹出表单，输入对话场景和轮次，调用Dify生成
2. **手动创建流程**: 进入空白画布，从左侧拖拽节点
3. **选择话术模板**: 选择话术模板栏目中已创建的模板

#### 4.4.2 流程图画布

**左侧节点面板**（去掉"旁白"和"话术示范"）:
```
┌──────────────────┐
│ ● 陪练者问学员    │  ← 橙色节点
│ ● 学员问陪练者    │  ← 红色节点
│ ● 结束           │  ← 绿色节点
└──────────────────┘
```

**画布区域**: 类似Dify的流程编辑器，支持：
- 拖拽节点到画布
- 节点间连线
- 缩放和平移
- 点击节点编辑右侧弹出设置

**节点类型**:

1. **开始节点** (自动存在，不可删除)
2. **陪练者问学员** (大节点，包含两个子节点)
   - 陪练者节点: 节点名称、陪练者问（文本）
   - 学员节点: 节点名称、标准话术、要点(最多10个)、解析、流转条件
3. **学员问陪练者** (大节点，包含两个子节点；画布自上而下与 type 2 相反)
   - 学员节点（上）: 节点名称、标准话术、要点(最多10个)、解析、流转条件
   - 陪练者节点（下）: 节点名称、陪练者问（文本）
4. **结束节点** (自动存在，不可删除)

**流转条件**:
- 命中任意n个要点
- 命中指定的部分要点（勾选手动增加的要点）

**连线权重**:
- 点击连线弹出配置表单
- 可设置正整数权重
- 从A节点往下流转时根据权重随机路由到下游节点

#### 4.4.3 AI生成话术

**弹出表单**:
| 字段 | 类型 | 必填 |
|------|------|------|
| 对话场景 | 文本域 | ✅ |
| 对话轮次 | 数字输入 | ✅ |
| 谁先说 | 单选（陪练者先说 / 学员先说） | ✅（默认"陪练者先说"） |

**生成规则**:
- 调用Dify智能体生成
- 每一轮对话生成一个大节点，该轮同时包含陪练者问与学员说的标准话术、要点、解析
- 大节点类型由"谁先说"决定：选"陪练者先说"则生成"陪练者问学员说"大节点；选"学员先说"则生成"学员问陪练者说"大节点
- 轮次数由用户输入的"对话轮次"决定，生成的大节点个数与之相等
- 包含开始和结束节点
- 整个流程图是一整条链（一个节点只有一个直接下游）
- 同一层可以有多个分支节点（带权重的随机路由）

## 六、公共组件需求

### 6.1 流程图编辑器 (FlowEditor.vue)

**核心组件**，类似Dify的workflow编辑器

**功能**:
- 画布渲染（支持缩放、平移）
- 节点拖拽放置
- 节点间连线
- 节点点击编辑
- 连线点击配置
- 自动布局

**推荐库**: vue-flow (基于react-flow的Vue 3版本)

### 6.2 节点组件

| 组件 | 说明 |
|------|------|
| StartNode | 开始节点 |
| EndNode | 结束节点 |
| TrainerAskNode | 陪练者问学员（大节点，包含两个子节点） |
| StudentAskNode | 学员问陪练者（大节点，包含两个子节点） |

## 九、类型定义

```typescript
// 项目类型
interface ProjectItem {
  id: string
  name: string
  type: 'train' | 'examine'  // 日常训练 | 通关考试
  status: 'draft' | 'published'  // 未发布 | 已发布
  assignType: 'project' | 'single'  // 项目安排 | 单独安排
  description: string
  code: string
  startTime: string
  endTime: string
  completionStandard: number  // 完成标准(日常训练)
  passScore: number  // 达标分数(通关考试)
  passStrategy: string  // 通关策略(通关考试)
  responsiblePerson: string
  coverImage: string
  dialogueMode: 'voice' | 'text'
  scoringDimensions: ScoringDimension[]
  virtualTrainer: VirtualTrainer
  createdBy: string
  updatedBy: string
  createdAt: string
  updatedAt: string
}

// 评分维度
interface ScoringDimension {
  id: string
  name: string
  weight: number  // 百分比
  enabled: boolean
  ruleType: 'exact' | 'keypoints' | 'mixed'  // 话术一致性专用
  scoringRule: string  // 评分规则描述
  isCustom: boolean  // 是否自定义
}

// 虚拟陪练者
interface VirtualTrainer {
  name: string
  language: string  // 普通话/粤语
  voiceId: string
  speed: number
  inputLanguage: string[]  // 学员录入语言
  forbiddenWords: string
}

// 流程节点
interface FlowNode {
  id: string
  type: 'start' | 'end' | 'trainer_ask' | 'student_ask'
  position: { x: number; y: number }
  data: {
    nodeName: string
    trainerQuestion?: string  // 陪练者问
    standardScript?: string  // 标准话术
    keyPoints?: KeyPoint[]  // 要点
    analysis?: string  // 解析
    passCondition?: PassCondition  // 流转条件
  }
}

// 要点
interface KeyPoint {
  id: string
  content: string
  order: number
}

// 流转条件
interface PassCondition {
  type: 'any_n' | 'specified'  // 命中任意n个 | 命中指定
  n?: number  // 任意n个时的n
  specifiedPointIds?: string[]  // 指定时的要点ID列表
}

// 流程连线
interface FlowEdge {
  id: string
  source: string
  target: string
  weight: number  // 权重
  label?: string
}

// 话术模板
interface TemplateItem {
  id: string
  name: string
  description: string
  permission: 'private' | 'public'
  status: 'draft' | 'withdrawn' | 'published'
  createdBy: string
  createdAt: string
}
```
