# 在线课堂 AI字幕与转码专项接口文档

> 版本：v1.0 ｜ 日期：2026-10-04 ｜ 服务：OnlineClassroom（经网关 /api/kng）
> 配套：01-需求文档.md、02-技术实现方案.md；通用约定同课件管理 v1.0。
> 本专项同时**修订**课件管理 v1.0 接口的两处行为（见 §1）。

---

## 1. 既有接口的行为修订

| 接口 | 修订 |
|------|------|
| POST /api/kng/admin/upload/merge | 合并完成时同步 ffprobe，响应增加 `mediaMeta`：`{"durationSeconds":772,"width":1920,"height":1080,"codec":"h264"}`；元数据随发布写入课件 |
| POST /api/kng/admin/courseware（发布） | 视频/音频类：响应 status=1（发布中）不变，但**驱动方**由定时模拟改为 transcode job；非媒体类响应 status=2（直接已发布） |
| GET /api/kng/admin/courseware/{id}/detail | 响应增加 `hlsPath`、`subtitlesFlag`、`mediaWidth/mediaHeight/mediaCodec` |
| 课件列表响应 | 已有 subtitlesFlag 语义转正（真实值） |

## 2. 新增接口

### MT-02/03 媒体任务查询（转码/字幕管理页共用）

#### FP-MT-04/05 分页查询媒体任务
- **Method / Path**：`POST /api/kng/admin/media/jobs?page=1&pageSize=10`
- **请求参数**（body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | int | 是 | 1 transcode（转码管理页） 2 subtitle（字幕管理页） |
| status | int | 否 | 0 pending 1 running 2 success 3 failed；**缺省=页面 tab 语义**：传 0 或 1 = 处理中 tab、传 3 = 失败 tab（前端 tab 切换传 `processing:1` 或直接两值——简化：`tab: "processing"|"failed"`，见下） |
| tab | string | 是 | `processing`（=pending+running）/ `failed` |
| keyword | string | 否 | 名称/分类/操作人 模糊 |

- **请求示例**：`{ "type": 1, "tab": "failed", "keyword": "" }`
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 1,
    "records": [
      {
        "id": "1948010293847565400",
        "jobType": 1,
        "status": 3,
        "stage": null,
        "coursewareId": "1948010293847565100",
        "coursewareTitle": "灯塔工厂方案5",
        "catalogName": "产品话术",
        "error": "ffmpeg exited with code 1: Invalid data found when processing input",
        "retryCount": 0,
        "createdByName": "董瑞",
        "createdAt": "2026-10-04 10:00:00",
        "startedAt": "2026-10-04 10:00:01",
        "finishedAt": "2026-10-04 10:00:35",
        "elapsedSeconds": 34
      }
    ]
  }
}
```

- **说明**：转码中 tab 的"已转换时间"= elapsedSeconds（running 时前端 now-startedAt 自算或 30s 轮询）；字幕管理页"开始时间"=createdAt、"操作人"=createdByName。

#### FP-MT-04/05 重试任务
- **Method / Path**：`POST /api/kng/admin/media/jobs/{id}/retry`
- **说明**：仅 status=failed 可重试；retry_count<3；subtitle 按断点 stage 续跑；重置回 pending。转码重试成功后同样驱动课件 status→已发布。
- **响应**：`{ "code": 0, "message": "success", "data": null }`
- **失败示例**：`{ "code": 1, "message": "重试次数已达上限", "data": null }`

### MT-06 播放地址

#### FP-MT-06 获取播放地址
- **Method / Path**：`GET /api/kng/admin/courseware/{id}/play`
- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "playUrl": "/kng-files/transcode/1948010293847565100/index.m3u8", "durationSeconds": 772 } }
```

- **失败示例**：`{ "code": 1, "message": "暂无可播放内容", "data": null }`（非视频/转码未完成/失败）

### MT-05 字幕读写（编辑字幕抽屉）

#### FP-MT-05a 读取字幕
- **Method / Path**：`GET /api/kng/admin/courseware/{id}/subtitles`
- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "subtitlesFlag": true,
    "languages": ["zh", "ha", "en", "vi"],
    "entries": {
      "zh": [
        { "index": 1, "beginTime": "00:00:01,100", "endTime": "00:00:02,472", "text": "我再补充几点，" },
        { "index": 2, "beginTime": "00:00:02,672", "endTime": "00:00:06,000", "text": "这份报告看看出来大家应该有个感受。" }
      ],
      "ha": [ { "index": 1, "beginTime": "00:00:01,100", "endTime": "00:00:02,472", "text": "我再補充幾點，" } ],
      "en": [ { "index": 1, "beginTime": "00:00:01,100", "endTime": "00:00:02,472", "text": "Let me add a few more points," } ],
      "vi": [ { "index": 1, "beginTime": "00:00:01,100", "endTime": "00:00:02,472", "text": "Tôi xin bổ sung thêm vài điểm," } ]
    }
  }
}
```

- **说明**：未生成时 `subtitlesFlag=false, languages:[], entries:{}`。

#### FP-MT-05b 保存字幕（按语言整份重写）
- **Method / Path**：`PUT /api/kng/admin/courseware/{id}/subtitles/{lang}`
- **lang**：zh/ha/en/vi
- **请求示例**：

```json
{ "entries": [ { "index": 1, "beginTime": "00:00:01,100", "endTime": "00:00:02,472", "text": "我再补充几点：" } ] }
```

- **说明**：整语言 SRT 重写落盘；字幕 job 活跃中调用返回 code=1"字幕生成中，稍后保存"。
- **响应**：`{ "code": 0, "message": "success", "data": null }`

#### FP-MT-05c 重新生成字幕
- **Method / Path**：`POST /api/kng/admin/courseware/{id}/subtitles/regenerate`
- **说明**：二次确认后调用；重投 subtitle job（从 asr 阶段全量重跑，覆盖现有 SRT）；已有关联活跃 job 返回 code=1。
- **响应**：`{ "code": 0, "message": "success", "data": null }`

### 字幕触发补充（编辑页开关）
课件编辑接口（PUT courseware/{id}）行为补充：ai_subtitle_enabled 从 false→true 且课件已发布且无活跃字幕 job → 自动投递 subtitle job（不需手动 regenerate）。

## 3. 接口与功能点对照

| MT | 接口 |
|----|------|
| MT-01 元数据回填 | merge 响应修订（§1） |
| MT-02 转码 job | 发布接口行为修订 + media/jobs(type=1) + retry |
| MT-03 字幕管线 | media/jobs(type=2) + retry + regenerate + 编辑接口行为补充 |
| MT-04 转码管理页 | POST /api/kng/admin/media/jobs |
| MT-05 字幕管理页/抽屉 | 同上 + GET/PUT subtitles |
| MT-06 播放 | GET .../courseware/{id}/play |

## 4. DDL（建表与增列）

```sql
CREATE TABLE IF NOT EXISTS `kng_media_job` (
  `id`            VARCHAR(32)  NOT NULL COMMENT '雪花ID',
  `job_type`      TINYINT      NOT NULL COMMENT '1 transcode 2 subtitle',
  `courseware_id` VARCHAR(32)  NOT NULL COMMENT '课件id',
  `status`        TINYINT      NOT NULL DEFAULT 0 COMMENT '0 pending 1 running 2 success 3 failed',
  `stage`         VARCHAR(20)  NULL COMMENT 'subtitle管线: asr/srt/translate; transcode为NULL',
  `progress_lang` VARCHAR(20)  NULL COMMENT '翻译阶段已完成语言CSV,断点续翻',
  `error`         VARCHAR(2000) NULL COMMENT '失败原因(stderr尾部/异常)',
  `retry_count`   INT          NOT NULL DEFAULT 0 COMMENT '上限3',
  `created_by`    VARCHAR(32)  NULL COMMENT '操作人',
  `started_at`    DATETIME     NULL,
  `finished_at`   DATETIME     NULL,
  `created_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_cw_type` (`courseware_id`, `job_type`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='在线课堂-媒体处理任务';

-- kng_courseware 增列（幂等）
ALTER TABLE `kng_courseware`
  ADD COLUMN IF NOT EXISTS `media_width`  INT          NULL COMMENT '视频宽(px)' AFTER `language`,
  ADD COLUMN IF NOT EXISTS `media_height` INT          NULL COMMENT '视频高(px)' AFTER `media_width`,
  ADD COLUMN IF NOT EXISTS `media_codec`  VARCHAR(20)  NULL COMMENT '编码格式' AFTER `media_height`,
  ADD COLUMN IF NOT EXISTS `hls_path`     VARCHAR(500) NULL COMMENT 'HLS m3u8相对路径' AFTER `media_codec`,
  ADD COLUMN IF NOT EXISTS `subtitles_flag` TINYINT    NOT NULL DEFAULT 0 COMMENT '字幕已生成' AFTER `hls_path`;

-- kng_setting 增列（历史扩展位；当前运行参数读取 application.properties，不读取该 JSON）
ALTER TABLE `kng_setting`
  ADD COLUMN IF NOT EXISTS `media_conf` JSON NULL
  COMMENT '媒体处理配置 {"asrModel":"paraformer-v2","translateModel":"qwen-flash","workerConcurrency":2}';
-- 种子可保留作兼容展示，但不得作为运行时参数来源。
```

> 注：MySQL 的 `ADD COLUMN IF NOT EXISTS` 需 8.0.29+；低版本沿用课件增补段的 information_schema 判断写法（code agent 执行时按目标库版本择一）。仓库最终脚本见 `be/OnlineClassroom/sql/v3.1-媒体处理与隐藏列.sql`。
