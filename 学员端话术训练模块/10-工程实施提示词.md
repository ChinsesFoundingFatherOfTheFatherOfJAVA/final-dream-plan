**工程铁律（历史上都踩过，违反必返工）：**

1. `application.properties` 一律**纯 ASCII**：中文 key 用 `\uXXXX` 转义，注释写英文（用户 IDEA 按 ISO-8859-1 解码会乱码，中文 map key 致 Spring 绑定失败）。
2. MyBatis-Plus：新增实体后**逐列比对 DDL**（实体字段多于表列直接 Unknown column 报错）；JSON 列用 `List<String>`/自定义 TypeHandler 时配 `@TableName(autoResultMap=true)`；`BaseMapper.insert` 有 (T)/(Collection) 重载，Mockito verify 必须写 `any(实体.class)`。
3. 前端 ID 一律 string（防 JS 长整型精度丢失）；布局遵守"height 锁死 + 整链 flex:1 + min-height:0，禁用百分比"。
4. **跨时钟纪律**：`training_session.start_time/end_time` 由 JVM 写，各表 `created_at/updated_at` 由 DB 写（UTC），两组列之间做任何时间比较都会错 8 小时。
5. 验证闸口：后端 `mvn -o test`（离线，62 例基线全绿才算过）；前端 `npx vue-tsc --noEmit`（当前 0 错，不得新增）、`npm test`（21 例基线）、`npx vite build`。**不要用 `npm run build`**（会跑全量 type-check 之外的东西且历史上被在途文件卡过）。
6. Windows 下 vitest 必须 `pool:'threads' + fileParallelism:false + isolate:false`（已配好，勿动）。
7. **不做任何 git commit**；改动文件清单在交付说明里列出。
8. 本机无 mysql CLI：执行 DDL 用临时 Java 类（JDBC + 先查 information_schema 判存在保幂等 + `~/.m2` 的 mysql-connector-j jar + Git Bash 下 classpath 用 `cygpath -w`），执行完清理临时目录（**含密码，必须清**）。
