> 目标：验证"用百炼 qwen-audio API 按录音评语气"是否可信（FP-30 / 08 §2）。
> **不改任何生产代码**；通过才立项 Phase 2（tone 指标入链路），不通过则语气维度维持"不评"。
> 产出：`poc/tone_poc.py`（评分脚本）、`poc/samples_template.csv`（补采样本模板）、本文（执行指引）。

## 1. 评测协议

- **模型**：`qwen2-audio-instruct`（百炼 OpenAI 兼容接口，key 复用 TTS 的 `dashscope.api-key`，脚本直读 application.properties，无硬编码密码）；temperature 0.1。
- **三角度**：热情 / 亲和 / 自信，单次调用只评一个角度（避免多任务互相污染）。
- **每条样本每角度评 2 次**（稳定性指标需要成对数据）。
- **评分提示词**：0-100 分 + 一句话依据，锚点 100/80/60/40/0；明确"只依据录音真实听到的语音表现，转写文本仅作内容参考"——这句是防模型只看文字猜语气的关键。
- **样本量**：存量 11 条起步（脚本自动从库里捞），补采后 30 条左右为宜。

## 3. 执行步骤

### 步骤 A：先跑存量样本（立即可做）

```
cd /d D:\JACK\plan\学员端话术训练模块\poc
py tone_poc.py --from-db
```

- 脚本自动捞 `training_round_acoustic` 关联的语音消息（读文本 + 本地 `D:\audio\asr\*.wav`），11 条 × 3 角度 × 2 次 = 66 次调用，几分钟跑完；
- 结果写 `results_时间戳.csv`；存量样本**没有好/差标注**，方向指标会 SKIP，属预期。

### 步骤 B：补采样本（关键增量，存量 11 条全是同一人同一状态，区分度天然不足）

**推荐采集方式**：直接在测试项目的训练页用语音作答——录音会自动落 `D:\audio\asr\` 且声学特征入库，采完重跑 `--from-db` 即可，零搬运。

采集目标（**人对着话筒演**，每类 7~10 条，每条 15~40 秒）：

| 类别 | 演法 | label |
|------|------|-------|
| 热情饱满 | 想象热情的销售开场，语调上扬、有笑意、主动积极 | 好 |
| 平淡念稿 | 机械照读话术，无起伏无感情 | 差 |
| 紧张急促 | 语速快、声音发紧、迟疑停顿多 | 差 |

也可以用**外部录音文件**（手机录的 wav）走 CSV 模式：复制 `samples_template.csv` 填 `file/text/label` 三列，然后：

```
py tone_poc.py --csv samples.csv
```

混合评测时，给 `--from-db` 的样本补标注：建 `labels.csv`（两列 `id,label`，id 形如 `db_46`），执行：

```
py tone_poc.py --from-db --labels labels.csv
```

### 步骤 C：汇总判定

```
py tone_poc.py --summary results_xxx.csv
```

脚本自动算三指标并给结论：

| 指标 | 达标线 | 含义 |
|------|--------|------|
| 区分度 | 每角度按中位数极差 ≥ 25 | 分数没有全挤在 70-80 一带 |
| 稳定性 | **多评取中后漂移** ≤ 10（v2 口径） | 3 次取中位数后同录音评分不漂移；原始单次差仅作观测 |
| 方向正确性 | 好 > 差 | 预判好坏与模型打分方向一致（需带 label 样本） |

## 执行记录（2026-09-24，三轮）

| 轮次 | 样本 | 结果 | 关键发现 |
|------|------|------|----------|
| 第1轮 v1 提示词 | 存量12（电脑录音复述）+ TTS音色6 | 稳定性 FAIL（13.9，最大差33） | 评语全是声学证据，分维度评价成立；TTS 证明音色不敏感 |

| 第2轮 v2 提示词 | TTS6+真人2（72次，~5元） | **稳定性 PASS（取中漂移6.2）**、方向 PASS（56.1>53.9）、区分度 FAIL（亲和极差仅20） | v2 改进生效：可数判据锚点（80-100=3处+特征贯穿全程等）+庄重不扣分纪律+3次取中。**FAIL 是样本问题非模型问题：无真人差样本（机械念稿/冷漠），亲和维度无对照两端** |

### v2 提示词要点（已固化在 tone_poc.py）
- 锚点可数化：80-100=特征≥3处且贯穿全程；60-79=1~2处；40-59=基本缺失但表达完整；0-39=相悖
- 风格纪律：庄重/沉稳/从容不扣分，按与角度契合度计（演讲样本 78/85/92 收敛验证有效）
- 输出 evidence 而非 reason：先列数到的特征条数再给分
- `--runs` 默认 3（奇数取中位数）；`--model` 可换（跨模型结果不可比）

## 5. 已知边界（如实记录，不装完美）

- 存量 11 条的实际内容是"陪练者问句的复述"（09 §H.2 冒烟时录的），说话状态单一，**它们只能验证链路与稳定性，区分度要靠补采样本**；
- 一段录音 ≤ 60s（训练页录音上限），qwen-audio 的输入限制远高于此，无压力；
- ASR 文本随录音一起送模型，但提示词已约束"以听到的为准"——若评审发现模型评语只提文字不提语音表现，记下来，这是调提示词的第一信号。
