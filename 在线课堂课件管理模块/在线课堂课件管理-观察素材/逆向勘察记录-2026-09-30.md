## 2. 抓包还原的真实接口（读操作）

### 2.1 课件列表
- **POST /kng/knowledge/courseWarelist?limit=10&offset=0&orderBy=updateTime&orderType=desc**
- 请求体（点分类树"服务话术"后实测）：
```json
{"status":null,"type":null,"title":null,"catalogId":"<分类id>","collegeId":"<课堂id>","includeChildCatalog":1,
"onSale":null,"visiable":null,"lockedOut":null,"expired":null,"distributeSourceType":null,"envFlag":null,
"quote":null,"shareFlag":null,"hasTag":null,"dataPermissionCode":"View_courseware_scope","navCode":"kng_courseware_mgmt"}
```
- 响应：`{"datas":[{...课件行...}]}`，行关键字段：
  - `id`（课件id）/ `title` / `type`（类型码）/ `fileType`（"xuanyes"微课/"video"/"pdf"等文件形态）
  - `status`（4=已发布，抓包实见）/ `updateTime`（yyyy-MM-dd HH:mm:ss）/ `studyCount`（学习人数）
  - `onSale`（上下架）/ `visiable`（隐藏）/ `lockedOut`（锁定）/ `shareFlag` / `uniqueCode`（平台课程编号 ZXKT...）
  - `createFullname`/`createUserId`（上传者）/ `catalogId`/`catalogName` / `coverUrl` / `subtitlesFlag`（有无字幕，编辑字幕入口判定）
  - `studyHours`/`studyScore`（学时/学分）/ `price` / `recommendLevel`（推荐系数）/ `version` / `code`
- 筛选参数→请求位映射：类型=`type`、课件状态=`status`、搜索=`title`、更多筛选的 上架=`onSale`、隐藏=`visiable`、锁定=`lockedOut`、来源=`distributeSourceType`、环境=`envFlag`、被引用=`quote`、标签=`hasTag`（上传/更新时间区间推测走额外字段，未实证）

### 2.2 课件详情
| 接口 | 说明 |
|------|------|
| GET /kng/knowledge/detail/info/{kngId} | 详情主数据：title/type/fileType/catalogId/catalogName/coverUrl/studyHours/studyScore/price/author/lectures(主讲)/counseLorteacher(辅讲)/contributor(贡献者)/description/shareEnabled/noIframe(展示模式) 等 |
| GET /kng/knowledge/getcatalogallpath?cataLogId= | 分类全路径 `{"cataLogAllPath":"服务话术"}` |
| GET /kng/attribute/kng/info?kngId=..&type=0 | 课程属性配置（课程属性设置区块产物，我们不做该配置→不需要） |
| POST /kng/ulcd/kngs | 按ids批量查课件状态（列表/详情联动，可不用） |
| GET /kng/visitor/kng/config/{kngId} | 游客访问配置（不做） |

### 2.3 学习详情 tab
- **POST /kng/knowledge/study/info?limit=10&offset=0**
- 请求：`{"deptId":"","finishMethod":"","name":"","id":"<kngId>","studyStatus":"","courseId":"","hasChild":0}`
- 响应行：name/userName/deptName/post/studyStatus(2=学习中,1=已完课实见)/startStudyTime("yyyy-MM-dd HH:mm")/endStudyTime/studyLen(小时,h)/finishCost(完课用时,天)/finishMethod(2=自学实见)/studySchedule(%)/deptFullName(链路)
- 部门选择：GET /udp/depts/tree（同选人抽屉，scope 参数不同）

### 2.4 学习数据 tab
| 接口 | 响应 |
|------|------|
| GET /kng/study/data/overview/{kngId} | `{"numOf7days":0,"numOftotal":3,"numOfFinish":2}` |
| GET /kng/student/finish/time/overview/{kngId} | `{"numInOneDay":2,"numInOneWeek":0,"numInOneMon":0,"numInThreeMon":0,"numInMoreThrMon":0}` |
| GET /kng/deptment/firstLevel/list | 一级部门（图表部门筛选） |
| POST /kng/deptment/finish/data/overview | `{"deptIds":[],"kngId"}` → 按部门学习/完课人数 |

### 2.5 列表页下拉枚举（DOM 实测）
- 类型：全部类型｜文档｜视频｜音频｜压缩文件｜微课｜SCORM｜HTML｜外链课（与用户口径一致）
- 课件状态（实测全量）：未发布｜发布中｜已发布｜发布失败｜待审核｜审核未通过｜被举报｜已下架（含审核/举报中间态；用户指定只做 未发布/发布中/已发布/已下架 四态）
- 排序：更新日期/学习人数 可排序（query orderBy/orderType）
- 分页：limit/offset + 条/页下拉（10/20/30/40 实见）

- 发布课件下拉（截图11）：本地上传（上传文件/SCORM课件/HTML课件）｜外部链接｜从应用选择（从知识库选择/发表微课）｜米粒客户端（不做）
- 上传后表单页（截图13/15/16）：左侧锚点导航（上传文件/基本信息/相关方信息/权限设置/功能设置）点击滚动定位
- 下架弹窗（截图9）：警告文案 + 倒计时按钮"下架(2s)"
- 批量操作菜单（截图18）：上架/下架/移动/删除（注意：用户指定做这四项；原平台另有 设置浏览权限等，不做）
- 更多筛选（截图19）：做 是否上架/是否被课程引用/上传时间/更新时间；不做 是否隐藏/是否锁定/来源/环境/是否设置标签
- 筛选面包屑（截图20）：小标签样式，用户要求信息写详细（如"是否上架：是"），可叉掉
- 转码管理/字幕管理（21~24）：独立页、双 tab、搜索框、空态"暂无数据"
