# 在线课堂（管理端）课件管理复刻接口文档

> 版本：v1.0 ｜ 日期：2026-09-30 ｜ 服务：OnlineClassroom（经网关 /api/kng）
> 配套：01-需求文档.md、02-技术实现方案.md、04-建表与种子数据.sql
> 通用约定同分类管理 v1.0 接口文档 §1（{code,message,data}、code=1 中文 message、page 从 1 起、id 字符串）。

---

## 1. 通用约定（本模块增量）

**分页/排序（query，对齐原平台 courseWarelist 形态）**：`page`（从1）、`pageSize`（默认10）、`orderBy`（updateTime|studyCount）、`orderType`（asc|desc）。

**枚举**：见需求文档 §2。原平台映射：原 status=4(已发布)→我们 2；原 type 保持数值语义重排为 1~8。

## 2. 接口列表

### 2.1 课件列表（CW-02~06）【参照原平台抓包 POST /kng/knowledge/courseWarelist】

#### FP-CW-02 分页查询课件列表
- **Method / Path**：`POST /api/kng/admin/courseware/list?page=1&pageSize=10&orderBy=updateTime&orderType=desc`
- **请求参数**（body，全部可空；空=不参与筛选）：

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 名称/分类名/上传者 三字段 OR 模糊 |
| type | int | 课件类型 1~8 |
| status | int | 0未发布 1发布中 2已发布 3已下架 |
| catalogId | string | 分类树选中节点；空=全部分类 |
| includeChildCatalog | int | 1包含子分类（默认）0仅当前分类 |
| onSale | int | 是否上架 0/1（更多筛选） |
| quoted | int | 是否被课程引用 0/1（当前恒无引用；引用表接入后生效） |
| uploadTimeStart / uploadTimeEnd | string | yyyy-MM-dd（含边界） |
| updateTimeStart / updateTimeEnd | string | yyyy-MM-dd |

- **请求示例**：

```json
{
  "keyword": "灯塔",
  "type": 2,
  "status": 2,
  "catalogId": "1948010293847565020",
  "includeChildCatalog": 1,
  "onSale": 1,
  "uploadTimeStart": "2026-09-01",
  "uploadTimeEnd": "2026-09-30"
}
```

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 218,
    "records": [
      {
        "id": "1948010293847565100",
        "title": "灯塔工厂方案5",
        "type": 2,
        "typeDesc": "视频",
        "catalogId": "1948010293847565011",
        "catalogName": "产品话术",
        "status": 2,
        "statusDesc": "已发布",
        "onSale": 1,
        "updateTime": "2026-09-29 18:20:11",
        "studyCount": 1,
        "platformNo": "ZXKT202609290003",
        "coverUrl": "/kng-files/202609/abc123.png",
        "createdByName": "董瑞"
      }
    ]
  }
}
```

- **说明**：`studyCount` 由 kng_study_record 实时聚合（当前恒 0）；列表筛选"是否上架"对应 onSale。

```json
    "catalogId": "1948010293847565011",
    "catalogPath": "产品话术/杰克",
    "status": 2,
    "platformNo": "ZXKT202609290003",
    "standardMinutes": 12,
    "standardSeconds": 52,
    "standardDurationFollow": false,
    "studyScore": null,
    "studyScoreCalc": 1.29,
    "finishStandardPercent": 100,
    "description": "<p>视频简介</p>",
    "coverUrl": "/kng-files/202609/abc123.png",
    "code": "",
    "versionStr": "1.0",
    "viewPermission": 1,
    "downloadEnabled": true,
    "downloadPermission": 1,
    "appSaveEnabled": true,
    "appSavePermission": 1,
    "speedEnabled": true,
    "speedHoursCalc": true,
    "aiSubtitleEnabled": false,
    "contributor": { "userId": "3001", "name": "董瑞", "account": "40023266" },
    "createdByName": "董瑞",
    "createTime": "2026-09-29 18:20:11",
    "updateTime": "2026-09-29 18:20:11",
    "files": [
      { "id": "1948010293847565101", "fileName": "灯塔工厂方案5.mp4", "fileSize": 734003200, "language": "zh", "storagePath": "/kng-files/202609/a1b2.mp4" }
    ],
    "attachments": [
      { "id": "1948010293847565102", "fileName": "配套PPT.pdf", "fileSize": 2097152 }
    ]
  }
}
```

- **说明**：`studyScore=null` 表示跟随学分策略；**`studyScoreCalc` 为后端按 `kng_setting` 的 score_conf 实时换算的学分值**（前端跟随时显示"N 学分（跟随学时学分策略）"），换算规则：
  - 视频/音频：`标准时长(分) ÷ videoAudio.standardMinutes × videoAudio.score`（如 12.87分÷10×1.0=1.29）
  - 文档/压缩/HTML：`标准时长(分) ÷ document.standardMinutes × document.score`（页数口径的时长折算简化，**推断**，媒体解析后切页数口径）
  - SCORM：按 scorm 块同公式；外链课恒 0
  - 单独设置时 `studyScoreCalc = studyScore`；策略修改后全局跟随课件自动重算（实时，无快照）
- **说明**：`standardDurationFollow=true` 表示标准时长跟随学分策略（本次仅存储，页数换算待媒体解析）；`catalogPath` 由后端拼全路径（合并原平台 getcatalogallpath 请求）。

### 2.3 上传（CW-10/11）【自行设计，分片协议】

#### FP-CW-10a 初始化上传（含秒传）
- **Method / Path**：`POST /api/kng/admin/upload/init`
- **请求**：

```json
{ "fileName": "灯塔工厂方案5.mp4", "fileSize": 734003200, "md5": "e10adc3949ba59abbe56e05f20f883e", "chunkSize": 5242880, "totalChunks": 140 }
```

- **响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "uploadId": "f81d4fae-7dec-11d0-a765-00a0c91e6bf6",
    "uploadedChunks": [0, 1, 2],
    "instant": false,
    "storagePath": null
  }
}
```

- **说明**：md5 命中已完成文件 → `instant=true` 且直接返回 storagePath（秒传）；`uploadedChunks` 供断点续传。

#### FP-CW-10b 上传分片
- **Method / Path**：`POST /api/kng/admin/upload/chunk?uploadId=...&chunkIndex=13`（multipart/form-data，字段 file）
- **响应**：`{ "code": 0, "message": "success", "data": null }`；分片序号不连续返回 code=1"分片序号错误"。

#### FP-CW-10c 合并
- **Method / Path**：`POST /api/kng/admin/upload/merge`
- **请求**：`{ "uploadId": "f81d4fae-...", "fileName": "灯塔工厂方案5.mp4" }`
- **响应**：

```json
{ "code": 0, "message": "success", "data": { "storagePath": "/kng-files/202609/a1b2c3.mp4", "fileSize": 734003200 } }
```

### 2.4 发布与保存（CW-08/10/11）

#### FP-CW-10d 发布课件（创建）
- **Method / Path**：`POST /api/kng/admin/courseware`
- **请求示例**（variant 由字段组合表达：files[].storagePath 非空=文件类；links 非空=外链）：

```json
{
  "title": "灯塔工厂方案5",
  "type": 2,
  "catalogId": "1948010293847565011",
  "standardMinutes": 12,
  "standardSeconds": 52,
  "standardDurationFollow": false,
  "studyScore": null,
  "finishStandardPercent": 100,
  "description": "<p>简介</p>",
  "coverStoragePath": "/kng-files/202609/cover.png",
  "code": "",
  "versionStr": "1.0",
  "viewPermission": 1,
  "downloadEnabled": true,
  "downloadPermission": 1,
  "appSaveEnabled": true,
  "appSavePermission": 1,
  "speedEnabled": true,
  "speedHoursCalc": true,
  "aiSubtitleEnabled": false,
  "files": [ { "storagePath": "/kng-files/202609/a1b2c3.mp4", "fileName": "灯塔工厂方案5.mp4", "fileSize": 734003200, "language": "zh" } ],
  "links": [],
  "attachmentPaths": [ { "storagePath": "/kng-files/202609/p1.pdf", "fileName": "配套PPT.pdf", "fileSize": 2097152 } ]
}
```

- **校验**：type∈{1,2,3,4,6,7}必须 files 非空（SCORM/HTML 仅接受 zip 后缀，压缩类≤3GB，各类型大小上限对齐需求文档格式表）；type=8 必须 links 非空（http/https）；名称必填≤200；附件≤50。
- **行为**：插入 status=**1（发布中）**，生成 platformNo；定时任务 30s 后置 2（已发布）。
- **响应**：`{ "code": 0, "message": "success", "data": { "id": "1948010293847565100", "status": 1 } }`
- **失败示例**：`{ "code": 1, "message": "视频文件不能超过5GB", "data": null }`

#### FP-CW-08 保存编辑
- **Method / Path**：`PUT /api/kng/admin/courseware/{id}`
- **请求**：同发布（可含 files 增删）；服务端**不更新** finish_standard_percent（发布后锁死）。
- **行为**：已发布课件保存后 status 不变；未发布课件编辑保存仍为未发布（编辑不触发发布，需另行发布——若入口需要，后续补"发布"按钮；当前编辑页对未发布课件显示【发布】= 本接口 + status=1）。
- **响应**：`{ "code": 0, "message": "success", "data": { "id": "1948010293847565100" } }`

### 2.5 操作（CW-09/13）

| FP | Method / Path | 请求 | 说明 |
|----|--------------|------|------|
| 下架 | `POST /api/kng/admin/courseware/{id}/take-down` | — | status 2→3，on_sale=0；仅已发布可下架 |
| 批量下架 | `POST /api/kng/admin/courseware/batch/take-down` | `{"ids":["..."]}` | 同上批量 |
| 批量上架 | `POST /api/kng/admin/courseware/batch/put-on` | `{"ids":["..."]}` | status 3→2，on_sale=1；仅已下架可上架 |
| 移动 | `POST /api/kng/admin/courseware/batch/move` | `{"ids":["..."],"targetCatalogId":"..."}` | 改 catalogId（单个/批量统一走 batch） |
| 复制 | `POST /api/kng/admin/courseware/{id}/copy` | `{"targetCatalogId":"..."}` | 生成副本：title="源-副本"（重名叠加序号）、status=0、copy_of=源id、files 引用同 storagePath；响应 `{"data":{"id":"新id"}}` |
| 删除 | `DELETE /api/kng/admin/courseware/{id}` | — | 引用检查（kng_ref 表，当前恒无）；物理删课件+files+attachments 记录；文件按引用计数保留 |
| 批量删除 | `POST /api/kng/admin/courseware/batch/delete` | `{"ids":["..."]}` | 同上批量 |
| 下载源文件 | `GET /api/kng/admin/courseware/{id}/download` | — | 文件流（Content-Disposition=原名）；外链课件返回 code=1"外链课件无源文件" |
| 引用记录（占位） | `GET /api/kng/admin/courseware/{id}/references` | — | 返回 `{"data":[]}`（kng_ref 接入后生效） |
| 下载记录（占位） | `GET /api/kng/admin/courseware/{id}/download-records` | — | 返回 `{"data":{"total":0,"records":[]}}` |

- 下架失败示例：`{ "code": 1, "message": "仅已发布课件可下架", "data": null }`
- 删除失败示例（未来）：`{ "code": 1, "message": "课件已被课程引用，无法删除", "data": null }`

### 2.6 转码/字幕管理（CW-14/15）

#### FP-CW-14 转码列表
- **Method / Path**：`POST /api/kng/admin/courseware/transcode/list?page=1&pageSize=10`
- **请求**（body）：`{"tab":"processing|failed","keyword":"..."}`
- **响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 1,
    "processingCount": 1,
    "records": [
      {
        "id": "1948010293847565110",
        "title": "新上传视频.mp4",
        "catalogName": "产品话术",
        "uploadTime": "2026-09-30 14:20:00",
        "convertedSeconds": 35,
        "createdByName": "董瑞",
        "remark": ""
      }
    ]
  }
}
```

- **说明**：processing tab=实时查 status=1；failed tab 恒空（`records:[]`）；convertedSeconds=当前时间-上传时间。

#### FP-CW-15 字幕列表（占位）
- **Method / Path**：`POST /api/kng/admin/courseware/subtitles/list?page=1&pageSize=10`
- **请求**：`{"tab":"recognizing|failed","keyword":"..."}`
- **响应**：`{ "code": 0, "message": "success", "data": { "total": 0, "records": [] } }`（AI 字幕待办#1 后接真实数据）
