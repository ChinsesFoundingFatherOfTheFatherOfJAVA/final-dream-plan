# 在线课堂（管理端）课件管理复刻需求文档

> 版本：v1.0 ｜ 日期：2026-09-30 ｜ 配套：02-技术实现方案.md、03-接口文档.md、04-建表与种子数据.sql
> 参照平台：train.chinajack.com/kng/#/courseware/mgmt；勘察记录见 `在线课堂课件管理-观察素材/逆向勘察记录-2026-09-30.md`
> 前置模块：分类管理（v1.0 已实现——分类树接口/DeptTree 组件复用）、课程设置（kng_setting 学分策略——编辑页"跟随学分策略"文案引用）

## 1. 项目概述

复刻课件管理：列表页（分类树+课件表格）、课件详情（三 tab）、编辑/发布（五段表单，四种发布途径）、更多菜单操作（下架/移动/复制/删除/下载/占位三项）、批量操作、转码管理、字幕管理。

范围边界：
- **真实文件上传**（Web 分片，本机磁盘存储）；**不做**转码/AI字幕/水印等媒体处理（留待办，见附录 D）
- 发布状态机"发布中→已发布"用**后端定时模拟**（无真实解析）
- 媒体能力相关页（转码/字幕管理）为骨架：转码管理有真实数据（发布中的课件），字幕管理恒空态

## 2. 术语与枚举

| 枚举 | 值 |
|------|-----|
| 课件类型 type | 1 文档、2 视频、3 音频、4 压缩文件、5 微课（占位，不会产生）、6 SCORM、7 HTML、8 外链课 |
| 课件状态 status | 0 未发布、1 发布中、2 已发布、3 已下架 |
| 学习状态 studyStatus | 1 已完课、2 学习中 |
| 完课方式 finishMethod | 1 培训、2 自学 |
| 浏览权限 viewPermission | 1 跟随分类浏览权限、2 单独设置允许浏览 |
| 下载权限 downloadPermission | 1 跟随分类中的「允许下载课件」权限、2 单独设置允许下载（0=不允许下载） |
| App保存权限 appSavePermission | 1 跟随分类中的「App保存课件」权限、2 单独设置允许保存（0=不允许保存） |

角色：管理端登录用户（沿用全站 JWT 与 `kng:courseware` 权限点——v1.0 分类管理已建）。

**权限边界（拍板，2026-09-30）**：本模块管理端仅做**菜单级权限**——拥有 `kng:courseware` 权限点的用户可见可操作全部课件，**不按人/按分类过滤数据范围**。原平台存在数据权限（抓包证据：列表请求带 `dataPermissionCode=View_courseware_scope`、学习数据带 `viewstudy_data`），我们暂不复刻，待组织架构权限体系成熟后统一铺（已记入决策表）。课件编辑表单中的"浏览/下载/App保存课件权限"为**学员端消费的配置**，与管理端操作权限无关。

## 3. 功能需求

### 3.1 列表页

#### CW-01 布局与分类树面板
- **功能描述**：`/kng/courseware` 三栏——左侧导航（复用 OnlineClassroomLayout）+ 分类树面板 + 内容区。
- **分类树**：数据复用 `GET /api/kng/admin/catalog/tree`；顶部搜索框（本地过滤+命中展开）、收起按钮（≡，收起后整个树面板隐藏，内容区加宽）；节点点击→按 catalogId 查列表（选中节点高亮蓝）；展开/收起本地计算；底部 radio **包含子分类（默认）/仅当前分类** → 请求体 `includeChildCatalog: 1/0`；树底部显示"共 N"（当前筛选课件总数）。
- **验收标准**：
  - Given 点击"服务话术" When 树选中该节点 Then 列表仅查该分类课件，且口径=包含子分类时含子级课件
  - Given 搜索"杰克" Then 树过滤显示命中链路
  - Given 切换"仅当前分类" Then 列表只查本级课件

#### CW-02 课件列表查询
- **接口**：`POST /api/kng/admin/courseware/list`（query: page/pageSize/orderBy/orderType；body: 筛选——对齐原平台形态）
- **列**：checkbox｜名称（类型图标[视频蓝/文档红/音频绿等按类型区分]+名称+外链图标[type=8]）｜类型｜更新日期（可排序）｜学习人数（可排序）｜状态（绿点+文案）｜操作（查看详情/编辑/更多 hover 菜单）
- **分页**：10/20/30/40 条/页 + 前往 N 页 + 共 N 条。
- **验收标准**：Given 无任何筛选 When 进入页面 Then 按更新日期倒序展示第一页 10 条；点击表头"更新日期"可切换升/降序。

#### CW-03 类型筛选
下拉九项：全部类型（默认）/文档/视频/音频/压缩文件/微课/SCORM/HTML/外链课 → body.type。

#### CW-04 课件状态筛选
下拉：默认占位"课件状态"（不参与查询）/未发布/发布中/已发布/已下架 → body.status。原平台的发布失败/待审核/审核未通过/被举报**不做**。

#### CW-05 搜索
"搜索名称/分类/上传者等"单输入框，后端对 名称(title) OR 分类名 OR 上传者名 三字段模糊匹配 → body.keyword（原平台传 title，我们扩为 keyword 三字段 OR，实现差异记录于决策表）。

#### CW-06 更多筛选弹窗与面包屑
- **弹窗四条件**（保留项）：是否上架（是/否）、是否被课程引用（是/否）、上传时间（开始~结束日期）、更新时间（开始~结束日期）。
- **不做**（用户指定）：是否隐藏、是否锁定、来源、环境、是否设置标签。
- **交互**：【确定】→ 按条件查询，列表上方出现**面包屑标签**（小标签样式，文案详细：如"是否上架：是"、"上传时间：2026-09-01 ~ 2026-09-30"），每个标签带 × 可单个移除（移除后重新查询）；【取消】关闭弹窗不动已生效筛选；重新打开弹窗回显当前条件。
- **验收标准**：Given 选"是否上架=是"并确定 Then 列表仅上架课件，面包屑显示"是否上架：是"；点 × Then 标签消失且列表恢复。

### 3.2 课件详情（CW-07）

路由 `/kng/courseware/info/:id`（三 tab，默认基础信息；右上角【编辑】跳编辑页；← 返回列表）。

#### 基础信息 tab
- **主要信息**（左侧两列 label-value）：名称、分类（全路径，如"服务话术"或"产品话术/杰克"）、标准时长（"12 分 52 秒（获得学分所需的学习时长）"）、学分（**跟随时显示实时计算值**："1.29 学分（跟随学时学分策略）"；单独设置时"N 学分"）、平台课程编号（ZXKT+日期+序号，自动生成）、完课标准（"完成标准时长的 100% 获得学分"）、简介（空显示 --）、附件（文件名列表，空显示 --）、编码、版本。
- **右侧**：封面图（无封面显示默认占位）+ 竖排锚点菜单（主要信息/相关方信息/权限设置/功能设置，点击滚动定位，只读展示对应区块）。
- **相关方信息**：贡献者（姓名(工号)）。**权限设置**：浏览权限/下载权限/App保存课件权限 当前值。**功能设置**：倍速播放/学时计算/AI字幕 开关值。
- **不做**（用户指定）：标签、价格、推荐系数、作者、主讲老师、辅讲老师、完课评论、讨论区、笔记区、游客访问。

#### 学习详情 tab
- **筛选**：所属部门（点击弹窗选择部门，复用 DeptTree 组件，支持包含子部门开关 hasChild）、学习状态（下拉：已完课/学习中）、完课方式（下拉：培训/自学）、姓名/账号搜索输入框。
- **列表字段**（全做）：姓名/账号/所属部门/岗位/学习状态（绿点已完课|蓝点学习中）/开始学习时间（yyyy-MM-dd HH:mm）/完成时间/累计学习时长（h，两位小数）/完课用时（天，未完课显示 --）。
- **分页**：10/20/30/40。
- **数据来源**：学习记录表（本模块建 `kng_study_record` 种子可空——学员端未做，列表正常展示空态"暂无数据"）。

#### 学习数据 tab
- **三统计卡**：近7天学习人数（人）/总学习人数（人）/总完课人数（人），副标题"（数据统计自课件发布之日起至今）"，卡内 ⓘ 提示。
- **学员完课用时概览**（横向条形，纯 CSS）：1天内/2-7天/8-30天/31-90天/90天以上 五档人数。
- **各部门学习完课数据概览**（双柱对比图，纯 CSS 或 ECharts 按既有工程惯例）：部门筛选（一级部门下拉，默认全部）、图例=学习人数（蓝）/完课人数（绿）。
- 数据接口四件套对齐原平台（overview/finish-time/dept-first-level/dept-finish）。

### 3.3 编辑与发布（CW-08 / CW-10 / CW-11）

编辑页与发布表单页**同组件双模式**（CoursewareForm.vue，mode: create|edit；按发布途径 variant: file|scorm|html|link）。
路由：`/kng/courseware/edit/:id`（编辑）、`/kng/courseware/publish/file|scorm|html|link`（发布）。

#### CW-08 编辑页（五段锚点导航）
左侧竖排锚点：上传文件/基本信息/相关方信息/权限设置/功能设置——点击平滑滚动到对应区块（当前区块高亮蓝）。底部居中【保存】（编辑模式）/【发布】（创建模式）。

- **上传文件区**（编辑模式；link 变体为"课件链接"输入）：
  - 文件列表表：文件名称（拖拽手柄+文件名）/状态（转码状态，占位显示 --）/所属语种（--）/操作（设置语种｜删除）
  - **设置语种弹窗**：选择语种（简体中文/繁體中文/English/Tiếng Việt，单选）→ 确定
  - "+ 上传文件"追加文件（编辑模式允许；上限对齐上传须知）
- **基本信息区**：

| 字段 | 控件 | 规则 |
|------|------|------|
| 名称* | input 0/200 | 必填 |
| 分类* | 下拉（分类树数据）+【新增分类】按钮（跳分类管理页新开窗口） | 必填 |
| 封面 | 图片上传（jpg/png，≤5MB，推荐 16:9） | 可选 |
| 标准时长 | **radio：跟随学分策略（课程设置-学分策略设置）｜单独设置时长**（文档/压缩/HTML/外链类显示 radio，对齐原平台截图16/17；**跟随态因页数解析待办（附录D#2）本次灰置**并提示"文档解析功能建设中，请单独设置"；视频/音频类无 radio 直接分+秒输入，自动取媒体时长待转码专项）→ 单独设置：分+秒 两个数字输入 | 视频/文档类必填 |
| 学分 | radio 跟随学分策略（默认，文案"跟随学分策略（课程设置-学分策略设置）"）｜单独设置学分（数字输入，一位小数）。**跟随时展示实时计算值**（如"1.29 学分"），规则见接口文档 §2.4 | |
| 完课标准 | 下拉 10%~100%（步进10，默认100%）+ 文案"完成标准时长的 N% 获得学分"；**发布后不可再编辑**（橙字提示"课件发布之后，完课标准无法再次编辑"） | |
| 简介 | 富文本 0/2000（工程已有富文本或 textarea+字数，按既有模块惯例） | 可选 |
| 附件 | 上传附件按钮；最多 50 个；类型同课件 | 可选 |
| 编码 | input | 可选 |
| 版本 | input | 可选 |

- **相关方信息区**：贡献者（标签式，默认=当前登录用户"姓名(工号)"，可删；**允许打赏不做**；作者/主讲老师/辅讲老师**不做**）。
- **权限设置区**：

| 字段 | 控件 | 默认 |
|------|------|------|
| 浏览权限 | radio：跟随分类浏览权限｜单独设置允许浏览 | 跟随分类 |
| 下载权限 | checkbox 允许下载 + 子 radio：跟随分类中的「允许下载课件」权限｜单独设置允许下载 | 勾选+跟随分类 |
| 下载文件 | 静态说明"学员下载的文件为源文件" | |
| App保存课件权限 | checkbox 允许保存 + 子 radio：跟随分类中的「App保存课件」权限｜单独设置允许保存 | 勾选+跟随分类 |

- **功能设置区**：倍速播放 checkbox（"开启倍速播放（开启后，学员可以按1.25/1.5/1.75/2倍速播放视频）"）、学时计算 checkbox（"倍速播放时学习时长也倍速计算（举例：学员2倍速学习5分钟，学习时长算10分钟）"）、AI字幕 checkbox（"开启AI字幕（开启后，该课件会生成字幕文稿…）"——**仅存储开关，生成能力待办**）。
- **倍速/学时与课程播放设置的两级联动**（表单打开时读 `GET /api/kng/admin/setting` 的 playConf 判定）：
  - 全局 `speedEnabled=false` → 课件级"倍速播放"强制不勾且禁用，悬浮提示"平台未开启倍速播放"
  - 全局 `speedScope=1`（所有课件课程都支持）→ 强制勾选且禁用，提示"平台已全局开启"
  - 全局 `speedScope=2`（跟随各自设置）→ 课件级可编辑
  - "学时计算"同构受全局 `speedHoursCalc` 控制（倍速播放被禁用时学时计算一并禁用）
  - 详情页只读展示**最终生效值**（全局压制后的结果）
- **不做**（用户指定）：关键点、价格、标签、作者、主讲/辅讲老师、是否隐藏、分享权限、游客访问、完课评论、讨论区、笔记区。

- **验收标准**：
  - Given 点左侧"权限设置"锚点 Then 表单平滑滚动到权限设置区且锚点高亮
  - Given 名称留空点保存 Then 红框+错误提示，不提交
  - Given 编辑已发布课件 Then 完课标准下拉禁用

#### CW-10 发布-上传文件（variant=file）
- **发布课件下拉**（截图11）：本地上传（上传文件/SCORM课件/HTML课件）｜外部链接｜从应用选择（从知识库选择/发表微课——**置灰**+悬浮"功能建设中"）；**米粒客户端区块不显示**。
- **上传页**（截图12）：虚线拖拽区（"拖拽或点击此处选择文件"+"支持：文档、图片、视频、音频、压缩文件"）+ 上传须知两条 + 支持格式大小表（文档 .doc/.docx/.ppt/.pptx/.xls/.xlsx/.pps/.pdf ≤200MB；图片 .jpg/.jpeg/.gif/.png/.bmp ≤100MB 且长宽≤10000px；视频 .wmv/.mp4/.flv/.avi/.rmvb/.mpg/.mkv/.mov/.mts ≤5GB；音频 .m4a/.wma/.wav/.mp3/.amr ≤1GB；压缩 .rar/.zip ≤2GB）。
- **上传**：选中即 Web **分片上传**（前端切片 5MB/片，后端合并，支持断点续传），文件行显示进度条；一次最多 10 个文件。
- **上传完成** → 表单页（截图13，create 模式：名称预填文件名去后缀）→【发布】→ 提示"正在解析中，解析完成后自动完成发布"→ 跳回列表，新课件状态=**发布中**。
- **状态机**：后端定时任务（每 30s 扫描）把发布中且上传时间超 30s 的课件置为**已发布**；此时操作列仍有查看详情/编辑/更多（菜单：删除/移动——对齐原平台新发布课件行为，但我们的"更多"菜单项保持全集不变）。

#### CW-11 SCORM/HTML/外链
- **SCORM**（variant=scorm）：上传页仅接受 .zip（≤3GB，文案"支持：压缩文件，大小限制3GB内"）→ 表单页（文件区显示 zip，其余表单同构）。
- **HTML**（variant=html）：同 SCORM（zip 包）。
- **外链课**（variant=link）：无上传页直接进表单页；第一段为"课件链接"：URL 输入（0/500，placeholder"请输入课件网址，建议使用https格式的网址"）+ 所属语种（设置语种弹窗）+ 删除 + "+ 添加外链"（多链接）；类型=外链课；完课标准区显示说明"外链课件无法记录学习进度"（推断，原平台截图17有完课标准说明文字）。

### 3.4 操作-更多菜单（CW-09）

| 菜单项 | 交互 | 说明 |
|--------|------|------|
| 下架 | 弹窗（截图9）：橙色⚠+「确定下架【xxx】吗？」+ 警告文案"检测到课件被课程、培训等业务使用，下架后学员无法再学习，请谨慎操作" + 「查看详情」链接 + 2 秒倒计时按钮「下架(2s)」倒计时结束可点 | 已发布→已下架 |
| 移动 | 抽屉（截图10，复用分类管理移动抽屉样式）：待移动课件名 + 请选择分类（搜索框+分类树）→ 确定 | 改 catalogId |
| 复制 | 抽屉（截图25）：提示条"复制出一个新课件，源课件与复制课件各自独立，编辑时不会同步更新" + "请选择目录"复选框分类树（单选一个目录，推断）+ 确定 | 生成副本：名称="源名称-副本"（重名再叠加），状态=未发布，文件引用同一存储（不复制文件本体），其余字段复制 |
| 删除 | 二次确认弹窗 + **引用检查**（当前无引用方直接可删；未来课程/考试引用后阻止并提示） | 物理删除课件记录+附件记录；文件保留（被副本引用时不删文件） |
| 下载 | 直接触发浏览器下载源文件 | |
| 引用记录 | **占位**弹窗：标题"引用记录"+ 空态"暂无引用" | 未来课程/考试模块消费 |
| 下载记录 | **占位**列表弹窗：空态"暂无数据" | |

### 3.5 批量操作（CW-13）

### 3.6 转码管理（CW-14）与字幕管理（CW-15）

- **转码管理** `/kng/courseware/transcode`（列表页"转码管理"链接进入；← 返回）：
  - 双 tab：**转码中**（数据= status=发布中 的课件实时查询）/ **转码失败**（恒空态，无真实转码）
  - 搜索"请输入名称/分类/分享者姓名搜索"；右上方文案"有 N 个课程处于转码中"
  - 转码中列：名称/分类/上传日期(可排序)/已转换时间(可排序)/分享者/备注/操作（**重试**按钮占位禁用）；失败 tab 列：名称/分类/上传日期/已转换时间/分享者/失败原因/操作 + "查看常见出错原因"链接（占位提示弹窗）
  - 空态：插画+"暂无数据"
- **字幕管理** `/kng/courseware/subtitles`：同构；双 tab 识别中/识别失败；列：名称/分类/开始时间/操作人/操作；恒空态（AI 字幕待办）。

## 4. 非功能需求

- 分片上传：5MB/片，GB 级文件不掉线；上传中断可续传（记录已传分片）
