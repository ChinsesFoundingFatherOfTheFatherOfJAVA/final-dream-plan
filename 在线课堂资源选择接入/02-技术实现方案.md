# 在线课堂资源选择接入 技术实现方案

> 日期：2026-10-28
> 技术栈：Vue 3.5 + TypeScript + Element Plus；Java 21 + Spring Boot 4 + MyBatis-Plus
> 涉及工程：`front-end`、`after-end/OnlineClassroom`、`after-end/AtualCombatTraining`
> AI 出题生成服务：`after-end/ExamService` 现有生成接口不改造

## 1. 架构结论

在线课堂模块负责资源列表查询和文档文本抽取；AI 设计助手负责把选中的在线课堂资源转成“培训材料”；AI 出题只把抽取结果写入现有 `materialText`。

```text
AI设计助手 ChatColumn
  └─ 上传资料菜单
      └─ KngSourcePickerDrawer(purpose=designAssistant,max=5)
          ├─ POST /api/kng/admin/courseware/ai-sources/list
          └─ confirm(coursewareIds)
              └─ POST /api/act/assistant/materials/from-kng
                  └─ AtualCombatTraining → OnlineClassroom 抽取接口
                      → act_ai_material + artifact.materials

AI出题 AiQuesDrawer
  └─ KngSourcePickerDrawer(purpose=question,max=1)
      ├─ POST /api/kng/admin/courseware/ai-sources/list
      └─ POST /api/kng/admin/courseware/ai-sources/{id}/extract
          → materialText → 现有 aiGenerateQues
```

选择理由：

- `kng_*` 表与源文件只由 OnlineClassroom 读取，ExamService 不直读。
- AtualCombatTraining 负责 `act_ai_material` 与 artifact 材料写入，符合数据所有权。
- 在线课堂文本抽取只实现一次，避免话术、设计助手、出题复制解析器。
- AI 设计助手与 AI 出题复用同一列表抽屉，只通过配置区分列与上限。

## 2. 复刻边界与取舍

### 2.1 对齐原平台

- AI 设计助手从“上传资料”菜单进入，不新增独立入口。
- 抽屉标题“在线课堂”，列：名称/课时/创建人/更新时间/有效期。
- 分类下拉 + 关键词搜索，无“更多筛选”。
- 上限 5，右侧已选 `N/5`，底部取消/确定。
- AI 出题保留原抽屉的更多筛选、类型、排序、已选区、上限 1。

### 2.2 刻意不同

| 项 | 原因 | 本系统处理 |
|---|---|---|
| 有效期 | `kng_courseware` 无过期字段 | 设计助手固定显示 `--` |
| 标签筛选 | 无课件标签表 | 首期不做 |
| 删除课程筛选 | 无删除态列表 | 首期不做 |
| 视频/音频/微课 | 抽取链路未闭环 | 首期不开放 |
| 全选筛选结果 | 有选择上限 | 最多选择剩余额度内的前 N 条 |

### 2.3 现成实现

不引入外部选择器库。复用 Element Plus 与现有抽屉、表格、分页、分类树和请求拦截器。

### 3.2 统一选择器

```ts
type KngSourcePurpose = 'designAssistant' | 'question'

interface KngSourceItem {
  id: string
  title: string
  type: number
  typeDesc: string
  catalogId: string
  catalogName: string
  credits: number | null
  durationText: string
  createdByName: string | null
  createTime: string | null
  updateTime: string | null
  expirationDate: string | null
  hidden: boolean
  sourceFileName: string
  sourceFileType: string
}

defineProps<{
  purpose: KngSourcePurpose
  maxSelect: number
  variant: 'designAssistant' | 'question'
  zIndex?: number
  excludeIds?: string[]

```

变体差异：

| 配置 | designAssistant | question |
|---|---|---|
| 标题 | 在线课堂 | 课程库中的 |
| 筛选 | 分类 + 关键词 | 关键词 + 更多筛选 |
| 列 | 名称/课时/创建人/更新时间/有效期 | 名称/学分/时长/分享人 |
| 上限 | 5 | 1 |
| 多选 | 是 | 单选替换 |

### 3.3 AI 设计助手

`ChatColumn.vue`：

- 将当前“上传资料”按钮改为 `el-dropdown`。
- 菜单项：
  - 从在线课堂选择
  - 从知识空间选择（disabled）
  - 本地上传
- 点击在线课堂打开 `KngSourcePickerDrawer`。
- 确定后调用 `importAssistantKngMaterials(sessionId, ids)`。
- 成功后刷新 artifact，并切换到“培训材料”tab。
- 同时由后端在消息流插入一条 `biz-common-parse-file` 完成事件（`status=1`），卡片逐条列出课件名、字数与失败原因；前端 `MessageBubble.vue` 已能渲染该 `bizType`，沿用现有渲染即可。
- 本地上传继续走现有 `uploadAssistantFile`。

`useAssistantStore.ts`：

- 新增 `importKngMaterials(coursewareIds)`。
- 接口返回成功后调用 `refreshArtifact()`。
- 材料可见性、删除继续复用现有 artifact 操作。

`MaterialsTab.vue`：

- 展示 `fileSource=3` 的来源标签“在线课堂”。
- 预览继续使用 `getSessionMaterials` 返回的抽取文本。
- 不向用户展示磁盘路径。

### 3.4 AI 出题

`AiQuesDrawer.vue`：

- 增加“选择课件”“选择知识（禁用）”。
- `selectedKngSource` 只保留一项。
- 点击“提取知识点”时调用 KNG extract。
- 当前 `materialText` 非空时先确认覆盖。
- 成功后同步字数、清空已生成草稿，避免旧草稿引用旧素材。

### 3.5 视觉与可交互

- 设计助手抽屉右侧已选区约 240px。
- 表格超长名称截断并提供 title。
- 达到上限后未选行复选框禁用。
- 分类下拉使用树形选择器，可展开/收起。
- 抽屉关闭按钮使用图标并提供 `aria-label`。
- 选中行、禁用行、隐藏行不能仅依赖颜色区分。

## 4. 在线课堂后端

### 4.1 新增结构

```text
after-end/OnlineClassroom/
  controller/KngAiSourceController.java
  service/KngAiSourceService.java
  service/impl/KngAiSourceServiceImpl.java
  service/KngDocumentExtractor.java
  service/impl/KngDocumentExtractorImpl.java
  dto/KngAiSourceDtos.java
  mapper/KngCoursewareMapper.java + XML 增量
```

### 4.2 列表查询

固定条件：

```text
status=2
on_sale=1
type=1
存在 .doc/.docx/.ppt/.pptx/.pps/.pdf 源文件
```

动态条件：

- `title LIKE`
- `catalog_id in subtree`
- `created_at` 日期范围
- `hidden` 默认包含

排序白名单：

- `updateTime → updated_at`
- `credits → study_score`
- `duration → standard_minutes*60 + standard_seconds`

COUNT 与列表必须用同一筛选条件，返回真实 `total`。

### 4.3 文本抽取

- 按 `coursewareId` 校验发布/上架状态。
- 取 `kng_courseware_file` 第一个文档类源文件。
- `/kng-files/...` 映射到 `kng.upload.dir` 根目录内。
- 路径规范化后必须 `startsWith(root)`。
- PDF 用 PDFBox 3；Office 用 POI。
- `purpose=designAssistant` 上限 30000 字。
- `purpose=question` 上限 20000 字。
- 返回纯文本、文件名、类型、大小、截断标记。

### 4.4 权限

- 新接口在 `OnlineClassroom` 管理端路径下，使用统一 JWT。
- 允许拥有 `act:training` 或 `exam:manage` 的管理员跨模块读取已发布资源，不要求额外 `kng:courseware` 菜单权限。
- 不返回未发布草稿和已下架资源。

## 5. AI 设计助手后端

### 5.1 新增接口

`POST /api/act/assistant/materials/from-kng`

请求：

```json
{
  "sessionId": "session-id",
  "coursewareIds": ["courseware-1", "courseware-2"]
}
```

服务端：

1. 校验会话存在、非只读。
2. 最多 5 个 id，去重。
3. 使用当前请求 `Authorization` 调用在线课堂抽取 API。
4. 单条失败收集错误，其他成功项继续。
5. 文本经 `MaterialTextSummarizer.summarize`。
6. 写 `act_ai_material`：
   - `file_id = "kng_" + coursewareId`
   - `name = 课件名称`
   - `file_type = 源文件扩展名`
   - `file_size = 源文件大小`
   - `extract_text/summary`
   - `visibility=1`
   - 有主题则写 `theme_id`
7. 相同 `session_id + file_id` upsert，不产生重复材料。
8. 有主题时调用 `artifactService.appendOrUpdateMaterial`。
9. 推送 `biz-common-parse-file` 完成事件（逐条课件名 + 成功/失败），并推 artifact 更新事件。
10. 返回成功材料列表和逐条失败信息。

### 5.2 数据模型

不新增表列。使用现有 `file_id` 约定区分来源：

- 本地文件：`file_id=<UUID.ext>`。
- 在线课堂：`file_id=kng_<coursewareId>`。

`act_ai_material` 仍使用现有
`session_id/theme_id/file_id/name/file_type/file_size/visibility/extract_text/summary`。

`ArtifactMaterial` 增补：

```ts
fileSource?: number       // 2 本地文件 / 3 在线课堂
sourceId?: string         // coursewareId
```

### 5.3 在线课堂访问客户端

AtualCombatTraining 新增 `KngAiSourceClient`：

- 只调用在线课堂 AI 素材抽取接口。
- 转发当前用户 `Authorization`。
- base URL 来自 `kng.ai-source.base-url`，默认 `http://localhost:8084`。
- 超时 120 秒。

不在 AtualCombatTraining 直读 `kng_*` 表。

### 5.4 材料预览与删除

- 预览走现有 `GET /api/act/assistant/sessions/{sessionId}/materials`，数据来自 `extract_text`。
- 删除走现有材料操作。
- 在线课堂材料不落 `act-files`，预览不读源盘路径。

## 6. 数据流

### 6.1 AI 设计助手

```text
选择课件 ids
 → ACT import endpoint
 → KNG extract
 → act_ai_material (file_id=kng_<coursewareId>)
 → artifact.materials
 → parse-file 完成事件 + artifact 更新
 → 培训材料 tab 可见
```

### 6.2 AI 出题

```text
选择 1 个课件
 → KNG extract(question)
 → materialText
 → 现有 aiGenerateQues
```

## 8. 风险

| 风险 | 处理 |
|---|---|
| 在线课堂抽取超时 | 120s 超时，逐条失败，不阻塞成功项 |
| 在线课堂材料进入 artifact 后重复 | 按 session + `kng_<coursewareId>` upsert |
| 设计助手材料预览依赖 act-files | 在线材料预览走 DB 文本，不读原文件 |
| 微课/视频类型缺失 | 首期明确不支持 |
| 本地文件与在线材料混排 | `fileId` 前缀和 `fileSource` 区分 |
