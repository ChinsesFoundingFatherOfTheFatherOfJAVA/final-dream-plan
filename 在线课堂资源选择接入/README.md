## 已确认事实

- AI 设计助手入口在聊天输入框“上传资料”菜单，菜单含“从在线课堂选择 / 从知识空间选择 / 本地上传”。
- AI 设计助手抽屉上限 5，标题“在线课堂”，列为名称/课时/创建人/更新时间/有效期，筛选为分类 + 关键词。
- AI 设计助手抓包数据只含文档类型，实测首屏 129 条，类型为 `ppt/pdf`。
- AI 出题入口在“智能出题”素材区，原平台支持文档/视频/音频/微课，上限 1。
- 本系统在线课堂已有 `kng_courseware` / `kng_courseware_file` 文档源文件与文本抽取依赖。
- 本系统微课 `type=5` 仍是占位；视频/音频字幕链路尚未整理成通用素材接口。

## 已确认范围

1. AI 设计助手与 AI 出题接入统一在线课堂选择器。
2. 首期只开放文档类课件。
3. 视频/音频在字幕转文本接口明确后开放。
4. 微课待在线课堂微课模块闭环后单独立项。
5. 知识空间保持置灰，不纳入本轮。
6. AI 生成话术已经实现，不在本目录范围。
