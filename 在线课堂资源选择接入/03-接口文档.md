# 在线课堂资源选择接入 接口文档

> 日期：2026-10-28
> Base URL：`/api`
> 鉴权：`Authorization: Bearer <StaffManagement JWT>`
> 响应：统一 `ApiResponse { code, message, data }`，成功 `code=0`
> 分页：页码从 1 开始，默认 20 条/页

| `createTime` | string/null | 创建时间 |
| `updateTime` | string/null | 更新时间 |
| `expirationDate` | string/null | 本系统无值，返回 null |
| `hidden` | boolean | 是否隐藏 |
| `sourceFileId` | string | 第一个文档源文件 id |
| `sourceFileName` | string | 原文件名 |
| `sourceFileType` | string | doc/docx/ppt/pptx/pps/pdf |

## 2. 在线课堂接口

### API-01 AI 素材源查询

- **Method / Path**：`POST /api/kng/admin/courseware/ai-sources/list`
- **Query**：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page` | int | 1 | 页码 |
| `pageSize` | int | 20 | 1~100 |
| `orderBy` | string | `updateTime` | `updateTime/credits/duration` |
| `orderType` | string | `desc` | `asc/desc` |

- **Body**：

```json
{
  "purpose": "designAssistant",
  "keyword": "",
  "type": 1,
  "catalogId": "",
  "includeChildCatalog": 1,
  "createTimeStart": null,
  "createTimeEnd": null,
  "includeHidden": true
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `purpose` | string | 是 | `designAssistant` / `question` |
| `keyword` | string | 否 | 名称模糊查询 |
| `type` | int | 否 | 首期只接受 1 |
| `catalogId` | string | 否 | 分类 id |
| `includeChildCatalog` | int | 否 | 1 含子类，默认 1 |
| `createTimeStart` | string | 否 | `yyyy-MM-dd` |
| `createTimeEnd` | string | 否 | `yyyy-MM-dd`，包含当天 |
| `includeHidden` | boolean | 否 | 默认 true |

- **固定条件**：`status=2 AND on_sale=1 AND type=1`，且存在文档源文件。
- **响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 129,
    "records": [
      {
        "id": "2109552974241972226",
        "title": "平缝机产品知识培训",
        "type": 1,
        "typeDesc": "文档",
        "catalogId": "2104855810181910530",
        "catalogName": "产品话术",
        "credits": 5.6,
        "durationText": "30分0秒",
        "createdByName": "林婷婷",
        "createTime": "2026-09-28 09:16:30",
        "updateTime": "2026-10-09 15:50:08",
        "expirationDate": null,
        "hidden": false,
        "sourceFileId": "2109552974241972227",
        "sourceFileName": "平缝机产品知识培训.pptx",
        "sourceFileType": "pptx"
      }
    ]
  }
}
```

- **错误**：`code=1` + 中文 message。
- **来源**：设计值；字段范围参考 `观察素材/抓包/AI设计助手-在线课堂选择.har`。
- **调用点**：统一在线课堂选择器。

### API-02 抽取课件文本

- **Method / Path**：`POST /api/kng/admin/courseware/ai-sources/{coursewareId}/extract`
- **Query**：

| 参数 | 类型 | 说明 |
|---|---|---|
| `purpose` | string | `designAssistant=30000 字`；`question=20000 字` |

- **响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "coursewareId": "2109552974241972226",
    "coursewareTitle": "平缝机产品知识培训",
    "sourceFileId": "2109552974241972227",
    "fileName": "平缝机产品知识培训.pptx",
    "fileType": "pptx",
    "fileSize": 108148,
    "text": "提取文本……",
    "chars": 8421,
    "truncated": false
  }
}
```

- **错误场景**：
  - 课件不存在/不可用
  - 类型暂不支持
  - 无文档源文件
  - 文件缺失
  - 文件路径非法
  - 未提取到文本
  - 文件损坏
  - 解析超时

## 3. AI 设计助手接口

### API-04 导入在线课堂培训材料

- **Method / Path**：`POST /api/act/assistant/materials/from-kng`
- **请求头**：透传当前 `Authorization` 给 OnlineClassroom。
- **Body**：

```json
{
  "sessionId": "session-id",
  "coursewareIds": [
    "2109552974241972226",
    "2109552974241972227"
  ]
}
```

- **校验**：
  - `sessionId` 必填且会话存在。
  - `coursewareIds` 1~5 个，去重。
  - 只允许 `designAssistant` 用途的文档课件。

- **成功响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "materials": [
      {
        "id": "material-id",
        "fileId": "kng_2109552974241972226",
        "name": "平缝机产品知识培训",
        "fileType": "pptx",
        "fileSize": 108148,
        "fileSource": 3,
        "sourceId": "2109552974241972226",
        "visibility": 1
      }
    ],
    "failures": []
  }
}
```

- **部分失败响应**：`code=0`，`materials` 返回成功项，`failures` 返回：

```json
[
  {
    "coursewareId": "xxx",
    "reason": "课件源文件不存在"
  }
]
```

- **副作用**：
  - upsert `act_ai_material`。
  - 有主题时更新 `artifact.materials`。
  - 推送 `biz-common-parse-file` 完成事件。
  - 推送 `artifact-updated` 事件。

### API-05 会话材料列表

复用现有：

`GET /api/act/assistant/sessions/{sessionId}/materials`

在线课堂材料通过 `act_ai_material.extract_text` 返回预览。

## 4. 数据约定增量

### 4.1 act_ai_material

不新增列。在线课堂材料使用：

- `file_id = CONCAT('kng_', coursewareId)`
- `name = 课件名称`
- `file_type = 文档源文件扩展名`
- `file_size = 文档源文件大小`
- `extract_text/summary` 保存抽取结果
- 不写入 `act-files`

本地文件与在线课堂材料的来源通过 `fileId` 前缀区分；同会话按 `file_id` upsert。

### 4.2 artifact.materials

| 字段 | 类型 | 说明 |
|---|---|---|
| `fileSource` | int | 2 本地文件，3 在线课堂 |
| `sourceId` | string/null | 在线课堂 coursewareId |

保留现有 `id/name/fileType/fileSize/fileSizeUnit/visibility`。

## 6. 不支持项

| 能力 | 首期状态 | 原因 |
|---|---|---|
| 视频/音频抽取 | 不提供 | 等待字幕/ASR 文本链路 |
| 微课抽取 | 不提供 | 微课内容模型未闭环 |
| 知识空间 | 不提供 | 模块未实现 |
| 标签筛选 | 不提供 | 无标签表 |
| 删除课程 | 不提供 | 无删除态模型 |
