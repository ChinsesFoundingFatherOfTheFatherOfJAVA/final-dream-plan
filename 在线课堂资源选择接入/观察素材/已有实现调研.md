# 已有实现调研

> 调研时间：2026-10-28

## 结论

未找到值得引入的开源课件选择器。该功能是业务资源查询、权限可见性、文本抽取和已选区状态组合，复用项目现有 Element Plus 抽屉、表格、分类树和分页组件更稳妥。

## 复用清单

- Element Plus：`el-drawer`、`el-table`、`el-input`、`el-date-picker`、`el-tree-select`、`el-pagination`。
- 现有在线课堂分类树接口与 `CatalogTreePanel` 的数据结构。
- 现有 PDFBox/POI 文档抽取能力。
- 现有 `exam-drawer` 抽屉基线与统一请求拦截器。

## 不引入项

- 不引入新的表格/选择器组件库。
- 不复制原平台前端资源、图标或接口字段。
- 不新增第三方富文本/文件解析 SDK。
