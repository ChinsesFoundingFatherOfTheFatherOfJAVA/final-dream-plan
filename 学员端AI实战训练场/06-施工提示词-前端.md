## 实现顺序

### 阶段 1：路由与只读页面

- 启用顶部导航。
- 添加学员路由和独立全屏 attempt/report 路由。
- 完成首页、主题详情、练习历程、文件页。
- 接口未完成时只允许在 API 层使用明确 mock；页面不得写死业务数据。

完成标志：路由刷新可用，空态/加载/错误态齐全，`npm run type-check` 通过。

### 阶段 2：准备与 attempt

- 场景准备弹窗。
- 案例确认、随机难度、自定义动态向导。
- 混合模式训练/考核选择和解锁提示。
- `AttemptPage` 准备阶段和准备完成页。
- `drillAttempt` store。

完成标志：三类练习都能创建 attempt，刷新后仍显示同一准备状态。

### 阶段 3：训练运行

- `useDrillSocket`。
- 文字对话、语音转写、TTS、教练点评、建议。
- 右侧场景抽屉、服务端计时和断线恢复。
- 双标签页只允许一个 writer。

完成标志：模拟后端 WS 下完整完成 3 轮训练，断网 10 秒可恢复。

### 阶段 4：报告与重练

- 结果事实卡、维度、证据、对话回放。
- 再练一次。
- 报告生成中状态。

完成标志：到时、主动退出、通过三种路径均有正确文案。

### 阶段 5：考核与防作弊

- 考核无 AI 辅助。
- 切屏监听和摄像头抓拍。
- 人脸 provider 不可用时阻断。

完成标志：切屏次数、摄像头拒绝、考核次数用尽都有明确状态。

### 阶段 6：管理端

- 替换 `StudentPanel.vue`。
- 添加学员抽屉、学员详情、对练记录、场景分布。
- 主题设置拆分全局设置。
- 版本历史只展示发布版本。
- AI 助手增加产品档案和在线课堂导入反馈。

完成标志：管理端能添加/移除学员、追加考核次数、看到真实训练/考核均分。

### 阶段 7：视觉与回归

- 用 `页面素材` 对照桌面 1519x858 和 1215x686。
- 检查 375px 移动端。
- 所有 fixed 元素不得重叠、遮挡或造成页面级横向滚动。


```powershell

```
