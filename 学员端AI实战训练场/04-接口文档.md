# AI实战训练场学员端与训考闭环接口文档

> 版本：v1.1 ｜ 日期：2026-10-30
> Base URL：`http://localhost:8080/api/act`
> 鉴权：请求头携带 StaffManagement 签发的 JWT。
> 所有 ID 均为 string；时间默认 `yyyy-MM-dd HH:mm:ss`

## 1. 通用约定

### 1.1 响应

```json
{ "code": 0, "message": "success", "data": {} }
```

- `code=0` 成功。
- `code=1` 业务失败，`message` 可展示。
- HTTP 401/403 由统一鉴权层处理。
- 业务错误同时返回 `errorCode`，前端可按码切换交互。
- 学员 `userId` 一律取自 JWT 上下文，不接受客户端用 body/query 覆盖。

### 1.2 分页

请求：`page` 从 1 开始，`pageSize` 默认 20，最大 100。

响应：

```json
{
  "page": 1,
  "pageSize": 20,
  "total": 31,
  "records": []
}
```

### 1.3 枚举

| 枚举 | 值 |
|---|---|
| themeStatus | draft, publishing, published, paused, finished, failed |
| studyMode | 1 训练, 2 考核 |
| practiceType | case, random, custom |
| attemptStatus | preparing, ready, in_progress, report_generating, completed, failed, cancelled |
| recordStatus | in_progress, report_generating, passed, failed, preparation_failed, system_failed |
| endReason | timeout, manual_exit, target_reached, round_limit, screen_violation, plan_ended, system_failed |
| participantSource | assigned, public |
| materialSource | act_local, online_classroom |
| versionSource | legacy_working, initial_publish, ai_confirm, manual_republish |
| difficulty | 1 简单, 2 中等, 3 困难 |

### API-S05 场景准备详情

- `GET /student/themes/{themeId}/scenarios/{scenarioId}`
- 返回场景完整描述、案例摘要、产品档案、练习方式、限时、通过分和当前次数。

### API-S05b 随机练习取档（2026-11-04 新增）

- `GET /student/themes/{themeId}/scenarios/{scenarioId}/random-script?difficulty=1|2|3`
- 从**发布期已预生成**的「场景 × 难度档」候选中随机取一份脚本，**不调模型**。
  与原平台 `randomScript?difficulty=N` 的取档语义一致（见 `08` §4.0 的实测依据）。
- 响应：

```json
{
  "difficulty": 2,
  "requestedDifficulty": 2,
  "degraded": false,
  "script": "{\"schemaVersion\":\"drill-script-v1\", ...}"
}
```

- `difficulty`：实际命中的档位；`requestedDifficulty`：请求的档位；
  `degraded=true` 表示本档无候选、走了降级链（其他档 / 案例正文），前端可据此提示。
- 鉴权与 `API-S05` 同口径（参与关系 + 当前发布版本）；**只读，不创建 attempt**。
- **「再练一次」不调用本接口**：走上次 attempt 的脚本快照复用（`reuseFromAttemptId`），保证不换脸。
- 降级链不静默返回空：连案例正文都没有时返回业务失败「该场景尚未生成随机练习脚本，请先在管理端发布」。

### API-S06 主题最近记录

- `GET /student/themes/{themeId}/records?page=1&pageSize=10&status=&scenarioId=&studyMode=`
- 默认按 `startedAt desc`。

### API-S07 学员练习历程

- `GET /student/practice-records?page=1&pageSize=20&status=&themeId=&studyMode=`
- `status` 为 `all/in_progress/passed/failed`。
- 返回统计和分页记录。

## 4. Attempt 与运行时

### API-A01 练习预检

- `POST /student/attempts/preflight`

```json
{
  "themeId": "t1",
  "scenarioId": "s1",
  "studyMode": 1,
  "practiceType": "custom",
  "difficulty": 2
}
```

响应：

```json
{
  "allowed": true,
  "activeAttemptId": null,
  "requiredSteps": [
    "product_profiles",
    "scene_background",
    "actor",
    "difficulty",
    "preview"
  ],
  "maxDurationSeconds": 900,
  "remainingSceneAttempts": 2,
  "remainingExamAttempts": 1,
  "checks": [
    { "code": "PLAN_TIME", "passed": true, "message": null }
  ]
}
```

- 只要某个检查失败，`allowed=false`，并返回第一个阻断错误码。

### API-A02 创建 attempt

- `POST /student/attempts`

```json
{
  "themeId": "t1",
  "scenarioId": "s1",
  "studyMode": 1,
  "practiceType": "custom",
  "difficulty": 2,
  "customConfig": {
    "sceneBackground": {
      "location": "客户办公室",
      "situation": "客户刚结束生产例会，只有 15 分钟。"
    },
    "actor": {
      "name": "王总",
      "identity": "客户",
      "personalities": ["严谨", "强势"],
      "background": "..."
    },
    "productProfileIds": ["p1"]
  }
}
```

- 返回 `Attempt` 和 `preparationState=preparing`。
- 不扣次数。
- 重复提交使用 `Idempotency-Key`；同 key 返回同一 attempt。

### API-A03 Attempt 快照

- `GET /student/attempts/{attemptId}`
- 返回 attempt、准备阶段、脚本摘要、最近消息游标和当前可执行动作。
- 非本人返回 403。

### API-A04 正式开始

- `POST /student/attempts/{attemptId}/start`
- 请求可带 `faceEvidenceId`。
- 在事务内再次校验并扣次数。
- 成功后返回 `status=in_progress`、`startedAt`、`deadlineAt`。
- 错误：`ATTEMPT_STATE_INVALID`、`SCENE_LIMIT_REACHED`、`EXAM_LIMIT_REACHED`、`EXAM_NOT_UNLOCKED`、`FACE_PROVIDER_UNAVAILABLE`、`ANTI_CHEAT_BLOCKED`。

### API-A05 消息历史

- `GET /student/attempts/{attemptId}/messages?afterSeq=0&limit=200`
- 返回按 `seq` 升序消息和轮次状态。
- 刷新/重连先调本接口，再连接 WS。

**实现说明（2026-11-04，t11）**：

- `afterSeq`：只取 `seq > afterSeq` 的消息（0 = 从头）；`limit` 默认 200，硬上限 500。
- 响应形状：

```json
{
  "attemptId": "a1",
  "total": 3,
  "totalCount": 3,
  "afterSeq": 0,
  "messages": [
    { "id": "m1", "seq": 1, "role": "user", "messageType": "text",
      "textContent": "…", "coach": false, "createdAt": "2026-11-04 10:00:00" }
  ],
  "turn": { "currentRound": 3, "maxRound": 50, "targetProgress": 40,
            "remainingSeconds": 600, "status": "in_progress" }
}
```

- `total` = **本次返回条数**；`totalCount` = 该 attempt 的**全量条数**（前端据此判断还有没有更多）。
- `role` 取 `user` / `assistant` / `coach` / `system`；`coach=true` 等价于 `role=coach`（前端不必再判一次）。
- `turn.remainingSeconds` 只在 `status=in_progress` 且有 `deadlineAt` 时有值，其余为 `null`（不编造 0）。
- 归属校验在查库前完成，越权与未登录均拒绝且不泄露对话内容。
- 未改任何 WS 帧名/事件名。

### API-A06 语音转文字

- `POST /student/attempts/{attemptId}/voice/transcribe`
- `multipart/form-data`：`audio`，16kHz WAV/浏览器兼容格式。
- 响应：

```json
{
  "text": "王总您好，想先了解一下目前排产最大的问题。",
  "durationMs": 4300
}
```

- ASR 结果只回填，不自动发送。

### API-A07 TTS

- `POST /student/attempts/{attemptId}/tts`

```json
{ "messageId": "m12", "voiceId": "longwan_v2", "speed": 1.0 }
```

- 服务端读取已保存的 AI 台词生成音频。
- 响应：`{ "audioUrl": "/audio/...", "durationMs": 4200, "cached": true }`。
- 同一 attempt 对同一 message 幂等。

### API-A08 建议

- `POST /student/attempts/{attemptId}/suggestion`
- 仅训练模式且 `suggestionEnabled=true`。
- 返回：

```json
{
  "analysis": "客户对交付风险敏感，先共情再追问。",
  "sampleReply": "王总，上次项目没落地确实会增加顾虑，我先确认您最担心的是交期还是数据稳定性？"
}
```

### API-A09 主动结束

- `POST /student/attempts/{attemptId}/finish`

```json
{ "reason": "manual_exit", "clientReason": "学员点击退出练习" }
```

- 幂等。
- 主动退出最终 `passed=false`。
- 返回 `reportId` 和 `reportStatus=generating`。

### API-A10 防作弊事件

- `POST /student/attempts/{attemptId}/anti-cheat/events`

```json
{
  "type": "screen.hidden",
  "occurredAt": "2026-10-29 15:30:00",
  "clientEventId": "uuid"
}
```

- `clientEventId` 幂等。
- 服务端返回 `accepted`、当前次数、是否已触发结束。

### API-A11 人脸抓拍上传

- `POST /student/attempts/{attemptId}/anti-cheat/face`
- `multipart/form-data`：`image` JPEG，`stage=precheck|ongoing`。
- 返回 `{ "passed": true, "evidenceId": "..." }`。
- 未启用摄像头或 provider 不可用时拒绝。

## 8. 管理端：设置、内容版本与产品档案

### API-AD07 全局设置读取

- `GET /admin/theme/{themeId}/settings`
- 不再返回“设置版本号”。
- 返回 `lockedFields`，首次发布后包含 `trainingModeEnabled`、`assessmentModeEnabled`。

### API-AD08 全局设置保存

- `PUT /admin/theme/{themeId}/settings`
- 不创建内容版本。
- 已锁定字段变化返回 `MODE_LOCKED_AFTER_PUBLISH`。
- 启用 face check 时必须满足 provider 可用。

### API-AD09 内容版本列表

- `GET /admin/theme/{themeId}/content-versions`
- 首次发布前 `records=[]`；内部隐藏 `v0` 不返回。
- 返回版本号、发布时间、来源、创建者、内容 hash 摘要和当前标记。

### API-AD10 发布

- `POST /admin/theme/{themeId}/publish`
- 首次发布创建 v1；失败可重试。
- 已发布主题再次发布只用于修复/重新编译，不产生内容变更版本；内容变更必须由 AI 确认触发。

## 9. WebSocket 协议

ACT 与 AIGentService 的内部运行态 HTTP/SSE 契约见 `08-训考运行态接口与JSON-Schema.md`；本节只定义浏览器到 ACT 的协议。

### 9.1 连接

```text
ws://localhost:8082/api/act/ws/drill?attemptId={attemptId}&token={jwt}
```

生产环境由同源反向代理承接 WS。

### 9.2 客户端帧

```json
{
  "type": "action",
  "action": "chat",
  "clientMessageId": "uuid",
  "attemptId": "a1",
  "data": { "text": "王总您好..." }
}
```

允许 action：

| action | data |
|---|---|
| drill.start | `{faceEvidenceId?}` |
| chat | `{text}` |
| voice.transcript | `{text, durationMs}` |
| suggestion.request | `{}` |
| drill.pause | `{}` |
| drill.resume | `{}` |
| drill.finish | `{reason:"manual_exit"}` |

### 9.3 服务端帧

```json
{
  "type": "event",
  "event": "assistant.delta",
  "seq": 12,
  "attemptId": "a1",
  "timestamp": "2026-10-29 15:30:01",
  "data": { "messageId": "m3", "delta": "王总" }
}
```

事件：

| event | 关键 data |
|---|---|
| connection.ready | `lastServerSeq` |
| preparation.progress | `stage`, `percent`, `title` |
| preparation.ready | `scriptSummary` |
| attempt.started | `startedAt`, `deadlineAt` |
| message.ack | `clientMessageId`, `messageId`, `seq` |
| turn.started | `round`, `remainingSeconds` |
| coach.feedback | `messageId`, `text`, `tags` |
| suggestion.ready | `analysis`, `sampleReply` |
| assistant.delta | `messageId`, `delta` |
| assistant.completed | `messageId`, `ttsConfig` |
| tts.ready | `messageId`, `audioUrl`, `durationMs` |
| progress.updated | `round`, `targetProgress`, `remainingSeconds` |
| turn.finished | `round`, `actions` |
| attempt.paused/resumed | `pausedAt`, `deadlineAt` |
| attempt.ended | `endReason`, `timedOut`, `reportStatus` |
| report.ready | `reportId` |
| error | `errorCode`, `message`, `retryable` |
| ping | `ts` |

客户端收到 `ping` 回：

```json
{ "type": "pong", "ts": 1793244443737 }
```

### 9.4 断线恢复

1. 客户端重新连接。
2. 服务端返回 `connection.ready.lastServerSeq`。
3. 客户端 GET 消息历史。
4. 服务端重放客户端缺少的未终结事件。
5. 客户端按 `seq` 去重。

同一 attempt 的写操作按 `clientMessageId` 幂等。
