# AI实战训练场学员端与训考闭环技术实现方案（前端）

> 版本：v1.1 ｜ 日期：2026-10-30
> 工程：`D:\JACK\final_dream\front-end`
> 技术栈：Vue 3.5、TypeScript、Vite、Element Plus、Pinia、vue-router、原生 WebSocket

## 1. 技术选型

| 能力 | 方案 | 理由 |
|---|---|---|
| 页面与路由 | 现有 vue-router hash 模式 | 与原平台 URL 和现有工程一致 |
| UI | Element Plus + 页面级手写 SCSS | 当前工程已全量使用；业务页继续复用现有视觉变量 |
| 状态 | Pinia + 页面局部状态 | 仅主题首页、attempt runtime、管理学员需要跨组件共享 |
| 请求 | 现有 `src/api/request.ts` | 沿用 JWT、统一错误拦截和 baseURL |
| 对话 | 原生 WebSocket | 协议轻量，不引入 STOMP/socket.io |
| 录音 | 复用 `src/composables/useRecorder.ts` | 已有 16k WAV/权限处理 |
| 播报 | 复用 `src/composables/useAudioPlayer.ts` | 支持继续播报和统一音频状态 |
| Markdown | 复用现有 AI 助手的 Markdown 渲染方式 | 产品详情、报告不新增富文本体系 |
| 在线课堂选择 | 复用 `KngSourcePickerDrawer.vue` | 已实现分类、搜索、分页和选择上限 |
| 文件查看 | 在线课堂复用学习查看组件；ACT 材料走鉴权流 | 避免复制源文件和路径泄露 |

不引入新的 UI 框架、拖拽库或实时语音 SDK。

## 2. 复刻边界与取舍

### 2.1 对齐原平台

- 首页三栏信息密度、主题卡、最近练习、主题详情 Banner 与场景卡结构。
- 场景准备、随机难度、自定义练习步骤、准备页和深色对练页。
- 训练教练点评、语音/文字输入、TTS、到时结束和报告结构。
- 练习历程、主题记录抽屉、管理端学员表格和添加学员抽屉。

### 2.2 自定实现

- 原站跨应用跳到 `drillmate`，本系统统一在 `/sparring/web/drillmate/**` 路由族内完成。
- 原站接口字段和 `studyStatus` 不照抄，前端使用本契约枚举。
- 原站产品档案通过 artifact-server，本系统走 ACT 自己的 `/student/product-profiles`。
- 原站报告嵌在聊天流中，本系统有独立报告实体和页面；页面表现仍接近原平台。

### 2.3 刻意不同

- 不使用“时间超限，未通过”这种提前宣布最终结果的矛盾文案。
- 不展示等级“青铜”和伪造荣誉榜。
- 不在前端计算最终通过或扣次数，服务端是唯一事实源。
- 不使用原站测试 TTS key；TTS 一律由后端返回音频 URL。

## 3. 路由

### 3.1 学员端

```ts
{
  path: '/sparring/web',
  component: StudentLayout,
  children: [
    { path: 'drillmate', name: 'DrillmateHome' },
    { path: 'drillmate/detail/:themeId', name: 'DrillmateThemeDetail' },
    { path: 'drillmate/history', name: 'DrillmateHistory' },
    { path: 'drillmate/files/:materialId', name: 'DrillmateFileViewer' }
  ]
}

// 运行时与报告为独立全屏页，不挂 StudentLayout
{ path: '/sparring/web/drillmate/attempt/:attemptId', name: 'DrillmateAttempt' }
{ path: '/sparring/web/drillmate/report/:attemptId', name: 'DrillmateReport' }
```

说明：

- `/attempt/:attemptId` 内根据 attempt 状态显示准备、准备完成、对练、报告生成中。
- 报告完成后可保持同一 URL 显示报告，也可由前端 `replace` 到 `/report/:attemptId`；建议前者减少跳转，后者便于分享和刷新。本项目选择 `/report` 独立路由，`查看报告` 时跳转。
- 所有路由 `meta.requiresAuth=true`。

### 3.2 管理端

沿用现有 `/sparring/freesimulate/theme/:id`，不改路由：

- 学员管理 Tab：真实组件替换 `StudentPanel.vue`。
- 主题设置：读全局设置接口。
- 版本历史：只展示已发布内容版本。
- AI 助手：增加产品档案 Tab/模块。
- 产品档案详情可作为右侧面板子视图，不新增顶层路由。

## 5. 页面实现

### 5.1 顶部导航

修改 `src/components/layout/StudentTopNav.vue`：

- 将禁用 `span` 改为 `router-link`。
- 激活判断使用 `route.path.startsWith('/sparring/web/drillmate')`。
- 移动端保留菜单可达性；若导航横向空间不足，进入“更多”菜单，不隐藏唯一入口。

### 5.2 首页 `Home.vue`

数据请求并发：

```text
GET /api/act/student/home/summary
GET /api/act/student/themes?scope=mine
GET /api/act/student/themes?scope=opportunities&limit=6
GET /api/act/student/practice-records?page=1&pageSize=1
```

布局：

- 1200px 网格：`280px minmax(0, 1fr) 320px`。
- 1024px 以下变为两栏，最近练习移到主列下面。
- 760px 以下单列。
- 每个区块独立 loading/error/empty。

### 5.3 主题详情 `ThemeDetail.vue`

- 主接口返回主题、场景、评估、资料和档案摘要。
- 场景按钮根据 `nextAction` 字段渲染，不在前端重推状态。
- 点击场景先请求场景准备详情。
- 记录抽屉请求 `themeId + pageSize=10`。
- 开启训练与考核时，场景卡显示“开始训练 / 开始考核（或锁定）”。

### 5.4 场景准备与三类练习

`ScenarioPrepareDialog` 只渲染服务端允许的 `practiceMethods`。任何入口最终都调用同一 `preflight`：

```ts
preflight({
  themeId,
  scenarioId,
  studyMode,
  practiceType,
  customConfig?,
  difficulty?
})
```

- `preflight` 通过后再显示或创建 attempt。
- 随机练习和自定义练习先收集参数，模式选择放在资格检查前。
- 自定义步骤数组由后端返回 `requiredSteps`，前端按顺序渲染。

### 5.5 Attempt store 与 WS

`drillAttempt` store 负责：

- attempt 详情。
- 消息列表。
- 准备阶段。
- 当前轮次和进度。
- TTS 播放队列。
- WS 连接状态。
- 结束和报告状态。

`useDrillSocket`：

```ts
ws = new WebSocket(`${wsBase}/api/act/ws/drill?attemptId=${id}&token=${token}`)
```

职责：

- 20 秒 ping/pong 由服务端和 composable 处理。
- 断线指数退避 1s、2s、4s、8s、15s。
- 重连时先 GET attempt 快照，再以 `lastServerSeq` 续传。
- 事件按 `seq` 去重。
- 发送动作使用 `clientMessageId`，防止重复。

客户端动作：

| action | 用途 |
|---|---|
| `drill.start` | 准备完成后正式开始 |
| `chat` | 发送文字 |
| `voice.transcript` | 发送已确认的 ASR 文本 |
| `suggestion.request` | 请求训练建议 |
| `drill.pause` / `drill.resume` | 训练暂停/继续 |
| `drill.finish` | 主动结束 |
| `pong` | 心跳 |

服务端事件在前端映射：

| event | UI |
|---|---|
| `preparation.progress` | 深色准备页四阶段 |
| `preparation.ready` | 准备完成页 |
| `turn.started` | 输入禁用、显示处理中 |
| `coach.feedback` | 只训练模式展示 |
| `assistant.delta` | 打字机追加 |
| `tts.ready` | 绑定音频 URL |
| `progress.updated` | 时间、轮次、目标达成度 |
| `turn.finished` | 恢复输入 |
| `attempt.ended` | 结束弹窗 |
| `report.ready` | 跳报告 |
| `error` | 结构化错误提示 |

### 5.6 对练页面

`DrillConversation.vue`：

- 左侧/主区固定形象舞台，比例自适应，容器 `min-height` 而不是固定 1:1.2。
- 消息区独立滚动。
- 场景旁白、AI 台词、学员台词、教练点评用不同语义样式。
- `ScenarioDrawer` 可关闭，打开时记住滚动位置。
- `DrillInputBar` 支持 Enter 发送、Shift+Enter 换行。
- 录音时显示音量与时长，识别结果回填到输入框，不自动发送。
- TTS 队列一次只播一条；“继续播报”从当前消息继续，不是重新请求整段对话。

`useAttemptTimer`：

- 服务端返回 `serverNow`、`deadlineAt`，前端只做本地平滑显示。
- 每 30 秒或恢复时校准一次。
- 时间到仅显示“正在结束”，等待服务端 `attempt.ended`，不由前端强制判定。

### 5.7 防作弊

`useAntiCheat.ts`：

- `visibilitychange`、`blur`、窗口失焦上报 `screen.hidden`，带去重阈值。
- 考核开始时请求摄像头；按服务端配置定时抓帧。
- 抓帧压缩为 JPEG 后上传，不把原始视频流保存在浏览器。
- 本地只展示“已启用防作弊”，不展示人脸比对细节。
- 超过允许切屏次数后禁止继续操作，等待服务端结束。

若摄像头权限被拒绝：

- 人脸识别启用的考核不允许开始。
- 纯训练不受影响。

### 5.8 报告页

`ReportPage.vue` 分为：

- 顶部结果横幅。
- 总分/通过线/目标达成。
- 结果事实卡：到时、主动退出、违规等。
- 总体评价。
- 维度卡与公式。
- 证据和改善建议。
- 对话回放。
- 返回和再练。

所有分数用后端字符串/小数，不在前端累加作为最终结果。

### 5.9 练习历程

- Tab 切换使用 query：`status=all|passed|failed|in_progress`。
- 主题筛选和分页请求服务端。
- 行内“查看报告”与首页共享 `openReport(attemptId)`。
- 进行中调用 `resumeAttempt(attemptId)` 恢复同一 attempt。

### 5.10 管理端学员管理

替换 `StudentPanel.vue`：

- 工具栏与表格分离，表格 loading 不遮整页。
- 添加学员抽屉复用 `DeptTree`，不建议直接复用考试模块里带考试专用字段的组件；抽出通用 `StudentPickerDrawer`，保留同样的交互。
- 部门、姓名/账号/工号查询与分页都请求服务端。
- 已选学员跨页保留。
- 行操作使用文字按钮或图标按钮并提供 tooltip。
- 学员详情抽屉按 tab 懒加载数据。

### 5.11 产品档案与在线课堂

AI 助手：

- `ChatColumn.vue` 的“上传资料”改为 dropdown。
- 复用 `KngSourcePickerDrawer.vue`，`purpose=designAssistant`。
- 成功后同时刷新 messages 和 materials。
- `ArtifactPanel` 增加“产品档案”Tab。
- `ProductProfileEditor` 编辑字段与 Markdown，保存到工作区 artifact。
- 点击确认时由后端统一落库与发布。

学员端：

- `FileViewer.vue` 同时根据 `sourceType + renderMode` 分流。
- 在线课堂材料通过 `/student/materials/:id/viewer-context` 获取 coursewareId，再复用 `CoursewareStudyInCourse.vue` 的查看能力。
- ACT 本地 PDF 使用带鉴权的 Range 流；TXT/Markdown 使用文本阅读器；Office 未生成 PDF 时进入正式文本回退。
- 产品档案使用 `09-产品档案artifact契约.md` 的 `profileKey`、`customFields[]` 和 Markdown 结构。

## 6. 视觉落地

建议变量：

```scss
$drill-primary: #436bff;
$drill-primary-soft: #eef3ff;
$drill-text: #262626;
$drill-muted: #8c8c8c;
$drill-border: #e9e9e9;
$drill-bg: #f5f6f8;
$drill-success: #16a34a;
$drill-warning: #fa8c16;
$drill-danger: #f5222d;
$drill-radius-card: 12px;
$drill-radius-inner: 8px;
```

动效：

- 卡片 hover 边框色 150ms。
- 抽屉/弹窗 180ms 滑入/淡入。
- 准备阶段进度按真实事件推进，可平滑过渡但不得伪造百分比。
- 报告维度条从 0 到实际宽度 300ms；尊重 `prefers-reduced-motion`。

## 8. 测试要求

- Vitest：状态映射、路由、attempt store、WS 事件归并、计时校准。
- Playwright：首页 -> 详情 -> 三类练习 -> 准备 -> 对练 -> 报告 -> 再练。
- 断线：对话中关闭网络 10 秒后恢复，消息与倒计时正确。
- 双开：同一 attempt 两个标签页，仅一个可发送。
- 移动端：375px 无页面级横向滚动。

## 9. 风险

| 风险 | 处理 |
|---|---|
| 原站研究与自研状态枚举混用 | 统一以 `04-接口文档.md` 为准 |
| WS 丢帧或重复 | `seq` 去重 + reconnect snapshot |
| 浏览器计时不可信 | 服务端 deadline 与系统定时结算 |
| 音频供应商阻塞 | 音频组件只消费 URL；供应商可替换 |
| 人脸供应商未配置 | 保存设置时阻止启用，运行前再次校验 |
| Element Plus 下拉的 z-index | 统一使用 `append-to-body` 和项目层级别名，验收复合筛选 |
