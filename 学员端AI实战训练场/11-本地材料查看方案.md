# ACT 本地材料查看方案

> 版本：v1.0 ｜ 日期：2026-10-30
> 解决：浏览器不能直接渲染 DOC/DOCX/PPT/PPTX 的问题。
> 结论：首期采用“PDF/文本双模式”。Office 优先异步转 PDF；转换器不可用或失败时回退到提取文本阅读，不阻塞上传、训练和发布。

## 1. 支持矩阵

| 源类型 | 首选查看方式 | 回退 |
|---|---|---|
| PDF | 浏览器 PDF 查看器 | 文本阅读 |
| TXT/MD | 文本/Markdown 阅读器 | 无 |
| DOC/DOCX/PPT/PPTX/PPS | 异步转 PDF 后查看 | 提取文本阅读 |
| 在线课堂文档 | 在线课堂现有查看器 | 在线课堂自身错误态 |

“回退文本”是正式产品状态，不是错误掩盖。界面必须明确显示“当前为文本预览，版式可能不同”，同时提供原文件下载。

## 2. 数据模型

`act_ai_material` 增加：

| 字段 | 类型 | 说明 |
|---|---|---|
| preview_status | varchar(24) | `not_needed/pending/ready/text_only/failed` |
| preview_file_id | varchar(64) | 预览 PDF 的内部文件 id |
| preview_error | varchar(500) | 转换失败摘要，不返回给学员 |

状态：

| 状态 | 含义 | 学员动作 |
|---|---|---|
| not_needed | PDF/TXT/MD 直接可读 | 打开原文件 |
| pending | Office 转换中 | 先显示文本阅读，可稍后刷新 |
| ready | PDF 预览可用 | 打开 PDF |
| text_only | 未配置转换器或格式不支持 | 打开文本阅读 |
| failed | 转换失败 | 打开文本阅读并显示“版式预览不可用” |

`act_content_version_material` 增加快照字段：

- `preview_file_id`
- `render_mode`：`pdf/text`

不向学员返回 `preview_error` 的底层异常。

## 3. 转换架构

```text
本地上传
  -> Tika 文本提取
  -> PDF/TXT/MD：直接标记 not_needed
  -> Office：
       创建 preview_status=pending
       提交 previewExecutor
       -> DocumentPreviewConverter
            provider=office-com / libreoffice / none
       -> 成功: 保存 PDF, status=ready
       -> 失败/无 provider: status=text_only/failed
```

解析和转换不能占用训练 runtime 或报告线程池。

## 4. Converter 接口

```java
public interface DocumentPreviewConverter {
    String provider();
    boolean supports(String extension);
    PreviewResult convert(Path source, Path outputDir, Duration timeout);
}
```

`PreviewResult`：

```json
{
  "success": true,
  "previewFile": "uuid.pdf",
  "durationMs": 3200,
  "error": null
}
```

### 4.1 provider

- `office-com`：Windows + Microsoft Office，开发机可选。
- `libreoffice`：生产推荐，`soffice --headless`。
- `none`：直接回退文本阅读。

当前开发机检测到 Microsoft Office，但未检测到 LibreOffice。因此本地可以配置 `office-com`，生产必须显式部署 LibreOffice 或保持 `none`。

不得在运行时自动探测并调用任意可执行文件；provider 只能由配置决定。

### 4.2 配置

```properties
act.material.preview.provider=${ACT_MATERIAL_PREVIEW_PROVIDER:none}
act.material.preview.office-executable=${ACT_PREVIEW_OFFICE_EXE:}
act.material.preview.libreoffice-executable=${ACT_PREVIEW_LIBREOFFICE_EXE:soffice}
act.material.preview.timeout-ms=120000
act.material.preview.max-file-size=52428800
act.material.preview.pool.core=1
act.material.preview.pool.max=2
act.material.preview.pool.queue=32
```

## 5. 安全

- 源文件路径以 `act-files` 根目录规范化后校验，不允许路径穿越。
- 不通过 shell 拼接文件名；使用 ProcessBuilder 参数数组。
- 临时目录必须每次转换独立创建，结束后清理。
- 只允许白名单扩展。
- 输出 PDF 必须位于 `act-files/previews/`。
- 转换超时强制终止进程。
- 同一 material 加数据库锁，防止并发重复转换。

## 6. API 调整

### 6.1 学员材料查看上下文

`GET /api/act/student/materials/{materialId}/viewer-context`

```json
{
  "id": "material-id",
  "name": "产品培训.pptx",
  "sourceType": "act_local",
  "fileType": "pptx",
  "renderMode": "pdf",
  "previewStatus": "ready",
  "viewerUrl": "/student/materials/material-id/preview.pdf",
  "originalUrl": "/student/materials/material-id/stream",
  "notice": null
}
```

文本回退：

```json
{
  "renderMode": "text",
  "previewStatus": "text_only",
  "viewerUrl": null,
  "textUrl": "/student/materials/material-id/text",
  "originalUrl": "/student/materials/material-id/stream",
  "notice": "当前为文本预览，版式可能与原文件不同"
}
```

### 6.2 新增接口

| API | 路径 | 说明 |
|---|---|---|
| API-F04 | `GET /student/materials/{id}/preview.pdf` | 返回预先转换的 PDF，Range |
| API-F05 | `GET /student/materials/{id}/text` | 返回提取文本，按发布快照鉴权 |
| API-F06 | `GET /student/materials/{id}/download` | 下载原文件，审计 |

权限：

- 学员必须仍参与该主题。
- material 必须属于当前 published snapshot。
- 在线课堂材料不经过本接口，使用 viewerContext 中的 coursewareId。

## 7. 前端

`FileViewer.vue` 根据 `renderMode`：

- `pdf`：内嵌 PDF 查看器。
- `text`：等宽文本阅读器 + Markdown 渲染。
- `online_classroom`：跳在线课堂 viewer。

页面操作：

- 下载原文件。
- 文本模式下显示说明。
- `pending` 时允许先读文本，并提供“刷新版式预览”。
- 错误不暴露磁盘路径、转换命令和 provider 异常。

## 8. 发布快照

发布时把以下字段复制到 `act_content_version_material`：

- source_type/source_id。
- preview_status。
- preview_file_id。
- render_mode。

发布后源材料转换仍在后台进行时：

- 学员先看到文本模式。
- 转换成功可更新当前发布快照的 preview_file_id 和 status。
- 不允许因此产生内容版本升级；预览是派生资源，不是内容。

## 9. 测试

- PDF Range 请求。
- TXT/MD 中文编码。
- DOCX/PPTX 转换成功。
- 转换器缺失时 `text_only`。
- 转换超时、损坏文件、文件为空。
- 路径穿越。
- 跨主题访问 403。
- 在线课堂材料走在线课堂 viewer。
- 转换失败不阻塞 AI 材料解析和训练发布。

## 10. 验收口径

首期交付必须保证：

- PDF/TXT/MD 可直接查看。
- Office 文件有文本阅读回退。
- 配置了 `office-com` 或 `libreoffice` 时，Office 可异步转 PDF 查看。
- 未配置转换器不会让上传失败，也不会阻塞主题发布。
- 学员只能访问当前发布快照中的材料。
