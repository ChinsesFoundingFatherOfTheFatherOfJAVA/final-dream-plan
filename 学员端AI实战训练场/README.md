  - `../AI实战训练场管理端复刻/`

## 实施边界

- 包含：学员首页、主题详情、场景准备、三类练习、准备生成、训练/考核运行、报告、再练、练习历程、方案时间限制、学员管理、产品档案、内容版本和在线课堂素材。
- 不包含：知识空间、竞技场、荣誉榜、实时口型驱动、审批式加入、分享/游客体系。
- 证据中的原平台接口只用于理解语义，正式接口由 `04-接口文档.md` 定义。
