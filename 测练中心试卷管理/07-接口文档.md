## 1. 试卷分类 PaperCatalog（与题库 Catalog 同构，路径换 /paper/catalog）

- **GET `/paper/catalog/tree`**：试卷分类树（节点结构同题库 catalog tree，含 users 管理员/继承字段）
- **GET `/paper/catalog/{id}`** / **POST `/paper/catalog`**（批量新建）/ **PUT `/paper/catalog/{id}`** / **PUT `/paper/catalog/{id}/move`** / **PUT `/paper/catalog/{id}/disable`** / **DELETE `/paper/catalog/{id}`** —— 请求响应结构 100% 同题库 `/catalog/*`（见题库 03 §1）

## 2. 试卷 Paper

### 2.1 POST `/paper/list?current=1&limit=10&orderby=updateTime&direction=desc`

body：`{ "queryType": 0, "keyword": "", "catalogId": "root", "routingPath": "", "creatorUserId": "", "buildType": -1, "disabled": -1, "status": -1 }`
- queryType：0全部 1我创建的 2共享给我的；status：-1全部 0未发布 4已发布

```json
{ "datas": [ { "id": "uuid", "name": "test-随机出卷", "catalogName": "默认试卷分类",
  "buildType": 1, "status": 0, "disabled": 0, "secrecy": 0,
  "totalScore": 0, "totalQuesQty": 0, "usedQty": 0,
  "createUserId": "u1", "createFullname": "管理员", "createUserName": "admin",
  "updateTime": "2026-10-13 10:00:00",
  "permissions": { "canDelete": true, "canEdit": true } } ] }
```

### 2.2 GET `/paper/{id}`
详情（管理页基本信息）：同上单对象 + `quesMode`。

### 2.3 POST `/paper`（创建抽屉）/ PUT `/paper/{id}`（编辑基本信息）
`{ "name": "≤200字", "catalogId": "uuid", "buildType": 0, "secrecy": 0 }`

### 2.4 试卷操作
- **PUT `/paper/{id}/disable`**：`{ "disabled": 1 }`
- **DELETE `/paper/{id}`**：仅创建者/超管（40003）；级联删关联（exam_paper_question/strategy/share，逻辑删）
- **PUT `/paper/{id}/transfer`**：`{ "toUserId": "uuid" }`
- **PUT `/paper/{id}/catalog`**：`{ "catalogId": "uuid" }`
- **PUT `/paper/{id}/ques-mode`**：`{ "quesMode": 0 }`（0题型+难度 1题型 2难度 3数量）
- **POST `/paper/batch`**：`{ "action": "delete|transfer|changeCatalog", "paperIds": [...], "toUserId": "", "catalogId": "" }`

### 2.5 共享（仅已发布）
- **GET `/paper/{id}/share`**：`{ "shares": [ { "targetType": 1, "targetId": "", "targetName": "部门名" } ] }`
- **PUT `/paper/{id}/share`**：全量覆盖 `{ "shares": [...] }`
- 前置：status=4，否则 `40030 该试卷未发布，不能共享`

### 2.6 发布
- **PUT `/paper/{id}/release`**（无 body；与 `front-end/src/api/paper.ts` 的 `releasePaper` 一致）
- 校验链：`40051 请先设置策略或添加试题` → `40052 请先设置分值` → 成功返回 `ApiResponse<Void>`（`data: null`），试卷 `status` 置 `4`
- status=4 后：策略/来源写接口返回 `40050 试卷已发布，不可修改`；题目编辑仅白名单字段（`40040 已发布试卷仅可修改题干/选项/答案/解析`）

### 2.7 引用
- **GET `/paper/{id}/use`**（不分页）：`data: [ { "id": "uuid", "refName": "考试名", "sourceType": 1, "creatorName": "林婷婷(40021816)", "status": "进行中", "createdAt": "2026-10-09 15:50" } ]`
  - `sourceType`：1 课程安排 / 2 单独安排；没有 `type` 与 `sourceTypeText` 字段。
- **POST `/paper/export`**：body 为 2.1 的 `ListQuery`（不是 query），返回文件流。

## 3. 随机卷策略 Strategy

### 3.1 GET `/paper/{id}/strategy`
```json
[ { "libId": "uuid", "libName": "模板/特种/开袋机", "selectedSourceType": 0, "selectedPointIds": "1",
    "catalogName": "默认题库分类", "quesQty": 0,
    "settingCount": [
      { "levelType": 0, "singleQty": 2, "multiQty": 0, "judgeQty": 0, "fillQty": 0, "qaQty": 0, "needQty": 0,
        "singleMaxQty": 19, "multiMaxQty": 11, "judgeMaxQty": 0, "fillMaxQty": 0, "qaMaxQty": 0, "maxQty": 30,
        "singleScore": 0, "multiScore": 0, "multiMissScore": 0, "multiMissScoreType": 0,
        "judgeScore": 0, "fillScore": 0, "qaScore": 0 },
      { "levelType": 1, "…同结构…" }, { "levelType": 2, "…同结构…" } ] } ]
```
- 请求时后端重算 MaxQty 快照（实时 COUNT），Qty/Score 读库。

### 3.2 POST `/paper/{id}/strategy/source`（设置抽题来源，全量覆盖）
```json
{ "sourceType": 0, "libs": [ { "libId": "uuid", "pointIds": [] } ] }
```
- sourceType：0按题库 1按考核点（pointIds 空数组=全部考核点） 2按自选试题
- 校验：已有 sourceType 0/1 来源时不可设 2（40061）；来源库数量上限计算后写 MaxQty。

### 3.3 PUT `/paper/{id}/strategy/cell`（单元格更新，失焦触发）
```json
{ "libId": "uuid", "levelType": 0, "field": "singleQty", "value": 2 }
```
- field ∈ singleQty/multiQty/judgeQty/fillQty/qaQty/needQty/singleScore/multiScore/multiMissScore/multiMissScoreType/judgeScore/fillScore/qaScore
- Qty 类校验 ≤ MaxQty（40060 超出抽题来源库存）；后端行锁合并整条 JSON 写回。

### 3.4 辅助
- **GET `/paper/{id}/strategy/summary`**：`{ "quesQty": 7, "totalScore": 35 }`（按当前 quesMode 生效字段计算）
- 快速抽题/快速设置抽题策略：前端算出目标矩阵后逐格调 3.3（或聚合 POST `/paper/{id}/strategy/batch-cell`，body 为 cell 数组——二选一实施时定，推荐 batch-cell 减请求数）

## 4. 固定卷题目 PaperQues（同源写入）

### 4.1 GET `/paper/{id}/questions?current=1&limit=10&type=-1&levelType=-1&keyword=`（管理页列表）
`{ "records": [ { "quesId": "uuid", "summary": "题干", "type": 0, "levelType": 0, "score": 5,
  "libId": "uuid", "libName": "默认题库", "mainPointName": "考点", "createFullname": "", "createTime": "" } ] }`

### 4.1a GET `/paper/{id}/questions/export?type=-1&levelType=-1&keyword=`
- **用途**：已发布考试的只读试题回看页导出。
- **筛选**：与 4.1 完全同口径。
- **出参**：`xlsx` 文件流；列=试题名称/题型/考核点/所属题库/难度。

### 4.2 GET `/paper/{id}/edit`（编辑页画布结构）
```json
{
  "sections": [
    { "sectionIndex": 0, "quesList": [ { "quesId": "uuid", "type": 0, "content": "HTML", "summary": "",
        "levelType": 0, "score": 5, "orderIndex": 1, "libId": "uuid", "libName": "默认题库",
        "questionItems": [ { "itemContent": "", "answer": 1, "orderIndex": 1 } ],
        "judgeAnswer": 0, "answerContent": "", "answerKeywords": [], "noOrderMark": 0,
        "points": [ { "pointId": "", "name": "" } ] } ] }
  ],
  "editableFields": ["content", "questionItems", "explainText"]
}
```
- 返回对象而不是数组：`sections` 按 sectionIndex 分组，中文编号前端计算。
- `editableFields` 只在 status=4 时出现（未发布为 null/缺省）。

### 4.3 POST `/paper/{id}/question`（添加题目=同源写入）
```json
{ "sectionIndex": 0, "score": 5, "libId": "uuid",
  "question": { "…题库模块 03 §3.3 请求态（type/content/questionItems/judge/answer/keywords/points）" } }
```
- 后端：QuesService.save 入库 + 插关联；校验链同题库（40010）+ score>0。
- `data`: `{ "quesId": "uuid", "orderIndex": 1 }`

### 4.4 POST `/paper/{id}/question/pick`（从题库选题，只建关联）
`{ "items": [ { "quesId": "uuid", "score": 5, "sectionIndex": 0 } ] }`

### 4.5 PUT `/paper/{id}/question/{quesId}`（编辑）
- **未发布**：可改全部（score/libId/levelType/points + 题目内容——题目内容变更走题库 QuesService）
- **已发布**：白名单（content/questionItems 内容与数量/答案/explainText），越权字段 40040

### 4.6 DELETE `/paper/{id}/question/{quesId}`
移除关联（**不删题库试题**，对齐原平台语义——题库试题独立存在）；冗余计数维护。批量：POST `/paper/{id}/question/batch-delete`。

### 4.7 PUT `/paper/{id}/question/sort`
`{ "moves": [ { "quesId": "uuid", "sectionIndex": 0, "orderIndex": 2 } ] }`（拖拽排序，含跨组移动）

### 4.8 POST `/paper/{id}/question/batch-score`（快速设置全部分数）
`{ "scores": [ { "sectionIndex": 0, "score": 2 }, { "sectionIndex": 1, "score": 3, "missScore": 1, "missScoreType": 1 } ] }`

## 6. 快速出卷

- **GET `/paper/import/template`**：xlsx 模板文件流（classpath 静态）
- **POST `/paper/import`**（multipart：file + libId + catalogId + secrecy）
```json
{ "successCount": 28, "failCount": 2,
  "errors": [ { "sheet": "单选题", "row": 5, "reason": "分值不能为空" } ],
  "paperId": "uuid" }
```
- 解析规则：题目/考核点≤5分号分隔/难度/分值必填/多选漏选得分[-|数字|n/n/n]/解析/正确答案/选项或填空顺序[有序|无序]+答案&&备选答案。

## 7. 默认分值配置

- **GET `/score-config`** / **PUT `/score-config`**：`{ "items": [ { "type": 0, "levelType": 0, "score": 1, "missScore": 0, "missScoreType": 0 } ] }`
- 用途：设置默认分值抽屉 + 策略分值/新题分值默认值。

## 8. 错误码（增量）

| code | 场景 |
|------|------|
| 40030 | 试卷未发布，不能共享 |
| 40040 | 已发布试卷仅可修改题干/选项/答案/解析 |
| 40050 | 试卷已发布，不可修改策略 |
| 40051 | 请先设置策略或添加试题（发布校验1） |
| 40052 | 请先设置分值（发布校验2） |
| 40060 | 超出抽题来源库存 |
| 40061 | 存在题库/考核点来源时不能切换为自选试题 |
| 40070 | 试题被试卷引用，不能删除（题库侧删题校验） |
