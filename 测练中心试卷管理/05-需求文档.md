## 1. 范围

复刻测练中心**试卷管理**（组卷子模块）：试卷分类树、试卷列表、创建/快速出卷、管理页、随机出卷策略编辑、固定出卷大题画布编辑、发布流、共享（已发布限定）、概览统计。

**核心语义（已拍板）**：试卷题目与题库试题**同表同源**（exam_question），试卷保存题目即入库（默认进"默认题库"，卡片可选归属库）；从题库选题仅建关联。

## 3. 功能需求

### FP-04 试卷分类树（EP-01/02）
- 与题库分类树**组件完全复用**（CatalogTree/CatalogFormDrawer/MoveCatalogDrawer/齿轮五项/权限继承），接口换试卷分类（exam_paper_catalog）；根节点"默认试卷分类"。
- 点击分类 → 列表按 catalogId+routingPath 过滤（含子分类）。
- **验收**：Given 试卷分类页 When 点新建 Then 抽屉与题库分类新建完全一致（批量文本框+权限设置）。

### FP-05 试卷列表（EP-03/04）
- 字段：试卷名称（保密橙tag）/出卷方式（固定/随机）/引用次数（排序；**非0蓝链可点→FP-11**）/创建人（姓名(工号)）/更新日期（排序）/试卷状态（**0=已保存灰点，4=已发布绿点，仅两态**）/启用（绿点悬浮反向字点击切换）/操作（**未发布显示"发布"+更多；已发布仅更多**）。
- 筛选：全部试卷/创建人（选人器）/出卷方式/启用状态/**试卷状态（未发布/已发布两态）**/名称搜索/导出数据（Excel）。
- **验收**：Given status=4 的试卷 When 列表渲染 Then 操作列无"发布"按钮；Given 引用次数=2 When 点击 Then 弹引用抽屉。

### FP-06 更多菜单（EP-05）
- 项：管理（FP-07）/编辑（固定→FP-10、随机→FP-08，按 buildType 分流）/删除（非创建者置灰，确认弹窗）/共享（**仅 status=4 显示**；抽屉复用题库 ShareDrawer：共享范围=部门+人）/转移（所有权变更）/修改分类（树抽屉）。
- 共享入口条件：前端按 status 控制显示 + 后端校验（未发布调共享接口返回 40030）。

### FP-07 管理页（EP-07）
- 页头：返回 + 试卷名 + 出卷方式橙色 tag + 右侧 发布（未发布时）/编辑/更多。
- 基本信息：试卷名称/试卷分类/试卷保密 + 编辑基本信息链接（抽屉：分类树+名称200字+保密）。
- 试题列表：题型（**五种无组合题**）/难度/试题名称搜索/导出数据；列：试题名称（**蓝链**）/题型/考核点/所属题库（**蓝链**）/难度。
- **跨模块跳转**：试题名称 → `/exam/queslib/detail?libId=&quesId=`（题库详情页支持 quesId 过滤只展示该题）；所属题库 → `/exam/queslib/detail?libId=`。
- **验收**：Given 点试题名称 When 跳转 Then 题库详情页列表仅显示该试题。

### FP-08 随机出卷编辑页（EP-08）
- 顶部：试卷名 + 自动保存提示（"试卷将自动保存"/"保存成功！"）+ 预览/导出/发布（发布后消失）。
- 左侧 tab：题型/概览（FP-15）。
- 配置区：所属分类 + **抽题方式四 radio**（按试题题型+难度/按试题题型/按试题难度/按试题数量；切换即调 quesMode 持久化）+ 顶部统计（试题数/总分，随策略实时计算）。
- **策略矩阵按 quesMode 四态**：
  - 题型+难度（默认）：题库行 ×（难度行[易/中/难] × 题型列[单选/多选/判断/填空/问答]）15 输入格/库
  - 题型：题库行 × 题型列 5 格
  - 难度：题库行 × 难度列 3 格
  - 数量：题库行 × 1 格
  - 每库行含：库名/所属题库分类/考核点（所有考核点）/总分 + 移除链接；底部合计行（题数/总分）
  - 每输入格旁 ≤上限 = 该库该题型难度实际库存（进页面时快照）
- **设定分值表**随 quesMode 变维度（题型+难度=题型×难度矩阵含多选漏选得分[统一得X分/按漏选数量均分两radio+帮助图标]；题型=题型列+漏选；难度=难度列；数量=单一分值）；合计（总分）行。
- **单元格失焦自动保存**（PUT 单元格数据，后端合并整条策略）。

### FP-09 抽题来源三入口（EP-08）
- "选择抽题来源"下拉三项：**按题库 / 按考核点 / 按自选试题**（自选试题在存在题库/考核点来源时**禁用**，移除全部来源后可点）。
- 按题库 → 抽屉多选题库（题库-考核点树 + 分类筛选 + 题库/考核点搜索 + 已选回显+清空）。
- 按考核点 → 同树按考核点粒度多选（勾选库=展开其考核点 tag 列表）。
- 按自选试题 → 抽屉空态（"请选择题库或考点"+去选择按钮）→ 选择题库/考点抽屉（树+搜索）→ 勾选后试题列表（题型/难度/搜索筛选+正确率列+全选筛选结果+分页）勾选确定。
- **快速抽题**（自选试题模式内）：抽屉按当前 quesMode 展示对应输入表（题型×难度表/题型行/难度行/数量行，≤上限），确定后写入策略。
- **快速设置抽题策略**按钮：选择来源后解除置灰；抽屉（试题总数 + 按难度/按题型/按数量三 radio + 对应输入行 + ≤上限）。
- **验收**：Given 已选题库来源 When 打开来源下拉 Then "按自选试题"置灰；Given 移除全部来源 When 再打开 Then 可点击。

### FP-10 固定出卷编辑页（EP-09）
- 左栏：选择题型（六题型按钮）+ 底部 AI出题/从题库选题/导入。
- 中心画布：**大题分组**——每题型一个大题组，标题"N、题型名（本题共X小题，共Y分）"（中文序号按题型**首次出现**顺序递增）；点左栏题型 → 该题型已有组的最后一题后追加编辑卡片（无组则新建组）。
- 题目卡片：折叠态（序号+题干+选项+分值预览+移动/复制/删除图标）+ 展开态（六题型编辑表单**复用题库模块** + **题目设置区**：此题分值[满分N分]/题库下拉/难度/考核点）；确定时校验链（至少一个正确选项→分数必须大于0）内联报错。
- **保存=同源写入**：题目写 exam_question（libId=卡片选择的归属库，默认默认题库）+ 写 exam_paper_question 关联（score/section_index）。
- 拖拽排序：大题之间 + 小题之间（sort 更新 order_index/大题重排）。
- 右栏：试题数/总分统计 + 快速设置全部分数链接 + 大题概览（大题名+小题数方框，点击滚动定位）。
- **自动保存**：卡片确定即存；发布前状态文案"试卷将自动保存"。
- **验收**：Given 空卷点单选题 When 添加1题确定 Then 出现"一、单选题（本题共1小题，共N分）"；Given 再点多选题加题 Then 出现"二、多选题"；Given 再点单选题加题 Then 新卡片在"一、单选题"组末尾，不新建组。

### FP-11 引用次数抽屉（EP-06）
- 引用该试卷的考试列表：名称（蓝链，考试模块未建暂无跳转）/类型（考试）/创建人/创建时间（排序）/来源（课程安排|单独安排）/状态（进行中等）；类型筛选+名称搜索+导出数据。
- 数据来源：exam_paper_use 轻量表（考试模块上线后回填；演示可插种子数据）。

### FP-12 创建/快速出卷（EP-11/12）
- **创建试卷抽屉**：试卷分类（树）/试卷名称（≤200字）/出卷方式（固定/随机 radio）/试卷保密（公开/保密，保密注释同题库）。
- **快速出卷抽屉**四步骤：①下载模板（xlsx，含分值列）②选择题库（**整卷题目归属库**，写入 exam_question.lib_id）③选试卷分类+保密 radio ④上传（.xlsx/.xls 拖拽）→ 后端解析（模板列：题目/考核点≤5分号分隔/难度/**分值必填**/多选漏选得分[-|数字|2/2/2/2均分]/试题解析/正确答案/选项或填空顺序[有序|无序]+答案`&&备选答案`）→ 建试卷+写题+建关联+回显 ImportResult。
- 错误提示同题库导入（逐行明细）。

### FP-13 从题库选题/AI出题/导入（EP-09）
- **从题库选题**抽屉：双 tab（快速抽题=按抽题维度批量/选择题库·考点=树）+ 试题勾选列表（筛选+正确率列+全选筛选结果）→ 确定后对勾选题**建关联**（引用已有试题，不复制）。
- **AI出题**：复用题库模块 AI 建题面板（素材→Dify 生成→卡片流编辑）→ 确定录入时题目入库+建关联。
- **导入**：Excel/Word 下拉（复用题库解析器，扩展分值列）。

### FP-14 发布流与发布后状态（EP-14）
- 发布入口：列表"发布"按钮 / 编辑页"发布"按钮 → 确认弹窗"您确认发布该试卷吗？"（复用确认弹窗组件）。
- **校验链**（顺序）：无策略或无试题 → "请先设置策略或添加试题"；分值全 0 → "请先设置分值"；通过 → status=4。
- **发布后随机卷**：编辑页只读——发布按钮隐藏（顶部仅预览/导出）、策略矩阵全部输入禁用、radio 保留展示、来源/策略按钮禁用。
- **发布后固定卷**：左栏选择题型面板**整体隐藏**；顶部变"**同步试卷至考试（置灰占位，二期考试模块联动）**/预览/导出"；题目卡片可点击展开，**仅可修改题干、选项内容与数量、答案、解析**（题目设置区隐藏，分值/题库/难度/考核点不可改）；修改自动保存生效。
- **验收**：Given 随机卷已发布 When 进编辑页 Then 输入框 disabled 且无发布按钮；Given 固定卷已发布 When 展开题卡 Then 题干可编辑、此题分值不可见。

### FP-15 概览tab（EP-10/EP-15 复用组件承载）
- 题型分析/考核点分析/难易程度分析三环形图（中心"试题总数 N"+图例"名称 XX% X题"）；随机/固定卷编辑页共用；数据按试卷已关联（或策略命中）试题统计。

### FP-16 批量操作与设置默认分值（EP-13）
- 批量操作（勾选后）：删除/转移/修改分类。
- 设置默认分值：抽屉，题型×难度分值矩阵（含多选漏选得分）——全局配置（exam_score_config 表），编辑页"设定分值"表的**默认值来源**。

### FP-17 权限与菜单（EP-16/17）
- 试卷删除权：仅创建者/超管（前端置灰+后端校验）；共享/转移/修改分类复用题库权限体系（PermissionService 按 operateType 区分）。
- 侧边菜单：组卷>试卷管理激活；题库管理可正常跳转（已实现）；考试管理/练习管理/题目反馈/字段设置仍 PlaceholderPage。
